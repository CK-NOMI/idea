## P4 preregistered design
Frozen original full FP32 model (same 1B), no independent draft LM. h[t] is final hidden state immediately before lm_head, predicting the already committed pending y[t]. E[y[t]] is existing input embedding. Two-layer small shared predictor concatenates L2 normalized h[t] and E[y[t]], maps 2d ->128 ->4V, four horizon distributions q_j with training-only frequent vocabulary (up to 2047 + abstain class). Targets y[t+1:t+5] from training AR only, 24*60=1440 windows; no future feature. CE versus CE-0.5 sum_j prod_{i<=j} q_i(y[t+i]) (unknown class masked in product). This is an independent categorical sampling surrogate, not exact greedy objective or new theorem. Two trained heads equal parameter count and 20 epochs, AdamW, seed1204, batch64. No HFL yet. Context suffix lookup (max suffix 8, longest then latest match, only known prefix and own proposals) is strong cheap no-training comparator. Inference uses actual predicted IDs, abstains on unknown, full target argmax verification with mandatory correction/bonus and cache rollback, carries hidden row a for next pending token. No reference tape supplied to proposer. Timing includes draft head and host overhead. HFL next only if useful actual proposal signal: investigate prefix survival feedback regional adaptation vs matched flat and global baselines, not simply federate ordinary head or claim regional routing necessary.
