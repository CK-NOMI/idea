## 2. 容量边界（T/P）
限定：稳定工作窗口长度tau，固定共享算力预算C（dense forward-equivalent token slots；非显存大小）；普通AR每正式token消耗1，SD一次验证消耗v=K+1个目标token位置（稳态含前一已提交token的约定），提交期望ell=1+sum_{j=1}^K Pr(L_accept>=j)≤v。若有early exit缓存复用，v应改为真实各层等效工作；不把本限定用于所有自投机实现。每个训练token成本c>0（含反向等效工作）；固定推理需求d（每窗口正式token），无其他额外开销且AR满足SLO。则可用训练token上界 t_AR=(C−d)/c，t_SD=(C−d*v/ell)/c，当预算不足时该服务策略不可行而不是负训练量。因为v/ell≥1，SD在固定容量已饱和、相同需求与成本模型下不能增加可用于训练的计算槽，严格拒绝时上界更小。此为算力资源上界，非任意硬件wall time定理；AR串行依赖、内存带宽、KV、调度开销和推理SLO可能使AR不能达到该上界，SD可减少权重访问次数或满足AR无法满足的延迟。
例C=64,d=32,c=2,K=4,v=5，iid恒定接受概率alpha=.8时ell=1+.8+.64+.512+.4096=3.3616，AR训练上界16，SD约8.20，近减半；alpha=.5时ell=1.9375，推理需要82.58槽，策略不可行。alpha=1且无额外draft时才达到同算力上界。合成解析例，非真实模型。
相反的内存带宽极端：若每次目标前向都读W一次且内存带宽是唯一瓶颈，SD单位提交token的目标权重访问可由|W|降为|W|/ell，忽略draft和KV。这解释同一机制可在不同瓶颈下正负相反，不能以固定alpha推出GPU加速；MagicDec表明长上下文、大批量下仍可能因KV瓶颈获益。HFL同步轮若各区域必须完成N_e训练token，聚合等待至少max_e N_e/r_train,e，需实测实际训练rate；降低请求延迟不等于缩短聚合轮。若实际训练量因服务而变，A/R12的参与偏差约束仍适用。优化应使用同信息平坦、AR+训练co-serving以及同预算SD+训练co-serving，而非分离GPU弱基线。
通信P：相同LoRA版本参数上传量不因矩阵合批自动减少；单线性层d=1536,h=8960,rank16,FP16 A/B共335872字节/客户端/轮（不含其他层、优化器或协议）；若同一共享base在不同物理边缘，不能跨设备假设一次权重读取。迁移训练或请求可能违反驻留约束并增加activation/KV/网络。整个流程可消除部分若只占总wall time<15%，单独消除无法达到G5。

实际执行脚本（保存probe.py，python probe.py，torch==2.10.0 CPU；计时受机器负载影响不可要求数字一致）：
~~~python
import torch, time, statistics, json, platform
from pathlib import Path
torch.set_num_threads(2)
D,H=1536,8960
rows=[]
for seed in [11,29,73]:
    torch.manual_seed(seed)
    w=torch.randn(H,D)/D**.5
    for t in [4,16,64]:
        for v in [1,5,9]:
            x=torch.randn(t,D); z=torch.randn(v,D); g=torch.randn(t,H)
            def separate():
                a=x@w.T; b=z@w.T; c=g@w
                return a,b,c
            def fused():
                y=torch.cat((x,z),0)@w.T; c=g@w
                return y[:t],y[t:],c
            a=separate(); b=fused()
            err=max(float((i-j).abs().max()) for i,j in zip(a,b))
            for _ in range(2):separate();fused()
            st=[];ft=[]
            for i in range(5):
                for fun,arr in ([(separate,st),(fused,ft)] if i%2==0 else [(fused,ft),(separate,st)]):
                    s=time.perf_counter();fun();arr.append(1000*(time.perf_counter()-s))
            rows.append(dict(seed=seed,t=t,v=v,separate_ms=st,fused_ms=ft,separate_median=statistics.median(st),fused_median=statistics.median(ft),max_abs_error=err))
result=dict(env=dict(python=platform.python_version(),torch=torch.__version__,threads=torch.get_num_threads(),cpu=platform.machine(),dtype='float32',cuda=torch.cuda.is_available(),cpu_model=next((l.split(':',1)[1].strip() for l in Path('/proc/cpuinfo').read_text().splitlines() if l.startswith('model name')),None)),shape=[H,D],rows=rows)
print(json.dumps(result,indent=2))
~~~
