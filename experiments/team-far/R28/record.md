## 3. T: exact one-round local-kernel frontier
Let H be the legal history including J and already revealed votes. For remaining indices, X_i conditional on all their votes are independent, with known class laws q_i^b. Let a_i=Pr(B_i=1|H), marginal qbar_i=(1-a_i)q_i^0+a_i q_i^1. A local kernel K_i(y|x,H) gives output class-conditioned distribution r_i^b(y); call i informative if B_i nondegenerate and r_i^0 != r_i^1. Under independent local verifier randomness, conditional outputs are independent given B. Necessity: the two probability-vector columns r_i^0,r_i^1 are linearly independent when distinct (their sums both 1). The tensor product of their left inverses maps product output law on informative set I back to product input vote law. Thus exact target product implies B_I mutually independent given H. Pairwise independence alone is insufficient in general (e.g. XOR). Sufficiency: choose any mutually independent subset I. On I use maximal coupling of qbar_i,p_i; outside I use conditional class proposal q_i^{B_i} against p_i, so output is p_i for either vote. Marginal p_i and output independence on I follow from independent votes; outside I conditional p_i removes all dependencies. Deterministic vote indices can be treated as uninformative.
Let M_i(q)=sum_x w_i(x) min(q(x),p_i(x)), L_i=(1-a_i)M_i(q_i^0)+a_i M_i(q_i^1), D_i=M_i(qbar_i)-L_i>=0. For a round processing set S, the maximum expected retained weighted prefix over these independent local kernels is
R(S,H)=sum_{i in S} L_i + max_{I subset S: B_I independent | H} sum_{i in I} D_i.
Proof upper bound: every informative kernel is bounded by marginal maximal diagonal; uninformative by class-specific maximal diagonal; necessity restricts I. Construction attains both bounds simultaneously. No claim for shared correlated verifier randomness, general joint transport, arbitrary multi-bit feedback or non-additive reward. Threshold/count with heterogeneous positive probabilities often only one nondegenerate informative vote; structurally factorized tails or degenerate votes allow more. Numerically checking independence at tolerance is not exact certification; production must use structural or rigorous arithmetic criteria, with singleton/full conditional fallback.
One-round microGPT results threshold first .62221581 vs fully vote-conditioned .53723700, prefix 1.17511195 vs 1.01409690; count .61461427 vs .53723700, prefix 1.16079666 vs 1.01409690. Target marginal max error 3.89e-16, output vote-pattern TV max 7.10e-16; full 27^4 output not enumerated, product theorem supplies conditional result. One-round is faster in logical depth, not measured runtime, retains fewer drafts than R27.

## 4. T: grouped verification under hard round budget
State H records already processed set A and their vote values; choose nonempty S among remaining based on H before seeing S votes. Use one-round optimum on S; reveal the S votes (not necessarily publicly outside trusted sampler; contract excludes these newly internal observations from original J). Remaining proposal conditional law depends only on H and revealed votes because conditional X_i independent given all votes. Future target output law independent of all prior observations by induction. The grouped schedule exact under same fixed target; choosing schedule from previous votes is legal. For at most k rounds:
F_k(H)=max_S [R(S,H)+E_{B_S|H} F_{k-1}(H,B_S)], F_0(empty remaining)=0, otherwise -infinity.
Proof backward induction on remaining indices and budget. This is an exact restricted-class policy optimum (not arbitrary global transport). Within each round local kernels independent, action and informative subset selected from current history. If reward is two-token prefix, use w_i(x) above; each subsequent token uses unchanged causal q/p and independent randomness. Exact full formal output law by induction on groups and suffix steps; numerical floating-point not certified. Complexity exponential: up to 3^N history states and 2^N subsets per state before independence checks/transitions; brute implementation N=4. Large N needs structural certificate/limited cohorts, approximate scheduling only changes reward not correctness if feasible exact kernels retained. No claim HFL-only advantage: flat delegated coordinator with same information/physical nodes can implement exactly; communication of a_i and reward gains, versions, actual feedback and selection probabilities costs extra and may leak. If summary needs exchange after J, extra setup rounds must count.
