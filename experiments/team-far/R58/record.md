## T/H: late binding and exact counterfactual attention operator
x_j is causal shared shallow state; a_j=R1(x_j;x_<=j). For each reader i choose S_i subset {0,...,i-1} from shallow states x_<=i, never from current next-token label or candidate not yet drawn. Define z_ij=a_j if j in S_i, else x_j; current query uses a_i, current memory x_i. Formal p_S=softmax(W R2(a_i;z_i,<=i)), draft q=softmax(W x_i), same frozen shared head. This is a modified formal model; compared to original dense require quality evidence. A historical j can be selected at later i even when it was not selected earlier, so defer a_j until needed, cache at fixed version and exact causal prefix; selection may change by reader. For a set I of readers, first-stage required states union I and union S_i; cardinality minus valid cached states is the materialized work, not number of per-reader references. Additional K/V projections, cache residency, pair scoring, network costs still needed. Earlier R57 fixed write bit differs; not a generic exact conversion of arbitrary Transformer.
For one attention head, fixed query u, shallow/deep keys k^0_j/k^1_j and values v^0_j/v^1_j. At a common scale M define t^l_j=exp(u^T k^l_j/sqrt(d_h)-M). N0=sum t^0_j v^0_j, D0=sum t^0_j, deltaN_j=t^1_j v^1_j-t^0_j v^0_j, deltaD_j=t^1_j-t^0_j. Then exact selected-bank output o(S)=(N0+sum_S deltaN_j)/(D0+sum_S deltaD_j). By direct expansion. Increment adding j: o(S+j)-o(S)=(deltaN_j-o(S)deltaD_j)/(D(S)+deltaD_j); depends on entire set even though deltas additive. Can reuse all K/V score/value contributions across counterfactual masks, then rerun O/FFN/head for each; not free. Complexity after both banks computed O(|S|*d) attention accumulation per mask rather than O(n*d), but first-stage full a, K/V, logits, nonlinear FFN and output projections must be counted. Not new softmax math; related online softmax and previous R10/HPA block sum. Exact only real arithmetic; subtractive cancellation/underflow possible when reference scale dominated by unselected states, use stable recomputation fallback; production numerical bound not provided. All audits compare selected graph not original dense. If future deeper queries depend on changes in previous selected-bank outputs this formula alone cannot eliminate them.
At fixed theta and q, U(S)=log p_S(y|h)+beta overlap(p_S,q), or exact two-token survival objective with fixed child policy A_i(S)=sum_v min(p_S(v),q(v))*(1+a_child(v)). CE and A give distinct objectives; maximizing U may worsen downstream quality. Nonmonotonic and not generally submodular: scalar fixed-key uniform attention, binary formal logit s=sum of selected signed contributions, label1, beta=0; select j with +a or -a, with initial s=0. f(S)=log sigmoid(s). Adding negative contribution can hurt, and f({+,-})+f(empty)>f({+})+f({-}) for a!=0 by strict concavity, violating submodularity. At beta>0 not universally rescued (e.g. beta small). Hence singleton ranking/greedy cannot assume standard monotone submodular guarantee. Union execution cost across queries is submodular coverage but benefit is not; previous FERV max closure assumes additive benefits, not applicable in general. Counterfactual oracle uses gold label, NOT deployable or a true policy oracle for future unknown labels.
HFL learns region/global/client ridge writer selectors from additive Gram and RHS, optionally local-to-edge/cloud shrinkage selected on held-out names. At inference shallow prefix features only; exact pair scores use all candidate deep states OFFLINE. For 41 features, packed symmetric Gram 861 floats + 41 RHS=902 floats (~3608 FP32 B/sender/refresh for one target; two RHS 943 floats=3772 B), excludes model, protocol, version, downlink; not measured network. Actual implementation centrally pools features, no private secure aggregation or physical HFL, ordinary same-information flat exactly reproduces.
