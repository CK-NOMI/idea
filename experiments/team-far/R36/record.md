## 1. Contract and distinction
Fixed prompt, fixed-length L, frozen formal causal autoregressive policy p, binary reward R, N iid trajectories. Private finite certified set A contained in {R=1}, distinct full trajectories, a=P(A), B=A complement, pi=P(R=1). Assume 0<a<1 and 0<pi<1, independent randomness, identical tokenization and formal processed probabilities. Unknown correct solutions outside A remain eligible. No guarantee of real open-ended RLVR or physical data sharing. At each client compute probability and gradient of A via finite teacher-forced trie; edge/cloud aggregate authorized local gradients, not raw solutions. Same-info flat with delegated local execution can replicate; no DP claim. SD uses actual endogenous shallow q from same model, not an independent LLM. Compared with R35 full fixed-reference admission and R34 black-box full-path lower bound, this changes output contract: exact conditional sampling if desired, but learning only preserves on-policy first-step gradient expectation and admission law, not pathwise optimizer/trajectory outputs when using analytic scores. Compared with R32 group potential, A/R13 reward decomposition, R24 random anchor, FRGB clipping split, new narrow combination is the exact known-success-set weighted scatter and reuse of p-derived future probabilities in proposal conditioning. Neither Bayes nor Rao-Blackwell is a new foundational theorem.

## 2. T: exact mixture and partial Rao-Blackwellization
Draw M~Bin(N,a); select uniformly M of N labeled positions. Conditional on membership indicators, sample A members independently from p(.|A), others independently from p(.|B). This reproduces p^N exactly (multiply Bernoulli membership and conditional trajectory laws); if gradients alone required, skip sampling A identities. Generate B trajectories with exact conditional kernel, score true R including unknown successes. Let K total successes, r=K/N, population sd=sqrt(r(1-r)); homogeneous group reward gradient defined 0. Fixed length L, unclipped on-policy reward-only first step: G=(1/(NL sd))*sum_i (R_i-r)S_i, S_i=grad log p(Y_i); detach coefficients. Replace sum of M known-success scores by M*mu_A, mu_A=grad log a=sum_A p(y)S_y/a. This is E[G | membership, all B paths] and admission event E={0<K<N} is measurable, so same unconditional mean, same conditional admitted mean, same prompt admission Z=1-pi^N-(1-pi)^N; covariance reduction PSD via total covariance. Not full group trajectory preservation after dropping identities, not equal stochastic Adam/gradient clipping/multi-epoch PPO, not variable token denominators. KL/entropy not included.
Exact covariance gain: let C_A=Cov(S|A), conditional removed covariance on mixed group is M*((1-r)/(NL sd))^2*C_A. Conditional on K, M~Bin(K,a/pi). Averaging yields DeltaCov = [a*((1-pi)-(1-pi)^N)/(pi*N*L^2)] C_A. For admitted-only covariance divide by Z, fixed prompt. Thus certificate utility depends on weighted scatter D_A=a*C_A, not just mass. Add a path with mass b, score s; D_{A+y}-D_A=ab/(a+b)*(s-mu_A)(s-mu_A)^T by weighted second moment update. Trace nonnegative, but not submodular: A={score0}, B={score0,score2}, new distinct score0, all equal positive masses, marginal gain 0 on A and positive on B. Greedy has no general approximation guarantee. A singleton removes zero variance. Scores may be costly; choosing via full candidate scores is oracle-ish, not a deployed estimator.
If A is all correct (a=pi), E[S|R=0]=-pi*mu_A/(1-pi), using E[S]=0. Given mixed K, E[G|K]=sqrt(r(1-r))*mu_A/[L*(1-pi)], averaging over Bin(N,pi) (and dividing by Z if admitted) is fully analytic. Thus in the fixed-reference R35 limit, teacher-forcing analytic gradient is stronger than either AR or SD for this restricted expectation contract. Cannot infer same random optimizer trajectories. 
The shared-prefix formal forward position lower bound for this specific algorithm: for paired full trajectories, ideal cache-AR computes unique visited prefix set D. Candidate certificate trie T_A includes every prefix of any A trajectory; candidate uses T_A union visited B prefixes. This set contains D. Hence candidate cannot reduce ideal distinct p-prefix counts if certificate is newly computed, ignoring batch timing/eviction. Already required same-snapshot certificates could reduce *incremental* overhead, but not free generally.

## 3. T: certificate-conditioned endogenous proposal
H_p(h)=P_p(A|h) via exact finite trie; outside trie zero, at terminal 1 for A. w(x)=1-H_p(hx). For feasible prefix with Zp=sum p_x w_x>0, p_B(x|h)=p_x w_x/Zp. qW(x|h)=q_x w_x/Zq, Zq=sum q_x w_x>0, fallback target-only if Zq=0. Contrast raw q and q_B=q_x*(1-H_q(hx))/Q(B|h), where H_q requires q path probabilities; qW reuses p certificate without requiring H_q. q_B may be cheaply obtained from same shallow features during p evaluation, so no guaranteed physical saving. Use standard maximal-coupling SD kernel acceptance min(1,p_B/qW) and positive residual normalized; conditioned autoregressive p_B telescopes to p(.|B), valid causal verification and independent random draws. The sequence guarantee assumes actual conditioned proposal probabilities, bonus/rejection/EOS handling; not implemented here beyond local analytical kernel. Greedy p_B argmax is not necessarily unconstrained p argmax; original output law restored only by mixture, not by claiming constrained greedy equals original. Real top-p/numerics not tested.
Bound TV(p_B,qW) <= [sum_x w_x|p_x-q_x|+|Zp-Zq|]/[2 max(Zp,Zq)] by subtract/add same weighted measure at larger normalizer and triangle inequality. Not guaranteed better than raw q: p=(.5,.5), q=(.75,.25), w=(.75,.25) gives p_B=q, TV(raw)=0 but qW=(.9,.1), TV=.15. Nor guaranteed better than q_B. Conditional acceptance quality not measured time.
