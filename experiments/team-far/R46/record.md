## T: survival minorizer and exact gap
Fixed prefix distribution over a finite calibration set, fixed K, positive softmax probabilities (no truncation), fixed shallow/deep features, parameter vector theta including global/edge/client coordinates. Formal logits and draft logits affine in theta (e.g. tied output W_e applied to fixed y or x, with W_e=W_g+R_e); no simultaneously learned bilinear bridge or full backbone assumption. For each index i=(client/region, starting prefix, nonempty continuation v with length <=K), let w_i>=0 be fixed workload mass, m_i(theta)=w_i product_j min(p_theta(v_j|prefix),q_theta(v_j|prefix)). A(theta)=sum_i m_i(theta) is weighted expected accepted length excluding bonus. Remove zero w_i, assume positive m_i; a reference theta0 defines A0, r_i=m_i(theta0)/A0. Jensen:
log A(theta) >= log A0 + sum_i r_i log[m_i(theta)/m_i(theta0)] = log A0+S(theta).
Exact gap is KL(r || r_theta), r_theta=m(theta)/A(theta). Equality at anchor, gradient tangent where differentiable; at ties use common consistent subgradient. Each log m_i is concave in affine-logit parameterization, because logsoftmax concave, min of two concave functions concave, sums concave. Hence S concave even when both formal and draft tied parameters vary. This is standard log-sum variational identity/MM applied to accepted-prefix mass, not a new general Jensen/EM theorem; VSD is a close conceptual originality threat. Difference: includes *all nonempty accepted prefixes* and actual maximum-coupling factors min(p,q), not an oracle utility filter; jointly updates both p,q and imposes local CE quality constraints. Compare exact formulas in VSD before any publication.

Let L_c(theta) be empirical CE on fixed client guard features; convex under affine logits. Optimize max S(theta) subject to L_c(theta)<=L_c(theta_ref)+eps_c for every client, fixed convex trust radius, optionally per-region S_e>=0. Reference feasible. Any update with S>=0 is certified to not reduce calibration A, and convex combination of candidates feasible for the SAME constraints and anchor is also feasible. Different local constraints or anchors do not guarantee feasible aggregation. Local certificates s_e=sum over local r_i log ratio, a_e=A_e0 (fixed reference masses). Weighted global certificate sum_e a_e S_e / sum_e a_e, where S_e normalized locally; edge sums and cloud sums compose exactly, not simply client-average S_e. Each constraint can be checked locally on final candidate; region can report max violation, cloud max over edges; not a guarantee under missing/changed clients, population risk, or private verification fraud. Same-information flat can reproduce. Algorithm proposal: reference CE HFL update, freeze anchor; local optimization of concave S with local constraints; coordinate shared variables using consensus/dual methods, evaluate FINAL common proposal on every client, commit only if global weighted S>=0 and max guard violation<=0. Exact constrained solve, distributed consensus, dual convergence and physical messages NOT implemented in this round.
Path coefficient at a node h->x is sum of reference masses of every accepted prefix containing this transition, i.e. reference survival mass times downstream expected accepted suffix count plus 1. Thus S can use weighted log min(p,q) by transition rather than enumerate complete paths in M step; constructing weights exact remains exponential for large V,K. With old q and independent standard verification uniforms, all accepted prefixes of one rollout yield an unbiased unnormalized sample of the measure m(theta0); weighted log ratios sum over accepted prefixes estimates A0*S, accepted count estimates A0. Normalized ratio finite-sample biased; a random empirical surrogate does not guarantee true population improvement, need independent validation or bounded concentration. Need verify actual old/new policy snapshots and legal data access, no claim free computation/privacy. Standard exact SD uses actual q and p and residual positive part; induction preserves deployed p sequence, not previous p; greedy formal argmax with tie convention, actual EOS/top-p/FP/batched kernel not run.
Counterexample: with single-token binary p=q-independent? Fixed q uniform, one can choose p close to q with better acceptance and worse CE when label distribution concentrated. Also different local constraint halfspaces e.g. first coordinate <=0 and second <=0, locally feasible (0,2),(2,0) aggregate (1,1) violates both. Thus cannot claim automatic FedAvg protection. Guard finite data not population quality.
