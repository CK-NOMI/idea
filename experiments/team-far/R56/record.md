## T/H architecture and exactness
Client retains private text and causal gate g_c(h) in {0,1} (here region-shared g_e). Cloud owns common shallow transformer + full output head and last FFN-down weights M; edge fits gate utility by pooling logically local feature statistics, clients use gate for formal loss. Actual experiment centrally fits ridge using permitted logical data and one synchronous weighted gradient mean; no physical hierarchy, privacy guarantee or asynchronous optimizer equivalence. Same-information flat can replicate. Fixed gate and model snapshot; q(h)=softmax(Wx(h)+b), d(h)=softmax(W(t(h)+M f(h))+b), formal p_g=(1-g)q+g d. When g=0, p_g=q exactly by definition. This is a NEW FORMAL MODEL; no claim outputs equal original dense d, which must be a quality comparator. Gate is deterministic given causal prefix and fixed snapshot, calculated from shallow state and fixed baseline entropy/max prob; no future labels at inference. Gating rule (with frozen calibration) fixed during gradient updates and rollout. No independent draft LM. Standard SD on p_g: at open query compute true d, accept min(1,p_g(X)/q(X)), otherwise positive residual; closed query accept with probability 1. Greedy use formal argmax and common tie break. Independent uniforms and causal prefix, exact ideal sampling. At a fixed formal target p_g, a predictable stopping rule that decides BEFORE drawing next proposal given existing draft prefix (and independent policy state) whether to stop can vary block length: along accepted path the same decision is available on the realized prefix, so next output law is q_i min(1,p_i/q_i)+delta*(p_i-q_i)_+/delta=p_i for every proposed position; if stop before next proposal, sample from p_g at that prefix as bonus, also exact. Induction over emitted tokens with accepted history/stop state establishes conditional sequence law, under standard causal rejection truncation, fresh random draws, no unaccounted future selection. If gate/stop depends on unobserved next proposal, conditional proposal law may change. Counterexample p=q=Bern(.5), draw X then keep if X=1 else redraw p gives P(output=1)=.75; not a valid predictable policy. Production top-p, EOS, quantization and floating tie edge cases untested; for same deterministic causal processors applied to both routes, the algebra holds for resulting p/q. 
## T: actual last-layer query dependency
For shallow full prefix X=(x_1,...,x_n), final pre-norm block Q_i=W_Q norm(x_i), K_j=W_K norm(x_j), V_j=W_V norm(x_j), t_i=x_i+W_O sum_{j<=i}softmax(Q_i K_j/sqrt(d_h)) V_j, f_i=ReLU(W_up norm(t_i)), y_i=t_i+M f_i. Query row i independent of other FINAL-layer query outputs, so for selected I only Q/O/FFN and output rows i in I need compute; K/V for all ancestors of open queries still required. Closed position deep y_i need not exist. Induction not valid for arbitrary multiple gated layers whose deeper K/V depend on skipped outputs; require explicit architecture or recompute. Training loss at open i still depends on closed j<i through K_j,V_j; scalar uniform-attention example output at i=2 is (W_V x1+W_V x2)/2, derivative w.r.t W_V includes closed x1. Thus cannot infer whole-backbone backward savings from query gate fraction. For actual trained M only, closed path CE has zero M gradient; open gradient dL/dM=(W^T dL/dlogits) f^T; shared output bias b gets exact formal CE and overlap gradients. This is conventional chain rule/conditional computation. No full-backbone gradient assertion.
## T/H joint gate utility and active-query SD
At fixed p_g components, opening root changes expected 2-token survival mass vs closing by Delta_root=sum_i(q_i-min(q_i,d_i))(1+a_i), where a_i=child overlap UNDER FIXED child gate. Opening child i costs m_i TV(d_i,q_i). This is exact for fixed tree, root conditional; no claim global optimal gate in shared function class. To balance formal CE gain log(d(label)/q(label)) and SD cost, ridge target gain-beta Delta_root; actual training calibration assumes all child gates open, so this is a proxy, not true coupled optimal score. Fixed threshold calibrated on independent-by-name split. Compare entropy, global CE, regional CE, regional single-step TV, regional window, local window, always full/shallow. Formal objective CE(p_g)+beta*g*(1-overlap(d,q)); train shared M and b, freeze gate; all arms beta=.3, not an end-to-end gate gradient or exact K2 objective. SD likelihood feedback to gate simulated via exact enumerated child probabilities, obtainable with ordinary teacher forcing, not exclusive SD signal.
Active-query budget policy: while drafting, extend over closed positions even after B open draft queries, stop BEFORE next open once B exhausted or reach max token cap; verify open rows only; bonus may add ONE open query beyond draft budget. Exact same p_g, no new formal model across decoding policy arms. Alternative direct closed positions before first open (active2start). On a GPU, active rows could form a ragged verification batch with shared prefix K/V, no need closed query rows; actual JS computes open rows serially. Count distinct cached shallow/deep prefix calls per request, recomputed last-layer K/V rows and conceptual active-block launches. No actual GPU kernel batching or latency.
