## T: scoped KV-boundary rematerialization
Fixed causal dense transformer snapshot, deterministic operators, fixed generated path and stop-gradient reward coefficients. At a node v, local map F_theta(token, ancestor KV) outputs logits and local layer KV. Keep ancestor K/V numerical values, recreate local VJP tape independently without recursive recomputation of ancestor features. Reverse descending prefix length; sum incoming adjoints to each boundary K/V from all dependent local maps, including transitive effects through descendants; local VJP consumes logit adjoint and summed KV adjoints, emits parameter contribution and adjoints to ancestor boundaries. Chain rule yields same full parameter gradient as ordinary teacher forcing, not simply detach cached KV. No claim for stale versions, cross-sample coupling, dropout without replay, MoE capacity, precision or training after optimizer update. Ordinary AR and existing PrefixFlow/Tree Training/checkpointing can implement; AD principle not new. If all scored committed nodes are present in verifier, storing full tape saves one training forward per unique committed node compared with replay, but AR can retain identical nodes without rejected extras. Retaining only KV for every committed ancestor permits rematerialization per evicted node once for the reverse sweep; model weights fixed. Retention cost additive only under fixed per-node numerical payload/known ancestor KV and no runtime effects; offline selection resembles knapsack, not a new optimizer. Online heuristic retain deepest first with fixed cap, prune non-live speculative states at each block boundary; no optimality claimed. Coupled repair can change occupancy/sync patterns but cannot improve exact same-output gradient by itself; same delegated flat can replicate.
