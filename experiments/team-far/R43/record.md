## 1. Model and learning contract
Two equal-weight regions with distinct personalized formal distributions p_e(.|h), same vocabulary and frozen causal backbone, region formal output matrices W_e=W_g+R_e, R_1+R_2=0; shared shallow prediction matrix U on the same backbone, q(.|h)=softmax(U x(h)), formal p_e=softmax(W_e y(h)). No independent draft LM. Fixed region identity and target version for each request. The shared q is a distribution, not shared random draws. Shared calibration prompts and region p statistics require actual legal access; no privacy guarantee. Different regional formal models are part of the proposed learning architecture; not exact replacement of original pretrained teacher. Independent regional shallow heads with same backbone are essential controls.
At each actual proposal use real q, ratio min(1,p_e/q), positive residual, first-rejection truncation; independent random draws and legitimate bonus/EOS, causal history. In real arithmetic conditional induction preserves the deployed p_e sequence law, irrespective of how q learned. Greedy requires formal p_e argmax with fixed ties; no production top-p/FP/greedy/actual generation or batch kernel implemented here.
Two-token expected accepted length (EAL, no bonus) at common h:
A_e(q)=sum_x min(p_e(x),q(x)) [1+sum_y min(p_e(y|hx),q(y|hx))].
This is standard sequential max-coupling, not new on its own. HFL gives region personalized p_e and common q; SD's survival objective influences both q and W_e. Region outputs can differ, and shared q parameter constraint may be undesirable.

## 2. T: exact two-region two-token common-proposal frontier
For equal weights, denote m_x=min(p_1(x),p_2(x)), M_x=max, D_x=TV(p_1(.|hx),p_2(.|hx)), and a_x=.5 min(p_1(x),q(x)), b_x=.5 min(p_2(x),q(x)).
Given q root, conditional next-step objective = (a_x+b_x)-[a_x TV(p_1x,q_x)+b_x TV(p_2x,q_x)]. By triangle inequality weighted TV cost >=min(a_x,b_x) D_x, attained by choosing q_x equal to the formal distribution with greater surviving weight (tie any convex mixture). Zero mass branches arbitrary. Therefore optimal continuation gives root contribution f_x(s)=min(p_1(x),s)+min(p_2(x),s)-.5 D_x min(m_x,s), s=q(x).
For s<m_x slope 2-.5 D_x>=1.5; m_x<s<M_x slope1; above M_x slope0. Thus any s* in [m_x,M_x] maximizes f_x(s)-s over s>=0, and q*=(p_1+p_2)/2 is feasible with sum1, proving global optimum. All root q in pointwise intervals and normalized achieve optimum with optimal continuations. This yields exact closed form
A*_common = 2-TV(p_1,p_2)-.5 sum_x m_x D_x.
It is a bound on ANY single shared autoregressive q distribution, independent of neural capacity. It is attainable in unrestricted probability space but generally NOT by a cheap shared shallow head, since oracle requires all target probabilities and branch-specific region choices. At fixed q0, equal conditional averaging loses .5 sum_x |a_x-b_x| D_x versus optimal continuation. Distinguish from FLPV: there fixed single p and region q mixture with latent posterior; here distinct p_e and one shared q, survival weights across formal targets, no hidden region in actual request. R40 one-step TV triangle bound is direct antecedent. Not claiming elementary triangle or piecewise optimization new. Unequal region weights, >2 regions, deeper windows, parameter sharing constraints are not covered by closed form. For 2 equal regions, oracle root mixture suffices; gain is conditional routing, not need for novel root fusion.
If region-specific q allowed, unrestricted q_e=p_e gives EAL2, so common architecture always has disadvantage when targets differ. Concrete impossibility: if bound < measured independent shallow-head EAL, NO common q can beat it under this exact metric and evaluation distribution. This holds for two equal regions and common prompts, not arbitrary region-specific prompt distributions or latency. Shared parameter q can still be conditioned on region ID, but then is not common q(.|h); that's a different architecture and strong baseline.

## 3. H/T: actual two-way learning proposal
Let L_e=CE_e(W_g+R_e)-beta E_{h~cal} A_e(q,p_e), with U fixed during formal step; q updated separately on fixed teachers, e.g. joint EAL or survival-target distillation. Region CE gradients average its two clients, and authorized public calibration probability gradients evaluated per region. g_e=grad L_e, gbar=(g_1+g_2)/2. Cloud W_g <- W_g-eta_g gbar; regions R_e <- R_e-eta_r(g_e-gbar); zero-sum residual invariant by construction. This is ordinary multi-task reparameterization/projected gradient, not a novel federated optimizer; same-info delegated flat can reproduce. SD objective explicitly changes formal model update, HFL learned p_e changes survival weights and q training. No claim that actual stochastic rejection feedback or physical HFL required: exact EAL can be computed by teacher forcing and ordinary shared/individual KD/acceptance-aware training can implement same objective. The auxiliary objective can cause formal model collapse (p_e=q uniform gives EAL2 with degraded task performance). Strong quality constraint needed; NLL tests not matched quality or long-term convergence.
For q approximation: root distill mean p; child choose p_e with greater a_x,b_x computed from current q root, or mean for ties; weight child CE by a_x+b_x; detach these choices/weights. This is heuristic imitation of full-probability oracle, not exact optimizing neural EAL. Exact EAL gradients through softmax and min (zero subgradient at ties) available; root derivative in region e (1+A_child)1{q(x)<p_e(x)}, child derivative min(p_e(x),q(x))1{q(y|hx)<p_e(y|hx)}. Symmetric p gradients for fixed q; chosen subgradient at ties. Full window enumeration O(V²) per prefix, dense p/q next rows; not practical at V128k without valid approximation, and region data sharing / sufficient statistics not solved. EAL and WTV training known; specific exact multi-target bound is incremental math, not an original full architecture.
