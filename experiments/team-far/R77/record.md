## T: schedule and exact cache contract
Split standard causal model into shallow parameters theta_s (embedding, position, first layer) and deep parameters theta_d (second layer and shared output head). Shallow cache is post-layer-1 features and its KV, keyed by exact shallow parameter version, prompt, position and causal input. Changes to theta_d preserve shallow values by DAG dependency; q and p logits must be freshly evaluated under current W, and deeper states recomputed. No stale draft sample reuse; random drafts sampled fresh. Fixed deterministic operators, same version per request, positive allowed support. AR uses same exact cache contract. Ordinary LayerSkip + FedPart/partial coordinate updates and version-aware cache is a strong baseline, not a new foundational invariant.
For a set of scheduled shallow-update events S_c across clients, an aggregate's potential shallow invalidation support is union_c S_c (actual cancellations can reduce it). For fixed event counts m_c, min union size=max m_c by nesting events in a common calendar; independent staggered schedules can invalidate each event. At edge/cloud rebase, ancestor versions may invalidate caches even when local shallow updates are disabled. This is event-count property, not a cache hit or runtime guarantee. 
Deferred shallow phase: all clients at common shallow/deep snapshot theta, two local cycles each with two edges and two equal-weight clients. Do not apply shallow gradient during regional cycles; accumulate all shallow deltas and apply once at cloud. Deep is fixed during this phase in current prototype; in deep phase ordinary local deep SGD and edge/cloud means. Full parameter space eligible across alternating phases, but optimization trajectory differs from local block SGD. If first edge gradient g_e1 and second g_e2 are L_e-Lipschitz within that block, exact two-cycle normal edge updates averaged at cloud versus deferred using same batches at theta differ by at most eta^2/2 sum_e L_e||g_e1(theta)|| (two equal edges, assuming deep fixed), by triangle and Lipschitz; nonzero in general, not convergence guarantee. Phase order and sample heterogeneity matter. No claim this is exact original optimizer, no permanent freeze, no secure aggregation or actual RPC.
