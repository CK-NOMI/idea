## T/H: exact dependency contract
Causal shared spine x_i=F_theta(h_<=i), first refinement a_i=R1(x_i; x_<=i), write bit w_i and read depth r_i in {0,1,2}, both deterministic functions of available causal shallow state/region snapshot. Historical bank z_i=(1-w_i)x_i+w_i a_i; second refinement b_i=R2(a_i; z_<=i). Final feature y_i=x_i if r_i=0, a_i if r_i=1, b_i if r_i=2; p_i=softmax(W y_i) (implementation scales second correction and adds shared bias), draft q_i=softmax(W x_i). Closed r=0 has p=q under same head/processors. No independent full draft LM. First refinement reads x, not its own writes, so causal DAG acyclic. For requested output index set I, let J={i in I:r_i=2}, L=max J or -1. Sufficient first-stage ancestor set U={i in I:r_i>=1} union {j<=L:w_j=1}. Compute a only on U, b only on J. Other a cannot affect chosen outputs by DAG. Structural closure is minimal for an execution restricted to this graph if every listed dependency must be materialized, excluding accidental cancellation, alternative algebra, existing cached nodes and special sparse attention. Ordinary arbitrary deep causal Transformer doesn't satisfy this read/write separation. If a_j computed on closed historical position, its gradient may be nonzero from later reads even when own loss has zero derivative wrt a_j. For differentiable fixed gates, exact gradient of any selected losses under closure is identical to dense evaluation of SAME routed architecture by chain rule; not gradient of hard gate, or full pretrained target. Example scalar a_1=theta*x_1, z_1=a_1, b_2=z_1+z_2, r_1=0, r_2=2, w_1=1: d b_2/dtheta=x_1, so ignoring closed token 1 corrupts training. For fixed read indices and writes, cost of materializing a is |U|, not number of open outputs; incremental caching charges only new U. Full-write with any second read at last index may need every prior first refinement. Read-only w=0 restores independent cross-decoder queries, already YOCO-like. Generalization to arbitrary DAG reverse reachability is classical not new. 
Standard exact SD for fixed routed target, actual q, causal first rejection truncation, independent uniforms min(1,p/q) and positive residual, exact bonus and same deterministic processors gives token and sequence law. Greedy same formal argmax and tie break. Gate decision before current token draw; version/cache keys include fixed snapshot, prefix and gating policy. No production FP/top-p/EOS test. Same-info flat and AR can use all closure/cache benefits. No causal reverse SD-to-HFL necessity. Proposed future writer selection marginal utility from downstream reads weighted by survival, not executed.
