## T: group complete formal state, not approximate gradients
Fixed snapshot theta, complete anchor M and DMC coarse class history S, deterministic representative sequence and legal causal graph F_theta(M,S). Private raw history differs but class branch independent of fine history; fine decoder uses disjoint parameters in the theorem. For fixed loss weights a_i (may be signed detached advantages) and same state, sum_i a_i J_F^T dL_i/dz = J_F^T sum_i a_i dL_i/dz. Shared entire graph and complete loss ancestors required; equal activations alone do not imply equal Jacobians; stochastic masks, version, state-dependent expert capacity, raw-dependent attention, processors, optimizer state, positional IDs can invalidate grouping. Standard reverse mode linearity; Tree Training and PrefixFlow already aggregate prefix adjoints, not a new AD theorem. Novel candidate scope is larger shared state equivalence classes by modifying DMC formal model rather than ordinary raw-prefix sharing. For class c=g(y), formal logits l=W(z0+Delta f), raw softmax p over V, P_c=sum_{g(v)=c}p_v, grouped class score weights C_c=sum_i a_i 1{c_i=c}, A=sum_c C_c. Weighted negative log-likelihood L=-sum_c C_c log P_c, dL/dl_v=p_v(A-C_{g(v)}/P_{g(v)}); for positive REINFORCE gradient reverse sign. Exact last FFN projection derivative (W^T dL/dl) f^T. Fixed selected labels/advantages, not full GRPO clipping/multistep Adam equivalence or score from stale snapshot. Group counts additive through tree. Shared frozen anchor, g, representatives, same theta and authorized group IDs/counts necessary; count messages may reveal private prefixes or rewards, no DP or secure aggregation implemented. If clients independently update theta, not valid to aggregate nonlinear gradients as if same snapshot. Need one synchronous update or snapshot-specific keys. HFL local inner steps cannot silently be replaced by same-snapshot global gradient; this round exact synchronous one-update primitive only. 
For a fixed set of official output paths, raw-prefix baseline counts distinct actual raw states, class AR baseline counts distinct committed coarse states U. SD verifies a superset V of U including rejected/bonus candidates. With ideal exact cache AR has no more unique formal rows than SD, and both can retain equivalent VJP assets for learning. SD may reduce serial rounds, not total unique formal computation. Need compare matched optimized class AR+Tree Training, optimized factorized token SD (R66 equivalence), delegated flat same state statistics. No general HFL necessity. B4 class SD uses actual p/q, min(1,p/q), positive residual, legal block-boundary bonus and actual fine history emissions, fixed horizon no EOS; exactness relative to new formal factorization, not original dense teacher. Greedy/raw top-p/temperature/finite precision production not tested.
