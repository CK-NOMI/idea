## T: avoid the entire count graph
Let independent labeled drafts X~Q=prod_i q_i, formal target P=prod_i p_i, with fixed positive categorical probabilities and versions conditional on full causal history. Base independent maximal coupling gives flow J(x,y)=Q(x)prod_i T_i(x_i,y_i); each changed coordinate moves once from a q_i>p_i donor to p_i>q_i recipient, hence offdiag graph acyclic (rank number of recipient positions). Diagonal D(z)=prod_i min(p_i(z_i),q_i(z_i)); outgoing O=Q-D, incoming I=P-D. At initial x keep with min(1,P/Q); otherwise follow J(x,.) conditioned on nonidentity. At arrival z stop with (P-Q)_+/(P-D), otherwise follow conditional outgoing again. Conservation: residual starts (Q-P)+; incoming path mass I by topological induction; arrival stops (P-Q)+, continuing I-(P-Q)+=min(I,O); plus starts =O. Thus each edge used with original mass J, each output has P exactly, joint equality sum min(P,Q), and each changed lane stays changed (no double moves), so E #changes=sum_i TV(p_i,q_i). For homogeneous p,q, count likelihood ratio equals labeled likelihood ratio, no cancellations, so equality is also optimal histogram equality and expected new occupied categories reaches R69 lower bound. Direct labels preserve independence without assignment. Heterogeneous p_i,q_i extension is for exact labeled product and minimal lane moves only, not count equality or occupancy lower bound. Must not group for compute reuse without identical causal graph/version.
Expected hops =sum_{x!=y}J=1-prod_i(1-TV_i)<=1; worst-case <=N; conditional on initial reject expected hops=(1-A_ind)/(1-A_group). To draw nonidentity without rejection loop choose first changed slot j with mass (prod_{k<j} a_k)(1-a_j), a_i=min(1,p_i/q_i); subsequent slots independent ordinary max coupling, residual categorical precomputed. Homogeneous preprocessing O(K), CDF binary-search per repaired slot O(log K), expected total repair count N TV, expected O(N+K+N TV log K), worst O(N^2+K+N log K), memory O(N+K); alias O(1) optional not implemented. Log ratios stable in positive support; exact real arithmetic claim only.

## T/H: direct new federated learning objective
Fixed target p_i, endogenous shallow q_i(phi_i). Group loss L=1-sum_x min(P(x),Q_phi(x)). Off ties, gradient wrt local phi_e is -E_Q[1{log P-log Q>0} sum_{i in e} grad log q_i(x_i)]. At ties use a subgradient or smooth surrogate. Edge aggregates scalar likelihood ratios, broadcasts gate, clients compute local score gradient; target held fixed in draft update. Add per-lane TV penalty, local compute regularization and fixed exposed repair cost B_e; use independent sampling and causally frozen cohort; no changed formal target. HFL can train shared endogenous head plus local adapters under these group-aware objectives. Sum scores must match parameter ownership and aggregation weights; private logits/token visibility and leakage need protocol audit. This is a proposed objective, not demonstrated learning convergence or necessary HFL advantage; flat with same delegation can reproduce it. ## Multistep and HFL
Conditional product theorem can be applied afresh at each token frontier, with p_i,q_i depending on actual committed histories and no future proposal/reward lookahead; induction yields full target joint sequence law for fixed horizon, not an implementation of asynchronous block speculative decoding or production greedy/top-p/FP. Precomputed suffix reusable only when causal state matches and selection ignores suffix RNG; discarded wrong-prefix proposals must regenerate. Heterogeneous distributed extension can reduce scalar log ratios across hierarchy and draw first changed region conditional on nonidentity using region product of a_i, then local first change; no need to transmit full probability vectors if target distributions available locally. Requires repeated exposed round trips if cross-region, no free communication. Local region cohorts likely better than global when WAN latency high. No proof that group acceptance corresponds to useful real barrier cost: optimized independent SD can batch repair instructions, direct AR can avoid speculation, flat delegated compute can reproduce.
Cost condition for an exposed fixed repair cost B and added kernel cost H: H<B(A_group-A_ind). End-to-end requires total time ratio <=.85 or useful work >=1.20 at same cost with CI. No measurement.
