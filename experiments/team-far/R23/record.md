## 1. Formal problem and scope
Fixed causal Transformer snapshot and original softmax p, own shallow exit q, standard maximal-coupling SD (draw X~q; accept with min(1,p_X/q_X); otherwise residual (p-q)_+/TV, discard suffix). Candidate length K. A first rejection at row j requires j prediction rows (the rejection row is required for corrected output). Define L=min(first rejection position,K), i.e. reached prediction rows, not count of accepted draft tokens. When all K accepted, a separate standard bonus row is normally needed, excluded from current experiment and optimization. Fixed frozen W/backbone and rank-k additive policy adapter T, A_i=T^T w_i; for fixed committed path reward R and snapshot, each score is A_y-mu_p with mu_p=sum_i p_i A_i. An exact compact checkpoint is mu_p (k scalars) at a prediction row; after Y/reward known compute A_y-mu_p and multiply fixed reward coefficient. This is only for this restricted adapter, not full parameter gradient or nonlinear PPO multi-epoch updates. All prefix rows must have correct causal history, same version/no stochastic ops. No early parameter commits; rejected suffix discarded. Holding all complete p in audit is not memory-efficient; actual script stores p for correctness checking, not a physical memory reduction.
Assume a fixed cohort of independent verifier blocks, each has a shared prefix length H. During verification a fixed-capacity retention budget B equal-sized slots across blocks must be chosen BEFORE acceptance random draws, because of hypothetical retention constraints. A saved row does not need to replay its moment. If any missing reached rows exist, one causally batched teacher-forcing replay to longest missing prefix provides all of them; if no missing row then zero replay. This cost model is stronger than separately replaying every missing row, but still assumes no other retained KV/checkpoints allow cheaper replay; ordinary optimized training may be much cheaper. Bonus, generation, draft, moment computation, optimizer, communication and storage writes cost extra. Real necessity of precommit storage constraint NOT demonstrated. Alternative postcommit decision can dominate if all candidate moments can transiently be retained until acceptance, which is likely for rank-k small state.
## 2. T: exact per-block frontier
Let S subset {1,...,K} retained rows, M(L,S)=max({j<=L:j not in S} union {0}). For known context-conditioned law p_l=Pr(L=l), nondecreasing replay cost F(0)=0, expected cost J(S)=sum_l p_l F(M(l,S)). At equal slot budget b, C(b)=min_{|S|=b} J(S). For missing sorted indices j1<...<jm with m=K-b, add sentinels j0=0, j_{m+1}=K+1. Let cumulative P(t)=Pr(L<=t). Then J=sum_{a=1}^m F(j_a)[P(j_{a+1}-1)-P(j_a-1)]. This partitions L by the last missing index; no independence of per-position reach is assumed. DAG edge i->j for i<j weighted F(i)[P(j-1)-P(i-1)], start edge weight0. Shortest path with exactly m interior vertices yields C(b); DP D_{t,j}=min_{i<j}(D_{t-1,i}+w(i,j)), D_{1,j}=0, final edge to K+1. Fixed m O(m K²) and all budgets O(K³) time O(K) rolling values, O(K²) backpointers for schedule reconstruction. Current frontier_probe implements values, main actual trace chooses masks by enumeration K6. Same math holds for arbitrary law, no general Transformer memory graph optimality. For additive per-row unit replay cost, J=sum_{j notin S} Pr(L>=j), so retaining first b is optimal locally; a new mechanism needs non-additive replay dependencies. Conditional known full draft and fixed q/p: Pr(L=j)=prod_{a<j}alpha_a(1-alpha_j) for j<K, Pr(L=K)=prod_{a<K}alpha_a, alpha_a=min(1,p_{x_a}/q_{x_a}). This is an oracle if exact p not yet available at allocation, does not include the last acceptance bit.
## 3. T: hierarchy, complementarity, strongest replacement
Given block frontiers C_i, region aggregates via min-plus convolution: C_R(b)=min_{sum b_i=b} sum C_i(b_i). Cloud merges C_R similarly. Associative exactly (min over all feasible allocations); backtrack regional local choices. Only B+1 values per region for a common equal slot budget; if B is huge or per-device physical capacity, offloading not free and cap-specific frontier required. This is classical resource-allocation DP, not proof of a hierarchical advantage: a same-information flat coordinator with identical regional delegation executes it exactly. No privacy guarantee.
Marginal savings may increase, so per-slot greedy can fail. Deterministic L=2 for two blocks, A:F(1)=100,F(2)=101, B:F(1)=1,F(2)=3. Retaining one row optimally saves 1 vs2, so greedy first allocates B; second saves at most1, total3. Allocating both slots to A saves101. This counterexample is within stated prefix replay cost, not general GPU time.
Postcommit: after L known, an optimal b-slot plan retains last min(b,L) reached rows, leaving longest missing max(L-b,0), cost F(max(L-b,0)). Proof: if b<L, at least L-b rows missing, their maximum >=L-b, attained by retaining suffix. Across cohort choose b_i via min-plus. With identical persistent capacity B and FREE transient availability of moments until commitment, postcommit dominates every precommit plan pointwise, as postcommit can choose precommit mask restricted to actual L. For additive unit costs it retains any useful rows. Precommit only useful if genuine predecision memory bottleneck prevents postcommit; no such evidence here. AR knows each generated row when it commits, can directly store score at same version; cannot infer SD advantage from precommit savings alone. Standard SD+batch teacher forcing/PrefixFlow/Checkmate/DTR strongest fair baselines. No claim same whole SD multi-token latency as AR.
