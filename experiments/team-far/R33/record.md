## 1. Question, scope, antecedent
Can a trainable shared vocabulary tree enable exact token-level max coupling without dense head evaluation, while training via sparse node paths? Fixed causal prefix and snapshot; formal p and endogenous shallow q both use same vocabulary/tree topology, possibly distinct output-node weights, no independent full draft LLM. Replacing flat pretrained softmax with fitted hierarchical logistic head defines a NEW target, not lossless acceleration of original pretrained target. Teacher-induced oracle tree masses in experiment preserve original p/q but need dense probabilities unless actual branch oracle supplied; fitted binary heads actually factorize. A/R07 already proved path-by-path conditional max coupling has lower/equal token diagonal than global coupling; do not repeat as new. R18/R20 residual envelopes direct internal antecedents. New direction: maintain leaf max coupling and exact residual through progressively tightened tree envelopes. No assertion that HFL is necessary; authorized scalar summaries and sparse rows may be shared but reveal data, no privacy guarantee.

## 2. T: output head and exact training
For internal node u, branch probabilities sigma(w_u^T h),1-sigma(...); p(x) product along path. For fixed observed label x, NLL sum of binary cross-entropies along path, gradient at u visited is (sigma(w_u^T h)-branch(x,u))h, unvisited head row gradient zero. Upstream gradients sum path contributions; no claim sparse backbone gradient. For shared common snapshot, one supervised gradient step and fixed client weights, sparse node sums compose exactly via regional addition, missing rows zero (not average by active clients); optimizer applied once globally. Multi-local-step FedAvg requires appropriate common aggregation semantics, sparse Adam momentum/weight decay cannot be skipped automatically, node indices/leaves disclose participation. Communication potentially proportional to union of active rows, dense batch union may fill entire tree; head rows O(depth*d) per sample vs V*d for flat CE, not measured FLOPs or GPU. Dense teacher distillation trains all internal nodes by teacher mass, not sparse hard-label training; our actual fit uses dense teacher distillation and is NOT HFL. Plain hierarchical AR gets same sparse head training/inference advantage; no G2 from this fact.

## 3. T: exact leaf acceptance and adaptive residual frontier
Given original X~q, evaluate p(X),q(X) along path and accept min(1,p(X)/q(X)). Diagonal mass min(p,q) globally optimal for token agreement; not local path max coupling. On rejection sample r(x)=(p(x)-q(x))_+/delta, delta=TV(p,q)>0. Plain exact residual rejection from p using g(x)=(1-q(x)/p(x))_+, conditional acceptance delta; if T is number residual proposals, P(T>t)=delta(1-delta)^t for integer t>=0 (T=0 on initial accept); E T=1 for delta>0 and Var T=2(1-delta)/delta. Tail can be arbitrarily long at high overlap; not time unless constant per proposal.
Frontier partition of vocabulary into disjoint unknown subtrees u plus evaluated singleton leaves. At unknown subtree assign envelope e(x)=p(x)gbar_u with gbar_u>=max_{x in u}g(x), known singleton exact e(x)=p(x)g(x). Initially gbar=1, reveal rejected X (g=0) and cache branch probabilities. Draw piece with weight p(u)gbar_u; inside draw p(.|u); accept with g(x)/gbar_u. If rejected, split sampled path to singleton and siblings, retain exact positive residual on evaluated singleton, tighten new subtree bounds and inherit old upper bounds. Known positive singleton accepted immediately. Do NOT remove an evaluated positive-residual leaf entirely after a failed draw, which would bias. For any adaptive history of previous failures, conditional probability of next accepted x is proportional to p(x)g(x), so exact output law by summing over stopping times. Failure at an unevaluated leaf reveals a distinct leaf; at most V-1 additional unseen leaves after initial rejected X and one exact draw, hence <=V residual trials (excluding optional deterministic fallback) and at most V-1 distinct branch queries per p or q if cache retained. Memory worst O(V), per-context cache local. A cap with exact dense residual fallback preserves law; cap then ordinary p would bias. Standard causal block induction with same actual processed p/q, stop at first rejection, valid continuation and bonus/EOS; actual MC only one step, greedy argmax requires exact search/full scan, not tested; arbitrary global top-k/p processing can defeat sparse head and is not covered. Real arithmetic, no production precision certification. Adaptive weighted rejection sampling COLM2025 direct antecedent; not new generic rejection principle.

## 4. T: certified learned-head residual bound
For node u, formal logit w_u^p^T h, shallow w_u^q^T s. Log-sigmoid for each branch is 1-Lipschitz (clamping used in code also nonexpansive). Thus |log q(b|u)-log p(b|u)| <= |(w_u^p)^T(h-s)+(w_u^p-w_u^q)^T s|. Precompute componentwise maximum path sums M_u^p[j]=|w_u^p[j]|+max(M_L^p[j],M_R^p[j]), similarly M_u^delta[j] for absolute difference weights; leaves zero. B_u=dot(M_u^p,abs(h-s))+dot(M_u^delta,abs(s)) bounds all descendant log-ratio magnitudes, possibly loose due component maxima from different paths. For x within u:
q(x)/p(x)>=q(u)/p(u)*exp(-B_u), so gbar_u=max(0,1-(q(u)/p(u))*exp(-B_u).
Use min with parent bound; exact known leaves. This ties certificate computation to trained weight structure, not evidence of learning gain; shared-weight special case removes second term, not evaluated. Bound table build O(Vd), store two vectors per internal node; per evaluated certificate two d-dimensional dots plus exp, actual probability path computation and frontier bookkeeping extra. Can be built after aggregate snapshot updates but maintenance/broadcast costs count. Regularizing norm paths may change formal quality, not tested. Oracle tight bound max g over all descendants measured only as diagnostic, not free. Near p=q bounds may be loose even when exact residual tiny. No guarantee of speed.
