## Architecture and T
4 client personalized formal heads W_c, 2 sibling regions, common frozen Transformer. Decompose W_c=W_g+R_g+C_c using means and centered residuals, no independent drafter. Define proposal head by inherited formal parameters: U_g=mean of sibling W_c, U_c=W_c. Root uses U_g; at subsequent position hx deterministic gate selects at most one region to split to its own W_c (or none); other region still U_g. Gate is a table of V token IDs fitted from summed calibration terminal EAL gains across client-local starting contexts, not a context-specific gate or expensive head bank. Fixed gate in joint training; no extra independent trained draft matrices; group means can be materialized and stored or derived. Formal logits p=softmax(W_c y); q=softmax(U_route x). Full local baseline always uses W_c at shallow and deep, same trainable head count, no independent draft and no group means/table. No claim active groups imply actual compute parity or saving.
T1: U_g linear logit pooling equals normalized geometric mean of local shallow distributions, not arithmetic mean; no general EAL dominance. Example binary local q1=(.9,.1), q2=(.1,.9), formal p1=q1,p2=q2. Shared U gives q=(.5,.5), mean one-step acceptance .6 vs local 1; if p1=p2=(.5,.5) instead, shared acceptance 1 vs local .6. Thus neither dominates in general. Any fixed gate is affine in W_c, and R46 log accepted-prefix minorizer remains concave. For node with sharing group G and proposal logits z=mean_j W_j x, each sibling receives (1/|G|) dA/dz x^T (or corresponding minorizer). Formal gradient only to its target client. This is chain rule, not a novel gradient theorem; ignoring cross-client contributions is generally incorrect. Region can sum shared proposal adjoints and distribute equally, plus each client's local formal/private proposal adjoints, then hierarchical mean/residual update. No extra raw samples necessarily sent if each client has legal inherited head, but actual communication/storage and version protocols untested. Flat same-information can reproduce. Gate changes invalidate fixed-reference concavity across policies; freeze gate per subproblem, require a new common anchor after a gate change and evaluate total objective rather than treating arbitrary gate switches as monotone.
T2 conditional per-block cost threshold (P, not actual measured time): with fixed K, no EOS and bonus/correction, expected committed tokens at given start =1+EAL. For common fixed start workload, ratio of cost per expected token of shared scheme and local baseline is (C_s/C_l)(1+A_l)/(1+A_s), if C denotes mean total block cost (including routing/verification/network). Break-even requires C_s/C_l <(1+A_s)/(1+A_l). To save 15% block cost per output token, ratio <=.85*(1+A_s)/(1+A_l). Not a universal end-to-end claim: actual start distribution changes; training and other cost must be included.
