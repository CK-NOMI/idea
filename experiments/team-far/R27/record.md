## 1. Contract and formal problem
Fixed contexts h_i and fixed precommit state F, old self-draft q_i using first layer, old and candidate formal snapshots p_i^0,p_i^1 (same trunk/W, one proposed shared additive hidden bias step). The N old draft blocks are drawn independently conditional F. First draft X_i~q_i; local binary vote B_i=b_i(X_i) (e.g. whether candidate formal p_i^1(X_i)>p_i^0(X_i)). Cloud chooses model version v=1{sum B_i>=T}; alternative published statistic is count C=sum B_i, with same v. This is a constructed hypothetical gate, NOT measured production HFL practice, nor proven reliable model-selection criterion. Fix selected v for all output blocks. Contract: conditional on F and authorized public selection transcript J (v or C), joint law of complete formal outputs is independent product of selected target causal kernels. This is stronger than merely unconditional mixture of snapshots, weaker than conditional on all draft/vote history. Not a privacy guarantee; version/count may leak information; if additional public decisions/timing reveal votes then must condition on that information as well. If original contract fixes an external version independent of all drafts, ordinary stale-q SD can remain exact with correct actual q; no universal flaw in async SD.
## 2. T: posterior proposal and exact verification
Let a_i=Pr_qi(B_i=1), S_i=sum_{j<i}B_j. For selection likelihood e(c,J)=Pr(J|total=c) (deterministic indicator in first version), define L_i(s,J)=sum_l Pr(sum_{j>i}B_j=l) e(s+l,J). Given preceding draft candidates X_<i and J, actual proposal is q_i^J(x|X_<i)=q_i(x)L_i(S_i+b_i(x),J)/[(1-a_i)L_i(S_i,J)+a_i L_i(S_i+1,J)]. Positive probability histories only. This is Bayes/conditional Bernoulli (Doob conditioning), not novel basic sampling theorem. Suffix Poisson-binomial mass polynomial product Π[(1-a_j)+a_j z]. Each regional polynomial can be multiplied into global; exact prefix/suffix counts via DP, no physical hierarchy exclusivity. O(N²) scalar DP time/storage for all suffix rows, O(N) direct sequential state evaluation for known threshold with CDF lookup after precompute, O(NV) posterior materialization or two class weights per position with ordinary p/q residual machinery. Communication depends on transcript/disclosure and local access; scalar a_i not intrinsically private. General nonlinear gradient-dependent model selection may require inaccessible joint likelihood, no polynomial claim.
Use standard max-coupling verification of actual conditioned q_i^J against p_i^v, fresh independent verifier RNG; reject residual (p_i^v-q_i^J)_+. Conditional output law p_i^v by identity. Conditional on all preceding draft and validation history and J, next first proposal law remains q_i^J because prior validation uses only previous draft and fixed J (not future drafts); hence by iterated conditioning joint output product. If selection depends only on FIRST draft token per block, remaining draft conditional given that token is unchanged. Standard causal verification for suffix with same original conditional q_i and first-reject truncation; continue on actual corrected prefix with fresh randomness if requesting fixed complete sequence, bonus when appropriate. Proof requires no future-dependent validation or additional unrevealed selection information used as random decision. Full fixed-length sequences, greedy, EOS, top-p and production precision not executed. Greedy target argmax at selected snapshot still correct by exact target checks, no sampling-law issue. If public knows full votes, conditioned q_i reduces to restricted q_i on B_i; if full candidate public, conditional proposal point mass. Contract never promises conditional output independence of entire candidate transcript unless conditioned on it.
Incorrect naive reuse: if one uses q_i instead of actual q_i^J, even correct p_i^v can yield biased conditional output and across-client dependence. Simple counterexample q=p^0=p^1=(.5,.5), version equals X in binary case, naive acceptance1 gives Y=X, so conditional TV=.5 from uniform even though target probabilities match. Correct posterior point mass and residual recover uniform; fresh draw also works.
Disclosure monotonicity T: if J2 reveals J1 and more, and selected p fixed given J1, posterior q1=E[q2|J1] (also condition same prior candidates). Convexity TV gives E overlap(q2,p)<=E overlap(q1,p). Not monotonic for realized individual events, nor claim privacy. Exact aggregate count compared with threshold; full votes more information still. Same physical flat coordinator with same delegated summary and disclosure performs identical polynomial and verification. Strong replacements: fresh self-SD after selection, independent pre-draft randomness not used for commit, exact direct AR at selected p, and target-first point-mass verification. No need to invent HFL dual necessity.

## 4. T and E (synthetic): soft commit gate
Let pi=Pr(S>=T), define Pr(V=1|S=s)=lambda*1{s>=T}+(1-lambda)*pi. Marginal Pr(V=1)=pi for all lambda. Agreement with original deterministic gate = lambda+(1-lambda)(pi²+(1-pi)²). Mutual information I(V;X)=H(pi)-E H(Pr(V=1|S)) (natural logs). Same posterior formula with stochastic event likelihood, verifier RNG independent of gate randomness; if gate coin or extra transcript published, condition on it too. Soft gate changes per-cohort learning decision and generally joint distribution of update/data; preserving marginal version frequency at fixed precommit snapshot does NOT guarantee same training trajectory or objective, cannot claim lossless learning.
