## 1. Contract
Common causal frozen pretrained Transformer supplies feature y(h) (last layer), x(h) (shallow), with shared trainable adapter A(d×d) and regional personalized formal heads W_e(V×d); p_e=softmax(W_e A y(h)). Regional q_e=softmax(W_e x(h)); alternative shared q=softmax(Wbar x(h)), Wbar initialized as equal mean of pre-fit regional heads, then frozen within run. No separate full draft LM. Actual target is region-personalized p_e, not original unadapted checkpoint p. All requests fixed model snapshot throughout rollout and same-tokenization prefix. Each region's actual p_e verified with actual q, standard acceptance min(1,p_e/q), positive residual, first rejection truncation, independent draws and no bonus (fixed length). In exact real arithmetic causal induction yields p_e sequence law, with independent randomness across trajectories; a shared q distribution/cache is not a shared random token draw. Greedy must compare to formal p_e argmax and emit target argmax on mismatch; no production greedy/top-p/EOS/finite precision/KV verification. Only authorized identical prefix and common parameters may share nodes; private prompts may prevent equality sharing, no DP or security claim.

## 2. T: common trainable node and exact pooled VJP
For one fixed snapshot, shared z_h=A y(h), region loss derivatives v_{e,h}=sum_{visits} w_i (p_e-e_{token}) for detached, prespecified group-centered weights. Regional adjoint u_{e,h}=W_e^T v_{e,h}. Then shared adapter gradient G_A=sum_h (sum_e u_{e,h}) y(h)^T. This is identical to sum of per-visit outer products, including different formal p_e and private head gradients G_{W_e}=sum visits w_i(p_e-e_{token}) z_h^T. In general for genuinely identical trainable shared node z=f_theta(h), VJP J_h^T sum u equals sum J_h^T u by linearity, provided same parameters/state/mask/input and all relevant ancestor dependencies retained. For distinct region-local versions or different dropout, merely equal output values are not sufficient; e.g. f_theta=theta and g_theta=theta^2 at theta=1 have equal output but unequal derivative. Regional SGD steps at different theta cannot be combined in one shared VJP. This is linearity of reverse mode, not a new foundational theorem; related to R10, FVT/FVR, PrefixFlow, and FedRep. SD affects candidate visits, but ordinary AR can also aggregate actual committed visits. Matching exact formal trajectory distribution implies matching distribution of committed prefix counts at fixed policy; speculative candidates alone do not reduce required committed gradients. Same-information flat with identical physical delegation can duplicate all operations. Our simulation does NOT implement multistep hierarchical averaging; common A updates from synchronous exact aggregate and heads stay regional. No measured causal HFL-specific gain.

Communication proxy: if server already legally knows exact y(h) and keys for m distinct positions in a region, transmitting m d adjoint scalars (+IDs, weights, versions) can replace a d×d shared-adapter gradient; cheaper in raw scalar count iff m<d, before metadata and comparison against existing low-rank/factorized gradient communication. More generally if y(h) spans rank r and common basis known, exact gradient coordinates can be d r scalars; fixed linear injective encoding of arbitrary such matrices requires at least d r real dimensions by rank-nullity. Not a general bit or network lower bound; basis dissemination and privacy may dominate. For unknown y, sending feature as well adds cost and is not free. No actual byte/network measurements.

## 3. T: shared proposal heterogeneity barrier and launch proxy
At the same prefix h with equal weights for two regional formal distributions, overlap mean =1-[TV(p1,q)+TV(p2,q)]/2 <= 1-TV(p1,p2)/2 by triangle inequality. Bound attainable over unrestricted q (q=p1 or convex mixture of p1,p2), not necessarily via affordable shallow features. For distinct contexts/weights conditional versions differ. Independent q_e may achieve higher overlap; optimizing common q against regional acceptance alone cannot overcome this bound. Common q output head cache saves only when the exact same prefix and q parameters are legally reusable. Reusing a sampled token across regions introduces dependence even when per-region marginal correct; our code samples independently from cached probabilities. For count proxy C= c_b * blocks+c_q * unique q projections holding all other costs fixed, shared vs regional drafter beneficial only when c_q/c_b > extraBlocks/qSaved if both positive. Actual block batching, target evaluations, feature transfer, training, q calculation and synchronization invalidate simple timing inference; not hardware result.
