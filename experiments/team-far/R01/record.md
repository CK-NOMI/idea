## Problem, scope and distinction
A client withdraws from federated training; fix retained data and exact re-trained target p. Old model q generated a sequence X of length L for a fixed exogenous prompt. It has already appeared in an authorized historical audit transcript T (including X). Can the system reuse that sequence as a nonparametric self-draft, without a separate draft LLM, when new rollout Y must satisfy Law(Y|T)=P, the retained-data target sequence law with fresh independent randomness? This is an explicit stronger service/audit contract, NOT the usual definition of exact model unlearning, not a DP claim, not a claim that previously published text can be erased, and not a proof that adaptive deletion is safe. No actual requirement for this stronger contract or permission to retain deleted-derived cache was established; if policy requires deleting the artifact, no reuse is allowed. Fixed p,q and nonadaptive deletion in the probe. If p depends on T replace P by the reference conditional law; averaging formulas require fixed P,Q as specified. Distinct from FSOT optimizer correction, FCRR post-training proposal posterior, and A/R14 private target verification transcript: here X itself is already public and conditional output independence is required even if correct q is known. FPCS and Block Verification address prefix overlap under marginal, not the stated fresh-output contract. Standard target-first deterministic candidate is a direct existing alternative; no first claim of novelty.

## T: exact boundary and candidate mechanism
Let P,Q be full sequence laws; prefix P(u), Q(u). For fixed X=x, a fresh-output contract forces every conditional row K_x=P. For LCP length C, E[C|x]=sum_{t=1}^L P(x_1:t). Average E[C]=sum_{t=1}^L sum_{|u|=t} Q(u)P(u). Proof: tail sum, and conditional prefix event has exactly P(u). In particular full-match probability=sum_x Q(x)P(x). By contrast ordinary maximal coupling only requires sum_x Q(x)K_x=P; its one-token match is 1-TV(P,Q). Uniform binary p=q and L iid tokens: ordinary same-trajectory reuse accepts L; fresh expected LCP=sum 2^-t=1-2^-L. Joint TV of identity coupling vs independent Q×P is 1-2^-L, despite output marginal TV zero. These are analytic examples, not empirical model values.

Audit-safe block execution: precompute new target p on cached x prefixes in a causally masked batch; use fresh independent random draws from p at each prefix; emit candidate x_t only when sampled token equals x_t; first mismatch emit sampled token, discard stale suffix, and continue fresh p. This is standard target-first verification/SD with point-mass proposals, not a new general decoding primitive. Does not reuse stale hidden/KV across changed weights. Conditional induction for fixed T and fixed target: each next token distributed according to target p given actual history. Greedy: compare each candidate to actual p argmax with matching tie break and discard on mismatch. Apply same temperature/top-p/EOS and numerical contract as target, actual production not tested. This verifies conditional output law, not public accept/timing or deletion privacy. Fresh internal self-SD independent of T also satisfies the contract.

Relaxation: for each x require TV(K_x,P)<=eps. Since each prefix event differs by at most eps, E[C|x]<=sum_t min(1,P(x_1:t)+eps)<=E_fresh[C|x]+L eps. A row-wise oracle moves up to eps mass from outcomes with smallest LCP to x (exchange argument), attaining the optimal conditional expected length for that row, but generally violates the marginal P. In addition require exact marginal; a feasible baseline K_lambda=(1-lambda)P+lambda K_std, with fixed lambda=min(1,eps/max_x TV(K_std,x,P)), ensures both exact marginal and conditional TV<=eps. This convex interpolation is not claimed globally optimal; computing worst row may be expensive or impossible in real LLM. Cannot use approximate conditional mode when exact freshness is required.

General joint TV diagnostic = sum_x Q(x) TV(K_x,P). If one samples old X conditional on deletion event, using unconditional Q is additionally invalid (FCRR already established similar adaptive proposal hazard). Fresh target-first avoids relying on old Q, if actual retained-target reference is correct.
