## T: pathwise zero-contrast certificate
Fixed snapshot W, frozen backbone, untied output head, fixed partition of V rows into K nonempty proper blocks B_j, seeded independent Rademacher direction in each block, signs may be generated after checking a bound that holds for all signs (seed/direction law fixed before noise). Use common iid position-indexed Gumbels across +/− and direction bank, no reuse across times. Base unperturbed path H^0 sampled with full support temperature T>0. At base prefix t, a_v=(Wh)_v/T+g_v, base winner w, block o=owner(w), uniform b_t=eps||h||_1/T. If j!=o, possible changed winner requires some v in B_j with a_w−a_v<=b_t. If j=o, possible changed winner requires either rival in same block with gap<=2b_t or rival outside block with gap<=b_t. Conservative equality included. These conditions follow because only rows in block perturb, and pairwise score differences move by at most 2b within block, b across. Define risk set A_t of blocks meeting these conditions, first risk tau_j=min{t:j in A_t}, default L. For every direction supported in B_j satisfying bound, both perturbation paths coincide with base for t<tau_j, by induction on common legal prefix. If tau_j=L, both full sequences exactly base, no need to materialize any perturbation, run either perturbed rollout, or query reward if R is deterministic function of sequence and same prompt/environment, or same lawful exogenous reward noise, and no parameter dependence; directional finite difference is exactly zero. If reward directly depends on W or independent stochastic calls, output equality does not certify zero. Only skip for same prescribed coupling; not an independent reward/rollout objective. If block uncertain, start both exact lazy signed paths at tau_j, fallback after deviation; no false certification. Can pre-verify base anchor with inner shallow q using same Gumbel at logical time and target-first commit until first mismatch; unused future guesses discarded, no change to base or paired joint reference. Certification is offline on completed base path; no use of future noise to alter formal trajectory, direction law, or select samples. Greedy g=0 same gap proof; top-p/top-k must use full target fallback and do not use this certificate, EOS and conservative finite precision contract need implementation. Actual experiment uses FP64 full-vocabulary fixed length.

## T: scale bound from block mass and extreme value gaps
At fixed base history before current Gumbels, let p=softmax(Wh/T), P_j=sum_{v in B_j}p_v, c=exp(b), c2=exp(2b). Via independent exponential races E_v~Exp(p_v), block minimum rate P_j. Number of nonwinning blocks whose score is within b of winner has expected sum_j c P_j/(1+(c−1)P_j)−1. Derive P(E_j<=c min E_k)=c P_j/(1+(c−1)P_j) by conditioning on min outside or integrating exponential; sum and subtract unique winning block. Winner block risk is at most event gap between first and second highest score<=2b; conditioned on winner i, min E~Exp(1) and residual outside minimum~Exp(1−p_i), hence probability no competitor within 2b is 1/[1+(c2−1)(1−p_i)]. Thus E|A_t| <= sum_j cP_j/[1+(c−1)P_j] − sum_i p_i/[1+(c2−1)(1−p_i)]. Bound also <=K, can min. Expected number of ever risky directions E|union A_t|<=min(K, sum_t E[bound_t]) under iid per-time Gumbels and fixed prior partition; not assuming independent positions. Expected certified zero fraction >= max(0,1−sum_t E[bound_t]/K). This can be nontrivial when L exp(b) << K; b may be huge for real d/eps, and long sequences may activate every block. No guaranteed reward sparsity beyond certified equality. Dependence between directions allowed as in R06 orthogonal conditional Euclidean MSE identity. If changing partition based on current noise and then treating as fixed bank estimator, that is a selection bias hazard; partition may use past-round statistics, not current noise unless separately proven. Real optimization direction selection, adaptivity, variance and quality remain unproven. Not new extreme-value or counterfactual theory in general.

## Mechanism and strong alternatives
Regional compiler assigns fixed partition and seed, runs base anchor using exact self-spec, broadcasts sparse first-risk schedule locally; inactive direction coefficients zero, active directions evaluated only from first uncertain location. Cloud aggregates exact prescribed sparse seeded FD updates. No cross-region prompt sharing assumed; no DP claim. Can avoid sending zero coefficients if receiver has preset bank/seed; metadata and communication cost must be measured. This is parameter-space speculative reuse, stronger than R06 per-direction per-prefix checks. Ordinary shared AR can implement the same anchor and certificate; indeed anchor AR with same certificate is mandatory fair baseline. Shared AR also can perform equivalent risk screening online; no fundamental SD-specific arithmetic gain. R07 compares both. The upper bound on direction scheduling visits is not a bound on whole GPU time. For output head weights tied to embeddings or perturbed backbone the certificate fails. Positive evidence is exact removal of work, negative evidence if same-information AR wins. No claim that hierarchy alone causes advantage.
