## Problem and mechanism
Move from parameter ownership to determining next-round model coordinates before all fine aggregation messages arrive. Fixed selected clients, committed equal weights, two edges each sum four signed 8-bit integer local updates in [-127,127]. First edge sum a exact; second edge sum z in signed 10-bit [-512,511]. Target formal optimizer is specifically deterministic quantized additive SGD-like update with code Q_G(a+z)=floor((a+z+G/2)/G), G even (mean grid step G/8). Previous parameter is already on fixed grid, so add this code to old code; no hidden FP master weights, error-feedback, momentum, adaptive scale, or residual state. If any of these exist, their next state must be recovered too; skipping exact fine updates otherwise changes the training algorithm. Full-precision FedAvg not equivalent. Coarse b MSBs yield lo=floor((z+512)/2^(10-b))*2^(10-b)-512 and hi=lo+2^(10-b)-1. For an arbitrary tree, partial nonnegative weighted sums of lower/upper bounds compose; exact integer arithmetic/no overflow, fixed scales and known weights required. Secure aggregation and privacy not established; selectively disclosing per-coordinate intervals could leak information.
T1: For monotone deterministic Q, Q(a+lo)=Q(a+hi) iff Q is constant on the whole interval, hence exact next code. With independent interval uncertainty, endpoints feasible and unequal codes make zero-error no-refinement impossible from that information alone. If correlated constraints exist, interval sufficiency remains but necessity can fail. Refining a nested interval cannot revoke a certificate. For uncertified coordinates request residual fine bits; certified coordinates require none for this optimizer. Induction yields same full formal parameter sequence as dense exact communication under same local sample schedule, randomness, deterministic math, and no unobserved optimizer state. No claim actual learning quality or original float trajectory.
T2: for integer uncertainty width w=hi-lo+1 and uniformly random independent phase modulo G, single coordinate certificate probability max(0,(G-w+1)/G); d independent phases give its d-th power for whole block. Not a universal probabilistic law or true model estimate; correlated coordinates and dependency-local activation certificates may differ. Whole dense shallow layer must be certified before reusing exact next-version activation unless a smaller dependency closure or proven exact incremental calculation exists. Non-certified midpoint guesses cannot validate gradients merely from token agreement (previous repo counterexample). A coarse message computed from completed slow-edge sum overlaps transfer only, not its training; b=0 pre-computation global bound was unhelpful in this audit.
T3/H: Freeze request version chosen independently of proposal randomness. Early certified prefix and shared head (if required) enable exact precompute for fixed next-round samples and self-draft q; otherwise stale or midpoint model is only a proposal, not exact next-version activation. Keep actual q, do not reuse incorrect KV in target, evaluate exact current p on committed causal prefix; stochastic min(1,p(y)/q(y)) and positive residual on rejection yield p conditionally; inductively correct sequence in ideal arithmetic including EOS and actual normalized temperature/top-p distributions. Greedy uses exact p argmax same tie-break, not q acceptance alone. Not an actual implementation, production FP and kernel equivalence unverified. If feedback alters p based on proposal RNG, independence/conditional target requires reproof. Ordinary AR also exploits exact early prefix; same-resource flat can run same protocol. SD-specific incremental training gain unestablished. Candidate two-way hypothesis: a measured verification queue allocates fine-refinement order across dependency closures, trading early draft window against next-round learning critical path, with identical target. Not demonstrated; strong baseline scheduler with same information can imitate.
