## T: exact migration and residual rank lower bound
Fixed common frozen backbone, W base head and formal p_c(h)=softmax[(W+A_c)y(h)], finite positive softmax. Let C=I-11^T/V center logit rows. For a common orthonormal input basis B (d by s) promoted to region/cloud, model after migration is W+S B^T+L_c (I-BB^T), S shared V by s, private constrained to orthogonal complement. For equality of the formal distributions for ALL y in R^d (or any set spanning it, under fixed features/processors), necessary and sufficient that C A_c B=C S for every c. Necessity: softmax equality iff centered logits equal, multiply centered head equation by B; sufficiency choose L_c=A_c and S equal centered coefficient, allowing row-constant gauge. Thus exact promotable directions are ker stacked C(A_c-A_ref), dimension d-rank. A previously observed finite feature set not spanning d may permit additional directions; not a theorem for arbitrary nonlinear backbone/temperature/top-p. Centering required: common logit shift does not affect probabilities.
If shared coordinates retain a private correction R_c B^T, choose R_c=A_c B-S; then W+A_c exactly reconstructs, no formal distribution change, including multi-token conditional sequence law. For pair i,j, C(R_i-R_j)=C(A_i-A_j)B, hence rank(CR_i)+rank(CR_j)>=rank(C(A_i-A_j)B). If centered difference full column rank d, RHS=s for every orthonormal B. Mean shared coefficient S=(A_i+A_j)B/2 yields both residual ranks s, so common s plus two rank-s residuals; arbitrary S may shift burden but cannot remove both. These are algebraic matrix-rank/coordinate counts, not universal bit-storage or network lower bounds. If full private coefficients already stored, shared q may be computed on demand rather than adding storage; at equal draft rank MACs may remain unchanged. Exact migration cannot be credited as cost savings simply because q coefficients shared. Note strong standard old-q exact SD and independent rank-r draft head both work without changing formal p.
For group weights w_c sum 1, mean Abar, G=sum w_c [C(A_c-Abar)]^T[C(A_c-Abar)], the least squared centered coefficient distortion for fixed B is Tr(B^T G B), attained at S=Abar B up to row constants. Global minimum over orthonormal B of dimension s is sum of s smallest eigenvalues (Ky Fan). This is a sharp Euclidean coefficient bound, not held-out NLL or acceptance optimality, classical linear algebra. If S chosen to improve q, residual may increase; formula no longer minimal. For pair rank obstruction there is exact centered rank vs finite precision tolerance. If all heads equal, any B promotable; if differences span d, none. R54 allowed private nullspace by architecture; R55 shows promoting its coordinates without overlap is not generically closed under exact model preservation.
## H/T: residual-retaining mixed ownership and exact decoding
Let B_e be r orthonormal draft basis, choose shared subset J of s columns and local remaining. Q_c=Abar_e P_J+A_c(P_B-P_J), q_c=softmax[(W+Q_c)x(h)]. Formal head W+A_c always retained as W+Q_c+(A_c-Q_c), so formal probabilities unchanged as J changes, no extra independent draft LM. Standard SD with true actual q at each prefix, fixed formal p, independent uniforms, acceptance min(1,p/q), residual (p-q)_+, causal first rejection truncation and bonus/EOS yields exact formal conditional sequence law; greedy formal argmax tie policy. Changes in q before or between blocks require correct proposal probabilities; no production implementation/top-p/finite precision sampling tested. Shared subset chosen by least disagreement of centered regional update columns or greedy calibration root overlap. Both may use same actual r at inference. This is not new learning objective; formal prefit remains CE in experiments. Optional joint feedback into formal owner choice is untested; HFL-to-SD only demonstrated on fitted heads, SD-to-HFL necessity absent. Same-information flat can copy. With two clients, proposal coefficient count (2r-s)V instead of 2rV, but formal residual must remain and shared-basis/coeff refresh/communication counted; base head still dense. At r8 s4 nominal proposal coefficient bank saving 25%, NOT total parameter, actual communication or speed.
