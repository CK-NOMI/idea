## 2. T: sufficient-statistic theorem and tree-invariance
Define m_i(k)=Pr(B_i=1 | K=k)=a_i A_{-i}(k-1)/A(k), where A is root Poisson-binomial PMF. Given count-respecting monotone repair and root joint G_J(k,l), B_i C_i = B_i if k<=l and C_i otherwise. Thus
W_i(1,1)=sum_{k,l}G_J(k,l)m_i(min(k,l)).
s_i=Pr(B_i=1|J)=sum_{k,l}G_J(k,l)m_i(k).
W_i=[[1-s_i-a_i+W11, a_i-W11],[s_i-W11,W11]].
Only root source count and minimum-count distributions are needed: S(k)=sum_l G_J(k,l), M(k)=sum_{min(u,v)=k}G_J(u,v). Consequently all R29 local reward statistics invariant to balanced tree topology, provided each count-respecting monotone coupling uses same G_J. Does not imply entire repaired vector joint law between B,C or physical costs invariant. Count-respecting couplings preserve B|K,L,J and C|K,L,J. For fixed G, max possible W11 <= E min(m_i(K),m_i(L)), attained by monotone repair since m_i is nondecreasing by conditional Bernoulli monotonicity. Further root quantile coupling maximizes E min(m_i(K),m_i(L)) over root couplings (layer cake: P(m_i(K)>t,m_i(L)>t)<=min(marginal tail probs), comonotone coupling attains all thresholds), simultaneously for all i. Hence minimal per-client disagreement and any fixed nonnegative weighted Hamming cost within count-respecting class. For threshold J, monotone direction fixed, W disagreement equals |s_i-a_i|, global marginal lower bound even among unrestricted couplings. For general J no universal weighted optimum beyond count-respecting class. Weighted Hamming not same as arbitrary p/q Token retention or joint latent verifier optimum; do not overclaim.

## 3. T: two-adjoint and threshold one-adjoint compression
For arbitrary root count distribution D supported where A>0 define h(k)=D(k)/A(k). For node convolution A_u=A_L*A_R propagate h_L(i)=sum_j h_u(i+j)A_R(j), h_R(j)=sum_i h_u(i+j)A_L(i). At leaf i, a_i h_i(1)=sum_k D(k)m_i(k), by expanding convolution or reverse-mode derivative treating leaf coefficient as independent input. Apply to S and M above, using one tree traversal with two adjoints. Quantile root coupling support <=2N+1 in exact arithmetic; compute by interval overlap O(N). Naive balanced convolutions and adjoint work O(N^2), tree coefficient/adjoint storage O(N log N) (sum per-level lengths), compared with R29 dense pair-count precomputation O(N^3)/O(N^2). This is not a new general differentiation theorem. Hierarchical coefficient messages in an ideal one-node-per-tree-node deployment O(N log N) scalar entries summed over edges per direction, not bytes or measured physical network; probabilities/adjoints may leak information and cannot claim privacy. Root no full client raw token needed, but actual topology, metadata, repeated round setup and local probability computations must count. Actual repair still samples root and conditional split distributions with appropriate fresh randomness; precompute of all conditional tables not required, sampling cost and depth distinct.
Threshold specialization J=1{K>=T}: for high event root quantile L<=K, C<=B; for low event B<=C. Hence W11=a_i for high and W11=s_i for low. Compute s_i directly with root h(k)=1{event(k)=J}/P(J), one adjoint, no root transport table or coefficient-wise division for statistics. Need nonzero event mass. W_high=[[1-s,0],[s-a,a]], W_low=[[1-a,a-s],[0,s]]. Can still need root quantile for actual repair sampling. For extremely rare event P(J) may underflow; use certified log/scaled arithmetic or full conditional fresh fallback, not guaranteed by FP64. General ratio D/A can suffer tail underflow, threshold no such division per count. Numerical stress not production proof.

## 4. T: linear vocabulary verifier

Objective per-token derivative on segments among {0, W_b1/a, -W_b0/(1-a), W_b1/a-W_b0/(1-a)}. Across two classes at most 8 slopes (possibly fewer). Constant-size bucket order and sequential filling within bucket, honoring segment predecessor (nonincreasing slopes for each coordinate), attains same first-token optimum O(V), no O(V log V) sort. No new general resource allocation theorem. Weighted two-token objective still has arbitrary w_x so distinct slopes; use first-token optimizer as cheap valid alternative that does not require all V successor-prefix probabilities for setup. After accepted first token standard suffix SD computes only relevant conditional probabilities; production batch still needs target evaluation. Correctness independent of weights because mixture r remains p. Let f* max first retention and wmin,wmax suffix weights. For weighted objective regret of unit optimizer <= (wmax-wmin) f*: first contribution of competitor <=f*, each retained prefix weight in [wmin,wmax]. Loose bound, actual differences small on char model; no uniform small-regret guarantee. Actual p,q vectors and probability computation nonfree. Both old and new optimizations compare same target contract and old drafts; fresh baseline generates new drafts.
