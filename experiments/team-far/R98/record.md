## T/H
With row inputs X_c, common A (r×d), regional B_c (V×r), fixed base W (V×d), Z_c=X_c A^T, Y_c=X_c W^T+Z_c B_c^T. For upstream G_c, dZ_c=G_c B_c, dB_c=G_c^T Z_c, dA=sum_c dZ_c^T X_c, dX_c=G_c W+dZ_c A. One concatenated projection and VJP exactly matches grouped identical A and summed adjoints in real arithmetic even for different prompts. This is ordinary linear algebra, not SD-only or hierarchical-only; base GEMM already batched in strong baseline. No reduction in leading MAC counts. Same-delegation flat and common-coordinate LoRA can copy. Product averaging commutes only with fixed common A (or same snapshot); multi-step both-factor averages generally not equivalent. Shared A across p,q does not make A h_s=A h_d; need exact same input or invariant projection. Candidate H: define formal and shallow logits with same residual B_c A h_s and distinct fixed W h_d/W h_s, making reuse exact by construction, changes formal model class; quality may degrade. If only residual reused, maximum MAC saved per pair r(d+V)/[2dV+2r(d+V)] = 0.8637% at measured dims, assuming both base heads needed, both adapter computations previously distinct, no other overhead. Not hardware latency bound. Do not use this output-head mechanism as core.
