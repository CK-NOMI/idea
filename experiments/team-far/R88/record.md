## T/O exact joint objective
At prefix h let a_e = w_e product along h min(p_e,q) (unconditional accepted prefix mass), b = product along h q (unconditional drafted prefix mass), initial a=w,b=1. Define
F_0(h,a,b)=0,
F_k(h,a,b)=max over simplex q sum_x [sum_e a_e min(p_e(x|h),q_x) - lambda b q_x sum_e w_e c_e(h,x) + F_{k-1}(hx,(a_e min(p_e(x|h),q_x))_e,b q_x)].
This is exact for A=expected accepted-token length and C=expected incremental cost of complete draft, U=A-lambda C. For fixed policy descendants, F is linear in (a,b), hence max is convex, positively homogeneous (a,b>=0). Fix one simplex cell partitioned by q_x=p_e(x|h); each min is affine within cell, so objective in q is convex on that polytope. A maximizing vertex exists; all but at most one coordinate belong to {0,1,p_e(x|h)}. Enumerate finite candidates and recurse; worst-case exponential, not deployable at normal V,K. Proof generalizes R44 (acceptance only) to separate unconditioned draft mass and accepted mass. Cannot replace b with sum(a): rejected suffix still costs verification. For singleton region and lambda=0 optimal q=p. Independent regional q upper bounds shared oracle but consumes different capacity/permissions. 
For fixed length with no EOS and bonus, standard exact SD commits one plus number accepted, so proxy expected work 1+A. For assumed fixed base cost c0, variable cost c1*C, correct block-ratio optimization is min (c0+c1*C)/(1+A), equivalently max throughput. Dinkelbach or scalar parametric search using F can obtain ratio oracle (not executed; lambda=c1*optimal throughput when maximizing A-lambda C). Across blocks state distribution may change; R59 steady-state bias must be accounted for, no claim local ratio is true long-run optimum. Standard SD under actual q and exact current p_e, causal min(1,p/q), residual (p-q)+, bonus gives exact conditional sequence; greedy requires formal argmax, no production EOS/top-p/FP or actual multi-token implementation here.
