## 2. T: exact interval residency and ordered admission optimum
Assume each version job j has release r_j, fixed known duration d_j>0, a dedicated equal-size version slot for the entire half-open interval [s_j,s_j+d_j), no preemption/offload, no memory/compute interference beyond K identical slots, no transfer/restore cost. Actual duration independent of schedule is an explicit idealization. If all starts fixed at release, C(t)=sum_j 1{r_j<=t<r_j+d_j}. Minimum zero-wait slots K*=max_t C(t) (lower bound simultaneous occupancy, upper bound assign freed slot in interval-start order). Total slot-seconds A=sum_j d_j=integral C(t)dt; any schedule with K slots makespan >= A/K (origin0). For already running groups sharing exactly one version, union of live intervals counts once; in this replay group starts aligned so duration is max cohort/request finish time. If same version needs new work later, release/reload can change model, and if authorization forbids shared slots cannot count once. No general memory lower bound with page sharing/compression or offload.
When jobs must be admitted in a predetermined total order, s_j>=max(r_j,s_{j-1}), choose earliest time at or after that lower bound with free slot (remove completed jobs; if full, advance to earliest active finish). Componentwise optimal over all schedules under assumptions: inductively greedy starts and finishes for each earlier job <= alternative's; at alternative s_j all earlier greedy jobs have started and its live earlier jobs subset of alternative's, so slot exists; greedy s_j<=alternative. Therefore minimizes any coordinatewise nondecreasing completion/delay objective (e.g. makespan/total delay). Without fixed order, different duration, variable slots or shared GPU bandwidth, result not applicable. This is classical interval partition/ordered identical slot scheduling, not a new underlying optimization theorem. A learner's publication times actually depend on training and preceding completions, while replay treats them exogenous; cannot use the replay as actual learning feedback or sustainable training rate. Fixed p, exogenous exact SD changes duration only, so observed AR-vs-SD capacity gain is ordinary SD gain. HFL does not add a new learning mechanism; G2 fails.
