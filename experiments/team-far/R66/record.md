## T: factor only expensive transition rather than entire formal model
At block start anchor M contains committed raw history, within block H is fine history and S=g(H) is deterministic class sequence. Fixed map g at model snapshot and within-block class transition depends only on S. Define formal target p(y|M,H)=P_theta(g(y)|M,S) E_phi(y|g(y),M,H), E normalized on selected class. Cheap E can read full fine history; expensive P cannot. Block boundary updates M using actual raw output; fixed predetermined boundary length, no verification crossing boundary without full exact anchor. If EOS or stop depends on raw token, either EOS singleton and stopping class-determined or stop/handle explicitly with causal rule; do not pretend all fine-dependent processors can be ignored. New formal p, not lossless original teacher. Standard class SD with actual q_c(s) from shallow path of same model, min(1,P_c/q_c) and positive residual, causal first rejection/bonus and block truncation. Then after committing class, sample fine token from E at actual raw prefix, with fresh independent randomness. Conditional sequence law follows p factorization and induction; entire class prefix may be generated before fine emissions only when within-block class evolution and stopping do not depend on fine history. Greedy target argmax is max_c P(c) max_{y in c}E(y|c), not argmax class then argmax within; to preserve token greedy use exhaustive or certified exact argmax and matching cache dependencies. Flat raw-token temperature/top-p may alter class probabilities depending on E/H; independently transforming class and emission defines new target rather than preserving old processors. Numerical/EOS/long rollout untested.
T/O: For teacher T at fixed full anchor, optimal fully coarse projection has extra expected NLL I_T(Y;H|M,S). New factorized family with unrestricted E has irreducible extra NLL I_T(C;H|M,S). Difference I_T(Y;H|C,M,S)>=0. For arbitrary learned P,E the excess relative to teacher decomposes exactly into irreducible class loss plus E KL(T(C|M,S)||P(C|M,S)) plus E KL(T(Y|C,M,H)||E(Y|C,M,H)); all weighted by teacher histories/classes. Cannot infer equal task quality from oracle or small micro-model. At B=1 no within-block coarse compression; if M is lossy, extra gap from that. 
T: delayed emission avoids computing E on rejected class candidates. However, a strong raw-token SD baseline can use the same conditional E as both target and proposal: q(y|H)=Q(g(y)|S) E(y|g(y),H). Then token acceptance equals class acceptance, since min(p_y,q_y)=min(P_c,Q_c)E_y, residual factors as (P_c-Q_c)_+ E_y. It is algebraically equivalent to class verification followed by fine sampling, and can delay emissions too. This is a strong equivalence/no-exclusive-advantage result (not a universal impossibility for architecture). Direct class-first AR with same P and E is a strong baseline; if class prediction cheap or precomputable, no SD needed. Any SD savings must be vs strong class-first AR on expensive P, same p, and optimized token SD with same factorization; not compare naive SD. Region adaptation can be delegated to flat with same info, so G2 remains open. 
H: training objective CE_class+CE_emission+beta exposed class-SD cost, region maps/priors optional, cloud shared anchor, private local fine decoder. To preserve portability across clients use stable class label mapping or explicit alignment; averaging class heads with inconsistent g invalid. Learn partitions by conditional class information loss plus actual multi-step state survival (not acceptance alone); fine emission memory/latency and anchor refresh included. Not implemented in R66; actual global partition and head SGD only. No claim that these generic methods are independently novel.
