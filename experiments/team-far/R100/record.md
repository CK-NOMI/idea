## T: shared bridge has a common-mode obstruction
For fixed legal prefix and fixed other parameters (including M), write p0=softmax(u), q0=softmax(v), u=W(y0+Mz_d), v=Wx. A shared FFN bridge b=B_e z_s induces identical logit shift c=Wb: p=softmax(u+c), q=softmax(v+c). Full support, T=1, no truncation. Let r_i=q0_i/p0_i. Then q_i=p_i r_i/Z, Z=sum_i p_i r_i. Thus log(q_i/p_i)-log(q_j/p_j)=log(r_i/r_j), independent of B_e. No finite common shift can attain p=q unless p0=q0; if p=p0 then c is constant and q=q0. Not a global impossibility for trainable other layers/M. For TV(p,p0)=delta, R=max r/min r, TV(q,q0)<=R delta: for event E, q(E)-q0(E)=(p-p0)·[r(1_E-q0(E))]/Z; oscillation <=max r, Z>=min r. Consequently A(p,q)<=min(1,A(p0,q0)+(1+R)delta); with KL(p0||p)<=eta, delta<=sqrt(eta/2). Bound can be vacuous. Binary p0=(.8,.2),q0=(.2,.8), p=(t,1-t),q1=t/(16-15t), A=1-t+q1. t-q1 is concave; KL interval endpoints give exact optimum.
