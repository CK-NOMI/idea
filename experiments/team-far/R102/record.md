## T/H: exact projection reuse on fixed legal prefix
Continue R101, not new acceptance loss. Freeze earlier trunk and attention through last FFN. For fixed group contributions v_g in R^d and reference h0, candidate h_j=h0+sum_g a_jg v_g, where a_j is difference from reference binary group mask. Final RMSNorm logits z_j=U h_j / sqrt(||h_j||²/d+epsilon), U=W diag(gamma); no head bias assumed (add same bias AFTER division if applicable). Thus cached reference raw projection U h0, group projections U v_g, and exact per-mask RMS denominator give same real-arithmetic logits as full candidate projection. If reference normalized logits only are available, reconstruct raw projection using reference norm in ideal arithmetic; actual quantized/rounded cache requires separate precision audit. Gram matrix of [h0,v_1,...,v_G] gives denominator via quadratic form; may be worse than direct hidden norm if G² large, choose measured strategy. Same legal prefix/version, fixed upstream and final head; changing upstream, nonlinear post-FFN transforms, independent adapters/normalization or using candidate-dependent activations invalidates formula unless explicitly accounted. Softmax and output processors remain candidate-specific. Exact algebra only, not bitwise GPU equivalence or original teacher equivalence after pruning.
Mask difference matrix A with rank r factor A=C B. Project r hidden basis vectors sum_g B_kg v_g instead of all M-1 candidate hidden vectors; combine via C. Fixed equal retained group count implies A1=0, hence r<=G-1. Compare direct cached-reference batched projection, group projection, generic rank factorization. No claims of reduced MACs for candidate-specific q projections, FFN formation, norms, softmax, storage, communication, training or deployed SD. Candidate p only in this experiment; q is same fixed distribution for all candidates. All evaluations require full vocabulary.
New sparse component anchor: connect all nonzero-support groups of every mask difference in a graph. In each connected component S, sum_{g in S} a_jg=0 for every j, because each row support lies within a single component and total sum zero. Choose an anchor t_S per component, then sum_g a_jg Uv_g = sum_{g != t_S} a_jg U(v_g-v_tS). With active group count G_a and c components, need G_a-c projected vectors, coefficient sparsity retained. For one-swap masks rows are signed incidence edges, rank exactly G_a-c (incidence matrix theorem). Proof: nullspace consists of vectors constant within components. General multi-swap mask only upper bound; generic rank may smaller. Choose anchor of highest occurrence count to minimize coefficient nnz within this restricted anchor family. This is standard linear algebra/graph incidence, not new theorem in general.
If reference projection already cached, direct head proxy D=(M-1)Vd; group proxy G_a Vd+V nnz(A); rank proxy r Vd+V nnz(C)+d nnz(B); anchored proxy (G_a-c)Vd+V nnz(A_nonanchors)+d(G_a-c). Count coefficient multiply-add even +/-1 (actual additions can differ); all omit shared hidden construction and separate denominator/softmax/Gram work. Group projection may need more memory; can tile vocabulary but exact softmax usually requires retained logits or extra pass, charge all. Choose minimum proxy, not wall time; generic rank baseline is strong and can implement same math. Flat same authorized data/computation and ordinary cached AR can also use this exact algebra; no G2.
