## T: selective path compression
At one parent with independent child laws and child maximal couplings J_c, let J0=product J_c, Q,P product laws, D=diag J0, I=P-D, O=Q-D. Choose any deterministic state function t(z) in [0,min(I,O)], fixed conditional on pre-draft history. Add t to the diagonal. For initial x~Q, retain with (D+t)/Q; otherwise walk a nonidentity J0 edge conditional on departure. At arrival z, relay with probability t/I, stop with 1-t/I. Zero denominators never visited under exact arithmetic. DAG rank is number of child coordinates with P_c>Q_c. In topological order, incoming mass I, initial departing mass O-t and relayed mass t imply outgoing mass O. Endpoint distribution is P (diagonal D+t plus final incoming I-t), original edge usage retained. Each child changes at most once, so full child joint law preserved; recursively all regional/client pair laws preserved, including exact mean repair counts. Root equality exactly sum(D+t), root repair rate decreases by sum t vs independent regional coupling. Expected root hop count remains 1-product child overlaps regardless of t; NOT equal network RPC, not <=2 globally. t=0 is independent regional output, t=min(I,O) is R72 maximal root; intermediate t gives exact partial compression. Partial child kernel may no longer be donor-to-recipient at its parent, so cannot freely stack arbitrary partial levels using R72 proof. This round only root partial, children maximal. Arbitrary overlapping groups not covered. Strict causal snapshot and independent proposals; no new actual multi-step SD, zero support/finite precision production audit.
## T: rank-constrained relay and squared-cost identity
Relay only at a single rank r (antichain), then each nonidentity path has <=2 root hops since rank strictly increases. This is bound on root path, not token repairs or total tree latency. Let E be number of changed child regions. Define a(z)=E[incoming edge changed-region count|arrival z,nonidentity], b(z)=E[outgoing edge changed-region count|departure z,nonidentity]. For independent child maximal base, a=sum_c(1-min(1,Q_c/P_c))/(1-D/P), b=sum_c(1-min(1,P_c/Q_c))/(1-D/Q). Incoming and outgoing edges independently paired conditional on relay state. With single-rank t, no path has multiple relays; disjoint changed child sets yield (A+B)^2-A^2-B^2=2AB. Thus E_t[E²]=E_0[E²]+sum_z 2t(z)a(z)b(z). Cost B Pr(root repair)+d E[E²] minimized over policies supported on fixed rank by t=min(I,O) iff B>2d a b (ties arbitrary). Can optimize rank via calibration but selection is oracle if chosen on same data. General multi-rank interactions add higher cross terms, heuristic threshold not globally optimal. For any fixed repair mean mu and root event rate r, E[R²]>=mu²/r (R72); no cost-free universal tail fix. Full root max can be worse on actual max-region latency. No new standalone foundational OT claim.
