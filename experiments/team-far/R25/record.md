## 1. New formal model, scope
At block boundary h, freeze pretrained microGPT trunk W. Joint model P(x,y|h)=sum_z lambda_z(h) a_z(x|h)b_z(y|h), with trainable softmax gate on normalized h and latent-specific additive logit offsets to W h. K=1/2/4/8. This is a NEW formal block LM, not exact replacement of original pretrained AR teacher T(x,y|h)=t(x|h)t(y|h,x). Across fixed two-token blocks recompute h after committed block; prefix-conditioned law within block determined by posterior. Different block alignment can define different model, no arbitrary resegmentation guarantee. For sequence generation complete block model needed, not experimentally run across many blocks here. BOS ordinary character, no EOS/top-p/temperature/production numeric contract.
T: exact block marginal P_X(x)=sum_z lambda_z a_z(x); posterior lambda_z(x)=lambda_z a_z(x)/P_X(x) if P_X>0; P(y|x)=sum_z lambda_z(x)b_z(y). Joint direct sampling Z~lambda, X~a_Z, Y~b_Z independently given Z has exactly P. Thus if one uses P as formal model, a speculative proposal Q=P_X P_Y or merged-component approximation can be verified by joint maximal coupling with overlap sum min(P,Q) and positive residual, but direct latent sampling avoids rejection and full V² joint materialization. For an exact same-target direct implementation draw Z then evaluate/sample only selected component heads (where gate can be evaluated independently), O(Kd+V) head terms under shared precomputed base logits vs all K head terms; not a measured GPU dominance. No need to materialize all probabilities for direct stochastic generation. Exact tokenwise greedy requires marginal argmax then conditional argmax; joint MAP may differ, and stochastic latent draw is not greedy. Full conditional enumeration with same tie break gives tokenwise greedy relative to NEW model only. If need original teacher T as target, verifier must still use T; P can be used as draft but then it reduces to related dependent-block drafting; no demonstrated reciprocal HFL innovation. 
T: X—Z—Y conditional on h implies I_P(X;Y|h)<=H(Z|h)<=log K. Any joint target whose conditional mutual information exceeds log K cannot be represented exactly; converse false (nonnegative rank). K=1 projection into product marginals minimizes forward KL with residual I_T(X;Y|h), so near-100% P vs its own independent proposal can indicate representation collapse, not target agreement. Region mixtures of joint models are exactly represented by concatenating all components with weights alpha_e lambda_e; rank budget grows. Parameter averaging is not equivalent, e.g. one-component regions delta_(0,0) and delta_(1,1), each rank1, equal probability mixture rank2, averaging component marginals produces four equally likely pairs. Exact flat concatenation same. Ordinary FedEM/probabilistic circuits are close.

## 3. T: improved hard partition preserving first-token marginal
For original teacher T_x,y and partition C=g(X) with R groups, define Q_g(x,y)=T_X(x) B_g(y), B_g(y)=T(Y=y|C=g(x),h). This is a formal joint block model with exact first marginal, group-specific second prediction. Conditional mean distribution B_c is unique forward-KL optimal for group with positive mass, by cross-entropy decomposition. For arbitrary fitted Bhat_c,
KL(T||Qhat_g)=I_T(X;Y|C,h)+sum_c T(C=c|h) KL(B_c||Bhat_c).
Proof split log ratio T(y|x)/Bhat_c into T(y|x)/B_c and B_c/Bhat_c and sum. I_T(X;Y|h)=I_T(C;Y|h)+I_T(X;Y|C,h), C deterministic. This decomposes structural information loss vs prediction-head learning error; group refinement weakly reduces oracle loss, not necessarily learned error. R>=V identity groups can represent teacher exactly only if conditionals exact; obtaining those may cost V forward passes. Can directly sample X from first marginal, then Y from group-conditioned distribution, or sample group and both X,Y from group conditional, no SD required. Not claim original target equivalence if compressed. KL clustering uses alternating weighted centroids and reassignment, local optimization only, not global optimality. Training pooled joint counts by adding region sums can be delegated to flat without any change. Per-context exact centroids are O, not deployable cheap distributions.

## 5. Costs and impossibility boundary
Oracle teacher joint costs V+1 prefix forwards/context, dense V² matrix. At V=128000, FP32 one full matrix 65.536GB (decimal), beyond one 40GB GPU; not a universal lower bound, could stream/subsample. Pooling regional V² statistics is equally expensive if dense; no actual network. Learned head R*V bias plus contextual V(d+1); for actual formal generation only selected group need evaluated after X known, versus all group heads for training soft distillation; no measured latency. Direct latent or group sampling avoids explicit verification under new target; with original teacher verification remains. No proven HFL/SD double necessity, same-info flat can implement learning. Do not claim exact original Softmax sequence or lossless quality.
