## 1. Problem and distinct mechanism
R28 independent local verifier randomness causes a restricted-class independence bound and exponential scheduling. Keep same R27 conditional contract: independent old first-token proposals X_i~q_i before selection, B_i=b_i(X_i), a_i=Pr(B_i=1) in (0,1), J depends only on total K=sum B_i (threshold or exact count). Fix selected formal p_i^J, require output product conditional on J and precommit state, not conditional on internal vote/repair transcript. No private raw token or prefix transfer needed for count transport under trusted regions, but probability summaries and counts disclose information; no privacy/crypto claim. Target full-softmax, ideal arithmetic, fixed model/prefix; suffix proposal unchanged given first token. Proper first-reject cutoff and exact causal continuation required, greedy formal argmax unchanged if exact; production top-p/EOS and finite precision not certified. Change mechanism: introduce correlated, hierarchy-composable repair of latent feedback bits, then independently validate local tokens using optimal target decomposition. This bypasses R28's independent-local-kernel restriction, not contradicting its theorem.

## 2. T: count-tree coupling and optimal Hamming repair
For binary balanced tree over clients, node u stores mass function A_u(k)=Pr(sum_{i in u} B_i=k) with leaf (1-a_i,a_i) and internal convolution A_u=A_L*A_R. Given source node count k, left split distribution S_u^k(s)=A_L(s) A_R(k-s)/A_u(k), right determined. At root transport observed K~Law(K|J) to L~Law(K) with monotone quantile coupling: with U uniform on source CDF interval [F_J(K-1),F_J(K)] draw L=F^{-1}(U). For each internal node use same randomized-CDF-interval construction coupling observed source left count s~S_u^k to target left count t~S_u^l, independent new randomness per node; target right count l-t. Source child count known from upward aggregation. Conditional on both parent counts and ancestor randomness, source splits have their correct conditional laws since ancestors use only counts and independent noise. Inductively target splits follow S_u^l and are conditionally independent across subtrees given parent target counts. Repaired leaf vector C has original independent Bernoulli product conditional on J. Applies also directly to different target odds (then no monotonicity guarantee). Do not condition outputs on the realized repair transcript as though it were original J.
Hamming lower bound for any coupling: d_H(B,C)>=|K-L|, hence E[d_H|J]>=W1(Law(K|J),Law(K)). Poisson-binomial mass functions log-concave with interval support. For l>=k, S_u^l stochastically dominates S_u^k: likelihood ratio proportional to A_R(l-s)/A_R(k-s) nondecreasing in s by log-concavity (extend support at endpoints); right count similarly by symmetry. Thus common quantile realizes s<=t<=s+l-k, both child count differences nonnegative. Recursing gives coordinatewise B<=C if l>=k (reverse if l<=k), so d_H=|K-L| almost surely in exact arithmetic. Root monotone coupling minimizes absolute cost (one-dimensional W1), achieves lower bound. This is minimum number of latent bit changes, NOT globally optimal Token retention for arbitrary p,q. Efron monotonicity and strong-Rayleigh stochastic covering are classical antecedents; application/algorithm structure not claimed new general theorem.
Average over J: E W1<=E|K-K'|<=sqrt(2 Var(K))<=sqrt(N/2) using independent unconditional K', so changed fraction <=1/sqrt(2N). For two-token retention weights w_i<=2, bridge repair X'=X for unchanged B, otherwise draw q_i(.|C_i), then standard p/q SD, loses at most 2 E d_H/N relative to fresh in expected retained old prefix (counting a changed bit as no old-prefix reuse); optimized latent verifier dominates this bridge as below. Bound useful only for balanced count-only selection and independent votes; not general learned nonlinear parameter update. For fixed J extremely rare event may have linear changes. If q=p, exact Hamming optimality yields maximum first-token retention across all couplings because changed vote implies changed token and unchanged votes can keep tokens. No such global optimality for q!=p, weighted prefix, or arbitrary grouping.

## 3. T: optimal latent verification after repair
Do not identify C_i with b_i(Y_i). Let W_i(b,c)=Pr(B_i=b,C_i=c|J). Given B,C, original X_i are independent q_i^b (tree uses bits, not individual token). Choose target conditional r_i^0,r_i^1 depending only on J and fixed known probability/transition summaries, satisfying (1-a_i)r_i^0+a_i r_i^1=p_i, both normalized. For each (b,c), locally maximal-couple q_i^b with r_i^c using independent randomness and residual. Given B,C, output law product r_i^{C_i}; averaging over B and independent C gives product p_i, exact conditional joint output. Even if B_i!=C_i, old token can be retained; C is a latent variable, not forced output vote. After first accepted token, standard causal suffix verification with original conditional q and p, independent RNG; first-reject discard, then exact continuation. Full target product follows first-step joint law and future causal induction under stated assumptions. New verifier need not use full r tables remotely: computed locally once W_i and p/q available; W estimates may reduce retention but do not alter correctness if r normalization and mixture exactly maintained.
Optimize w_i-weighted old prefix diagonal for fixed count coupling:
max_{r0,r1} sum_{b,c} W_i(b,c) sum_x w_i(x) min(q_i^b(x),r_i^c(x)).
Let t_x=a_i r1(x), r0=(p-t)/(1-a_i), 0<=t_x<=p(x), sum t_x=a_i. Separable concave piecewise linear objective. Each x belongs to one original bit class; breakpoints t=a_i q_i^b(x) and t=p_i(x)-(1-a_i)q_i^b(x) clipped to [0,p_i(x)]. Sort segments by descending slope, fill to mass a_i, with earlier segments first on ties. This attains global optimum for fixed latent coupling in O(V log V), not global optimal over all possible count transports. r0=r1=p recovers fully conditioned verifier; r_c=Law(Y|B=c) under ordinary max-coupling q->p is feasible. On unchanged bits its maximal-coupling diagonal >= ordinary SD diagonal conditional on b (old joint kernel feasible). On changed bits bridge discards old first token, optimized latent diagonal >=0. Thus optimized objective >= bridge and >=fully-conditioned. Unrestricted marginal overlap is upper bound. Different objective (first vs weighted two-token) optimized separately, not one joint execution.

## 4. T/P: polynomial propagation and costs
Root joint count table G_root(k,l) from quantile intervals. At node given G_u(k,l), quantile coupling H_{k,l}(s,t) of split laws; accumulate G_L(s,t)+=G_u(k,l)H(s,t), G_R(k-s,l-t)+=same. Leaves give W_i without enumerating 2^N patterns. Marginal child tables suffice for additive expected reward; not independent child transitions given entire global experiment, not claiming table product. Balanced tree naive convolution O(N^2) work, split caches O(N^2) storage, joint propagation worst O(N^3) scalar work using linear overlap of quantile intervals per pair of counts, O(N^2) peak tables/caches (sum squared node sizes geometric). Optimizing all local kernels O(N V log V); requires actual p,q for each context plus optional suffix overlap which costs additional model computation (two-token exact proxy evaluates all possible first tokens, prohibit assuming it free at large V). Sample protocol with cached tables: upward count collection then downward count transport, each O(log N) balanced tree logical levels, plus root and local verification; not wall-time speedup, per-node arithmetic and serialized links matter. Distributed precompute may transmit O(N^2) table entries (depending partition/caching); source probability/count scalar summaries and transition matrices may expose private data. Central flat coordinator with same information and delegation can reproduce exact algorithm, and if allowed all vote IDs once it can avoid physical tree RTT. Strong baselines fresh/AR, independent precommit drafts, R27 sequential, R28 optimized grouping, centralized conditional Bernoulli coupling, same-info flat. No HFL-exclusive necessity and no formal learning improvement shown.
