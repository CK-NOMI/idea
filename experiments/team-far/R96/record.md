## T: preserve output law and compute occupancy
R95 stale-proposal sequential maximal coupling already exact. For fixed draft X, prefetch target distributions at alternative finite-memory histories without changing any accept/repair decision or RNG. Arbitrary draft-dependent caching leaves path unchanged; never choose the emitted token or earlier block termination using unexposed future draft. For position j, probability (conditional on whole X; assuming independent verifier randomness) of first correction at j to y != X_j is w_j(y)=prod_{i<j} alpha_i * (1-alpha_j) * [p_j(y)-q_j(y)]_+ / TV(p_j,q_j), all p_j on original path. A single-substitution state at t>j can be reached via this event followed by no further change through t-1; exact probability adds product of altered-history acceptance ratios, and other histories may merge under last-L state equality. Thus w_j is an upper bound on the contribution from this one path, not on total state occupancy. Exact occupancy with all corrections can be found by propagating the conditional state transition kernel; state count up to V^L, expensive target calls, not deployable for large V. For a fixed set of uncached keys and known probabilities pi_k of being visited at least once, equal per-key cost, additive serial-miss proxy and single prefetch batch, expected saved misses=sum pi_k, so top-K pi optimal; different cost or capacity/critical path dependencies break rule. Prefetch increases total unique target evaluations by #unused keys; does not reduce formal work compared with ideal lazy cache, only moves work earlier. Same-p AR can also prefetch; standard SD tree and adaptive block are strong comparisons.

## Post-audit: componentwise cost bound (P)
For C=a*p_rows+b*q_rows+F*waves, nonnegative coefficients, positive reference C, the fractional saving versus prefix SD is a weighted average of the three componentwise fractional savings, hence at most their maximum. Additional nonnegative incremental costs only reduce it. Across all tested continuation and prefetch configurations the largest bound is L2 4.8032%, L4 11.6649%. Thus none reaches 15% even under this favorable three-component proxy, not a universal hardware latency bound. For L4 regional K1/2/4/8 vs continuation, F/a must exceed 48.00/58.06/64.31/65.75 to break even (same draft row counts, no ranking/calibration costs), useful prefetch fraction 2.04%/1.69%/1.52%/1.49%. Oracle is a first-correction-score oracle, not full occupancy optimum. Stop this family unless hardware measurements invalidate the proxy or a qualitatively different mechanism changes the work frontier.
