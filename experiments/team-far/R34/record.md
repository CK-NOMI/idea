## 1. Actual motivating scenario and contract
DAPO group filtering drops homogeneous reward groups, confirmed original https://arxiv.org/abs/2503.14476 and official verl https://verl.readthedocs.io/en/v0.4.0/algo/dapo.html and NVIDIA NeMo guide https://docs.nvidia.com/nemo/rl/0.4.0/guides/dapo.html. Prior R28 actual source audit confirms filtering after completed rollouts. This is NOT evidence of uncommitted draft-dependent formal model-version selection. Fixed prompt and snapshot, N iid formal full trajectories Y_i~P, binary deterministic reward R_i, pi in (0,1). Condition on E={1<=K<=N-1} where K=sum R_i. Target distribution is P^N(.|E), the actual retained conditional law for the fixed prompt, NOT unconditional independent product or original R30 contract. For dynamic prompt population D, retained prompt law is proportional to D(x) Z(x), Z(x)=P(E|x). Forcing a mixed group for every prompt changes training prompt distribution; need preserve admission probabilities, which are unknown and can cost full generation. Same fixed prompt quota/repeated group is a restricted scenario; not claim a deployed cross-region group. Heterogeneous extension assumes distinct labeled client streams with independent trajectories and comparable binary rewards at fixed versions; different prompts or rewards not conventional same-prompt GRPO. No privacy guarantee. Full standard SD formal sample exactly P under actual q/p, correct residual, causal continuation and EOS/bonus. Experiments use exact precomputed one/two-character probabilities, not full production SD rollout.

## 2. T: exact repair of conditional group with R30 count transport
A=Bin(N,pi); B(k)=1_E(k)A(k)/Z. Given observed source count K draw L from quantile coupling A->B via conditional uniform interval. Conditional on K,L, source success locations uniform k-subset; if l>k choose l-k zero indices uniformly without replacement, if l<k choose k-l one indices uniformly; repaired vector is uniform l-subset. For unchanged reward keep actual source trajectory; changed reward replace by independent P(.|new reward) (e.g. rejection from P). Conditional on labels, retained source trajectory values were independent and repair uses only labels and external randomness; output law exactly P^N(.|E). No duplicate sample, do not force reuse reward class if trajectory identity used for selection. This is simple homogeneous special case of R29/R30 count-respecting monotone transport, no HFL exclusivity. Optimal expected count changes under all couplings = W1(A,B); direction cost c_up=1/pi, c_down=1/(1-pi) for independent whole-trajectory rejection. Directional cost c_up(l-k)_++c_down(k-l)_+ = ((c_up+c_down)/2)|l-k|+((c_up-c_down)/2)(l-k), linear term fixed by marginals; quantile minimizes expected cost within stated repair class. Expected formal draws N+E[(L-K)_+]/pi+E[(K-L)_+]/(1-pi). Full rejection baseline N/Z. Naive repair keep already mixed source groups, homogeneous source -> independent B count then resample changed class. Source is not free, normalization oracle pi not free. Direct conditional trajectory sampler P(.|r) with cheap exact oracle can evade black-box rejection cost; ordinary AR can also use it. In experiment original p, q probabilities computed densely.

## 3. T: unavoidable full-trajectory sample count lower bound (main finding)
Any algorithm drawing an iid full trajectory stream from P, observing its reward, returning N DISTINCT previously drawn trajectories (no synthetic paths, no reweighting, no duplicates), exactly P^N(.|E), finite expected stopping count T, must have E[success draws]=pi E[T] and E[failure draws]=(1-pi)E[T] by Wald/martingale optional stopping. Retained successes L and failures N-L bounded by corresponding counts. Thus E T >= max(E L/pi, E(N-L)/(1-pi)). Since E L=N pi(1-pi^(N-1))/Z and E(N-L)=N(1-pi)(1-(1-pi)^(N-1))/Z,
E T >= (N/Z)[1-min(pi^(N-1),(1-pi)^(N-1))].
Relative possible savings <= min(pi,1-pi)^(N-1) <= 2^(1-N), i.e. N4 <=12.5%, N8 <=.78125%, N16 <=.0030517578%, N32 <=.0000000465661%. For pi=.01,N4 <=.0001% (fraction 1e-6). It is a draw-count bound, NOT wall-time/energy or variable-length token bound, does not cover early certified truncation, conditional proposal generation, exact likelihood-based reuse of q trajectories, gradient-only estimators, duplicate/reweight training or change of objective. In a standard full iid draw oracle, changing scheduling/recycling cannot yield >=15% draw-count savings for N>=4. Also not a general lower bound on SD acceleration per trajectory.
T: heterogeneous labeled distinct streams i with success pi_i; selection of which stream to sample predictable from prior history, finite expected total. Define A_-i=prod_{j!=i}pi_j, B_-i=prod_{j!=i}(1-pi_j), Z=1-prod pi-prod(1-pi). Each selected trajectory must be drawn from own stream. Optional stopping on each stream yields E T_i >= max((1-A_-i)/Z,(1-B_-i)/Z) = [1-min(A_-i,B_-i)]/Z. For positive fixed per-draw costs c_i, whole-group rejection cost sum c_i/Z, fractional saving <= weighted mean of min(A_-i,B_-i) <= 2^(1-N), by geometric mean sqrt(prod pi_j(1-pi_j)) <= 2^(1-N). Same odds/identical source pooling allowed in homogeneous bound; heterogeneous distinct-stream requirement matters. Can reuse unmatched class draws across many independent target groups at fixed snapshot with exact oracle target labels and disjoint trajectory buffers: pre-sample M independent conditional target patterns, draw until success/failure quotas met, retain first required of each class; given requested labels output trajectories independent conditional labels, exact group law. In limit M→∞ expected cost per group tends to lower bound by LLN plus uniform integrability (negative-binomial hitting times finite second moments, quotas <=MN); lower bound thus asymptotically tight in oracle fixed-stream setting. Not a practical scheme across changing policy versions or privacy boundaries; pi oracle and memory cost nonfree. Classical Wald and count coupling, not claim novel fundamental probability theorem. This provides a stopping criterion for R30 application, not a positive full HFL paper.

## 4. T/O: when self-SD could escape the bound
A full q trajectory is not a formal P draw. If exact conditional probabilities Q(.|b), P(.|c) and reward probabilities mu,pi are available, first quantile-couple Bin(N,mu) to B, then uniform bit repair; unchanged class maximal-couple Q(.|b) to P(.|b), changed class draw fresh P(.|c). Exact mixed target; expected retained full trajectory fraction [E min(K,L) O1 + E(N-max(K,L)) O0]/N, O_b=sum min(Q(.|b),P(.|b)). O oracle, not free generation. Arbitrary sequence reward conditional normalizers usually intractable. Conditional p token distribution could be p(y|h)*P(R=c|hy)/P(R=c|h) (Doob transform); only valid with exact continuation probabilities and legal support. Reward automata or certified early termination may offer actual alternatives, prior A/R13 and Selective Rollout have related mechanisms. Must beat direct conditional AR and existing exact self-SD; cannot declare a new mechanism from known Doob transform. Nonlinear optimizer can be matched only if complete admitted prompt/trajectory joint law preserved. Draft-based forced acceptance or empirical pi plug-in generally biases conditional law. No evidence for G2 here.
