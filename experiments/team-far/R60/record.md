## T: cohort coupling without completion-time selection
Fixed current formal snapshot, eligible clients i=1..8, two regions four each, fixed equal target weights, gradient g_i (or independent unbiased estimate conditional on pre-round history), select two per region before current random rollouts/rewards/gradients. Each client marginal inclusion .5. Exact conditional unbiased estimator Ghat=(1/4)sum_{i in S} g_i for G=(1/8)sum g_i. No deadline discarding, committed cohort completion required. Complementary feasible cohorts S,S^c, draw each with probability .5; both satisfy quota, and Ghat(S^c)-G=-(Ghat(S)-G). Within symmetric cohort distributions, any distribution is mixture of 18 complementary pairs (36 total subsets). Independent within-edge pairing gives 9 policies each uniform over 4 subsets; uniform all36 is baseline. For fixed gradients and deterministic or expected cohort duration t(S,m), cost V=E||Ghat-G||², T=E t, proxy J=(V+b)T with b>=0 fixed independent noise floor. On a mixture of complementary pair policies both V,T are affine; if endpoint V and T move in same direction lower endpoint dominates, otherwise product concave along line and minimum at endpoint. Repeating reduces to a single complementary pair minimizing product within this class (not all equal-marginal distributions or all policies). A selected cohort may use AR or SD determined before actual generation; to preserve formal objective, each chosen route must sample exact same conditional p on a fixed legal snapshot, true q, min(p/q,1), normalized residual, causal rejection/bonus/EOS and consistent temperature/top-p/finite precision; greedy target argmax tie contract. No new sampler, no production tests. Equal inclusion does not imply identical random optimizer path, nonlinear Adam expectation, convergence speed or task quality. Current exact gradients for selection require all clients to compute, defeating savings; oracle explicitly not deployable. 
Cross-fit: for two independent unbiased per-client pilot gradient estimates g^A,g^B under fixed snapshot, let d_A(S)=mean_S(g^A)-mean_all(g^A), likewise B. Then E[d_A dot d_B]=||mean_S(g)-G||² by independence; unlike squared noisy single pilot, no positive sampling-noise bias. Can be negative; actual algorithm clips negative cross-products to zero, hence not unbiased after clipping. Selecting minima also has selection bias. Pilot data in experiment split by names, not proof iid; same fixed weights across all. Exact gradient selection cost, stale snapshots, privacy, secure aggregation all need accounting. For candidate proxy with time T_c, variance V_c and extra exposed seconds h per round, improvement over baseline iff h<T_b(V_b+b)/(V_c+b)-T_c. This is a proxy headroom, not true end-to-end training bound. For 15% actual time reduction relative strongest ordinary SD, with baseline critical-path fractions f_l (learning),f_g (generation),f_c (communication),f_o (other), nonoverlap and same number of rounds, need sum f_i(1-r_i)-h/T0>=.15; same task quality and fewer rounds need actual convergence evidence. General DAG/resource contention requires actual traces. Standard same-information flat can exactly implement cohort decisions, pilot statistics and route choice; G2 not met.
