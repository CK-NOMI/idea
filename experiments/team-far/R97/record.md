## H proposed single candidate
Use pretrained early-exit causal Transformer backbone, train compact global/edge/client formal adapters with fixed common parameter basis at first stage. All inference uses same backbone, shallow endogenous exit q_c and full p_c with same authorized region/client identity and pinned version. Default q_c region/client-conditioned rather than forced identical distribution; shared group q_g only as optional route. No independent drafter. Example fixed-feature affine logits formal p_c=softmax((W0+U_g+V_c)y), q_c=softmax((W0+U_g+V_c)x+B0 x+Bg x+Bc x), with all matrices low-rank or fixed-basis updates and identical budgets across arms. This is candidate parameterization, not a full architecture proof. HFL aggregates globally shared coordinates at cloud, regional at edge; private remain local; weighting by sample counts. Freeze shared basis per certified subproblem, not assume convexity for trainable nonlinear features. Use R44 survival-conditioned group split, R88 draft-cost vs accepted mass distinction, R46 same-anchor empirical quality guard. Default local route unless actual measured memory/compute/network advantage under legitimate sharing: equality of prefix, version, masks, positions, and authorized cache for activation reuse; no presumed duplicate prompts; same model weights alone do not guarantee activation reuse. Independent request RNG. Do not count number of active heads as latency. Same-delegation flat allowed; identical physical protocol is not mathematically separable.
## T/H objective and admission
Fixed workload calibration A = sum of all nonempty prefix masses with product min(p,q), C = measured full per-block cost including rejected suffix, all draft, routing and communication; for fixed K, no EOS, one bonus/correction, expected outputs=1+A. Choose split if incremental cost dC < C/(1+A)*dA (fixed cohort, positive C), not based on EAL alone. Share versus local iff C_share/C_local < (1+A_share)/(1+A_local), 15% generation threshold .85 times ratio. Prior results R48 already establish this inequality; not a new theorem. Across changing block states measure long-run total elapsed/generated output; R59 notes start-distribution bias. Actual training/deployment objective is quality-constrained total time to fixed task quality and fixed number of generated tokens, with training and communication. Use R46 lower bound log A>=log A0+S for fixed route/frozen features/affine logits and all clients evaluating final common candidate; local empirical guards not population guarantee. EAL objective overlaps WTV/VAT/VSD; measured cost and structure must add identifiable value. Use true survival and draft-cost traces on calibration, detached route per update, independent quality validation, fallback CE. No claim exact unconstrained full-network optimization. Standard causal SD actual q/p, residual, legal EOS/bonus, fixed version; exact conditional law in real arithmetic for current p, greedy verifier uses formal argmax with tie rule; transformed distributions must be verified consistently, finite precision untested.
