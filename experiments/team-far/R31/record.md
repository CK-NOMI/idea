## 2. T: reverse one-token joint trace
For fixed p,q let m=min(p,q), delta=1-sum m, A acceptance, X proposed, Y formal. Forward standard SD:
Pr(X=x,Y=y,A=1)=1{x=y}m(x),
Pr(X=x,Y=y,A=0)=(q(x)-p(x))_+ (p(y)-q(y))_+/delta.
If delta=0 no rejection. On p(y)>0 the reverse kernel is Y~p, draw A~Bernoulli(m(y)/p(y)); accepted set X=Y, rejected draw X from (q-p)_+/delta, independent of Y conditional on rejection. This exactly reproduces forward joint law by multiplication. If original acceptance uniform U retained, conditional on accepted X=x draw U uniformly on [0,min(1,p(x)/q(x))], rejected on its complement; independent residual choice conditional on rejection. Do not claim exact original pseudorandom seed/path, only law. This is Bayes factorization of known maximal coupling, related to R22 direct common-mass AR and other team target-first/conditional feedback; not new basic coupling. Reversal of entire token/block trace with arbitrary subsequent learner as a concrete stronger falsification baseline is the extension. Standard target-first candidate matching (independent draft) is not generally this joint kernel. If only flag needed, no X/residual draw required; still needs exact p(y),q(y) or equivalent valid probabilities. Computing q(y) may require full normalization, do not claim zero-cost.

## 3. T: entire causal block and training transition equivalence
Given fixed formal AR sequence generated under p, reverse trace sequentially over its actual causal prefixes. At block start and each accepted prefix, sample A conditional on Y via m(Y)/p(Y), reconstruct X as above if observed; on first reject, draw unused original draft suffix autoregressively from q conditional on reconstructed rejected X and prior draft prefix. The rejected suffix was sampled in advance in ordinary forward SD but never influences earlier acceptance or residual under the contract, so its conditional law unchanged. Then close block at rejection, start next block on committed history. If all draft tokens accepted, original standard bonus is next p sample with no draft acceptance flag. Independent posterior draws at reached positions; legitimate adaptive next block length based on already observed reconstructed history can be sampled in order; predeclared length or legal nonanticipating decisions only, not policies reading unreconstructed future draft to choose verification/target. EOS rules must match actual original engine. For fixed horizon, truncation must be identical. Factorization plus chain rule implies joint law of output, proposals, acceptance, rejected unused suffix, block boundaries equal to forward SD. Induction over rounds yields exact same distribution of any measurable learner/aggregator/optimizer state transition that uses such trace and independent same-law randomness, including nonlinear weight normalization or local multi-step optimizer, when lawful model/version decisions depend only on already reconstructed history. Does not imply pathwise equality under identical seed, equality of actual execution time, hardware, energy, memory, timing-based deadlines or information permissions. Full greedy path analogue trivial if q's deterministic greedy and target exact argmax with same tie break, stochastic draft plus greedy verifier needs its actual kernel, not this max coupling. General temperature/top-p can be included only by using actual postprocessed p,q and same exact rules; actual production finite precision not verified. No arbitrary tree/diffusion draft/GBV claim. Separate true forward SD from this AR+replay strong baseline, not claim replay accelerates inference.

## 4. T: conditional learning moment and limits
For example shared shallow/full logit offset theta, p(theta),q(theta) normalized, one token Y and external label y*. Illustrative detached feedback local update (not claim true gradient of selection objective):
G=1{Y=y*}(p-e_Y)+lambda(1-A)(q-e_Y).
First part negative policy gradient for contextual binary reward, second rejection-masked self-distillation with stop-gradient selection. Conditional rejection rho(Y)=1-min(1,q(Y)/p(Y)).
Rao–Blackwell replacement Gbar(Y)=1{Y=y*}(p-e_Y)+lambda rho(Y)(q-e_Y).
Same conditional expectation as G, covariance improvement E[lambda² rho(1-rho)(q-e_Y)(q-e_Y)^T] PSD. Exact same mean at fixed snapshot but stochastic optimizer path/distribution changes, unlike reverse trace replay. Can aggregate conditional mean under fixed linear weights, or weights fixed given all Y, but not generally for nonlinear operations depending on random updates: e.g. D=0 or2 equally, E[D²]=2 != (ED)²=1. Actual Fed-GRPO optional median norm normalization nonlinear; cannot simply substitute client mean and assert exact server transition. True SD feedback and AR+reverse both can create same distribution of G. AR+conditional mean is a lower-variance comparator (cost may differ). Classical Rao–Blackwellization not novel. No direct causal benefit of SD to formal learning distribution if only committed trajectories and reconstructible trace used at matched sample counts. New resource-allocation studies must isolate actual joint computing/physical costs, not merely training loss choice.
