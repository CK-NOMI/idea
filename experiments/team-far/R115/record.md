## T/H
Fix absolute four-position groups, phase in {0,1,2,3} chosen before request; only one in four groups active, all others formal p=q from shallow blocks. At active positions run two deeper blocks with causal attention to active ancestors plus one summary per completed inactive group. Summary is from shallow states (not deep evolution) at each deep layer. Raw summary averages h before LayerNorm, weighted summary averages layer-specific normalized h, then projects K,V and adds log(4) to summary score. Fullkv control preserves all inactive shallow K,V with active queries only; none control drops inactive context (R110-like structural comparator, different periodic gate). This is a NEW formal target, not original dense teacher. Fixed phase is not a learned causal gate; no dynamic budget claim. Future group summaries masked by end position; incomplete groups omitted. For same fixed p/q, standard causal maximum coupling plus residual gives exact conditional marginal p in real arithmetic, discard wrong suffix; no full original model equality, production top-p/EOS/FP or incremental summary KV audited. 
For one fixed query and group of n keys with equal dot-product scores a (need not identical keys globally), softmax group mass n exp(a), value numerator n exp(a) mean(v); replacing with mean key/value and log n bias preserves attention output exactly. For general a_i, mean a_bar and deviations |a_i-a_bar|<=eps, true group mass / proxy mass lies [1,exp(eps^2/2)] by Jensen/Hoeffding; value average may differ because scores correlate with values. This is classical proportional attention and a bounded approximation, not new theorem or exact whole-model reconstruction. ToMe uses proportional attention, SelKV explicitly addresses merged-token mass. Both strong overlaps.

## Decision
Retain causal summary as optional quality-memory tradeoff, not as standalone new mechanism. Reject proven HFL-specific gain and actual speed improvement vs fullkv. No further communication work. Planning potential G1–7 7.6/7.0/9.1/8.3/8.2/6.9/8.6 mean7.96 (subjective, not probability); prior R114 HFR-SD7.93 different candidate, not comparable as promotion. Historical best complete8.14, empirical maturity6.60 unchanged, no80% evidence. The repeated micro-model evidence is insufficient for 1.5–2x strong-baseline target. Next decisive gate: actual pretrained 1B/8B trace and jointly trained sparse architecture, compare matched-quality ordinary MoD+SD, fullkv summary methods, direct sparse AR, same-delegation flat and same total storage budget; measure real incremental KV and GPU batch1/4/16, three nonIID/latency/seed, lifecycle/CI, 1–2x40GB. If unable to access pretrained hardware, do not continue tiny local sweeps as if evidence sufficient. New proposal needs larger removable critical-path share or different problem.
