## Candidate and scope
Fixed common parameter snapshot; authorized common public prefix K/V at cloud, private suffix at edge. New target model, not lossless conversion of pretrained target. Query factor q=U z, z=W_D x, output y=B A v with v concatenated attention outputs, ranks rq and ro. GQA head groups share K/V; all other model parameters may train, but cloud/edge copies of U,A must be aligned/versioned. For each head edge computes private local softmax statistics logZ_S, o_S. Send z and per-head logZ_S; cloud reconstructs q (position/RoPE must be accounted for in production), computes public logZ_P and o_P, headwise alpha_P=Z_P/(Z_P+Z_S), alpha_S=1-alpha_P. Return A concat_h(alpha_P,h o_P,h) and per-head global logZ (or alpha_S). Edge adds A concat_h(alpha_S,h o_S,h), then B. Exact in real arithmetic for this NEW factorized model, not the original checkpoint. Internal shallow path drafts; exact target verification uses ordinary target-first or standard maximal coupling with correct causal tree and processed distributions. No actual decoding implementation.
Backward: delta=B^T dy, g=A^T delta. Edge sends delta and per-head D_S=g_h dot o_S,h; cloud computes D_h=alpha_P D_P+alpha_S D_S, returns D_h and U^T dQ_P (rotate adjoint back if RoPE). Per key a_i=exp(q_h dot k_i/sqrt(d)-logZ); dV_i=a_i g_h, dK_i=a_i(g_h dot v_i-D_h) q_h/sqrt(d), dQ_b=sum_i a_i(g_h dot v_i-D_h) k_i/sqrt(d). Each side computes dA_b=delta outer concat_h(alpha_b,h o_b,h) and dU_b=dQ_b outer z (rotation adjoint as needed); sum across partitions, regions, and accepted loss ancestors; no duplicate loss weights. dB and dW_D computed at edge, shared prefix graph VJP once after summing dKV. Fixed snapshot required; no claim equivalent to asynchronous/multi-local-step FedAvg. Cloud learns shared prefix and interface; edge shares parameter gradients; no privacy proof. Query/adjoints can leak private information. SD only batches candidate queries; exact learning uses committed ancestors, rejected candidates not training data unless separately defined.
