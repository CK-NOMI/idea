## Problem and proposed mechanism
R60 cross-fit pilot estimates had nonzero acquisition costs and failed to beat time-only consistently. Instead use previously computed official gradient cache b_i, or a predictable regional curvature/secant extrapolation b_i=g_i(last)+s_e(w-w_last). No new pilot backprop. Fixed common parameter snapshot, eight equal-weight clients, two regions each four clients, select two per region before current gradient randomness, use complementary cohorts with equal probability; all selected must complete. One common SGD update, not general multi-step FedAvg. Formal objective F=(1/8)sum F_i. Hypothetical fixed self-SD model produces the same conditional target law with real q,p, min(1,p/q), normalized positive residual, causal first rejection/bonus/EOS and consistent temperature/top-p/finite precision; greedy target argmax/ties. We inherit this ideal contract only, not implement or verify an SD sampler. Cost model assumes externally specified SD client times, not model-dependent actual measurements. The edge stores historical gradients, parameter anchors and scalar secants, calculates predicted local imbalance norms; cloud scores complementary cohorts. Same-information flat with delegation can simulate. Prior FedVARP/FedStale make cache correction non-original; proposed combination is an engineering candidate, not an architecture-level discovery.

## T: exact residual estimator and limits
Given pre-round history H_t, choose predictable b_i and a cohort S with conditional marginal 1/2, independent of current gradient noise; E[g_i|H_t]=grad F_i(w). Let B=(1/8)sum b_i, r_i=g_i-b_i. Estimator Ghat=B+(1/4)sum_{i in S}(g_i-b_i) is conditionally unbiased. For fixed true gradients and complementary pair S,S^c, conditional sampling error is +/- d_S, d_S=(1/8)sum_i sigma_i r_i, sigma_i=+1 on S, -1 otherwise. V=||d_S||^2, excluding stochastic gradient noise. Adding any common regional vector c_e to all r_i in that region leaves d_S unchanged (sum sigma within each region=0). Under independent balls ||r_i-rhat_i||<=rho_i the exact worst-case error norm is ||dhat_S||+sum rho_i/8, achieved by aligning each signed error with dhat (any unit vector if zero). In particular with zero predicted residual and only independent radii, the worst-case variance is identical across all complementary pairs; there is no certified gradient-based ranking from radii alone. This is a restricted deterministic uncertainty set, not a general lower bound. Regional summaries u_e=(1/8)sum_{i in e} sigma_i rhat_i yield ||dhat_S|| <= ||u_1||+||u_2||. Tight if aligned; opposing vectors can cancel, so local norms cannot recover cross-edge covariance; use full-vector predicted scoring as strong comparator. Edge three distinct complement-pair norms and six individual cohort max times = nine scalars per region in simplified fixed cost model, plus routing, versions, aggregation; actual max timing depends on resource contention. Each edge stores O(n_e D) gradient/anchor state; exact per-client D-dimensional b_i can be kept locally and reduced, but costs of metadata, scans, privacy and model versioning are not free. Flat with the same local delegates exactly replicates. No HFL-specific advantage established.

## T: why variance-times-time is insufficient
For F(w)=.5(w-w*)^T Hbar(w-w*)+const, Hbar positive definite, G=grad F(w), SGD w'=w-eta Ghat, unbiased errors e with conditional mean 0, exact expected objective decrease D(S)=eta||G||^2-eta^2/2 G^T Hbar G-eta^2/2 E[e^T Hbar e]. Complement sampling contributes d_S^T Hbar d_S; independent equal-coordinate noise adds its covariance trace under Hbar. The local one-step progress/cost rule is maximize D(S)/T(S); not a guarantee of optimal long-run time, especially in nonconvex or multistep settings. Example D0=1, k=.1, V1=.1,T1=2; V2=.4,T2=1: variance*time selects first (.2<.4) while progress/time selects second (.495<.96). Same ordering counterexample for small positive noise floor. If D>0, candidate beats time-only baseline exactly when [D-k V_c]T_b > [D-k V_b]T_c for fixed D,k and isotropic scalar penalty; extra overhead replaces T_c with T_c+h. Actual candidate uses predicted base gradient and regional scalar curvature, not a certified progress lower bound. Oracle sees current all-client true gradients and exact quadratic Hessian, unavailable in deployment.
