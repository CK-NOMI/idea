## T1: random map compilation of R81
Uniform m flags, fixed order, pre-existing independent drafts and fixed local p,q conditional on causal frontier. Each node independently draws its local X~q and private random uniforms; defines for every incoming k the R81 conditional triple (Y(k),R(k),F(k)). Counterfactual randomness may be coupled within a node arbitrarily as long as every conditional entry has the R81 kernel; no cross-node shared RNG or choosing root flag from maps. Let d_x=(q_x-p_x)+, t_k(x)=min(q_x/m,(d_x-k q_x/m)+), r_y=(p_y-q_y)+, a_k(y)=q_y/m-t_k(y). Given X=x, accept unless U<t_k(x)m/q_x; rejection draws Y from r/sum r. On reject, sample outgoing flag by taking floor(m U' r_y/p_y); on accept, floor(m(r_y+sum_{j<k}a_j(y)+U' a_k(y))/p_y). This aggregates all R=1 atoms into one interval; valid because H is surely 1 there, and preserves R81 output and rank recursion. Share U, residual token, and U' across all k (or independent per k as alternative); each actual path has correct law since incoming state depends only on earlier local sources, independent of current map. The shared construction has at most 2 distinct output tokens per node (common draft x and one common residual y), not 2 Transformer forwards. q/p already available at same frontier, counterfactual downstream contexts generally not shared; multi-step, greedy, EOS, top-p, FP and actual model execution not audited.
For adjacent blocks A,B, F_AB=F_B∘F_A, associative, not commutative. Balanced binary tree upsweep stores maps for each block; downsweep gives left child actual input z and right child F_left(z). Exact same state, formal token and repair path as sequential processing with SAME tables, pointwise for any realization. Hence inherits R81 product target and restricted optimality, not any stronger universal optimum; map scan is classic FSM/prefix-sum technique (explicit historical HieraCert/R03 precedent on a different state object). No claim first associative map or generic scan. Work O(Nm) compositions, span O(log N) logical for balanced tree with parallel nodes, each lookup O(1); local p/q prep and residual sampling extra. Code prep naive O(m²V), can reduce via cumulative sum O(mV). No GPU speed claim. N=2^l simple full-tree model counts 2(N-1) upward edges each m*b bits and 2(N-1) downward edges each b bits, b=log2 m; root map unnecessary, possible pruning/colocation improves cost, not lower bound. Relative to N-1 sequential b-bit hops, payload factor 2(m+1), depth 2 log2 N vs N-1. For N8,m4:140 vs14 bits, 6 vs7 logical rounds; N32:620 vs62,10 vs31. All raw payloads ignore framing and routing.
## T2: exact structural compression and limitations

Shared residual/acceptance uniforms ensure at most two candidate output tokens per leaf. Using same U across k produces monotone accept/reject threshold but outgoing maps need not be monotone globally because reject and accept use different y; do not apply endpoint-only coalescence test. Exact check all entries. Constant root map alone does not imply all intermediate outputs independent of initial flag. No actual compression of gradient tensors, no claim privacy; map may reveal private p/q or draft info.
