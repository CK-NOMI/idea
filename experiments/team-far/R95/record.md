## T1 causal state
Fixed block/global anchor a, state s_t=E(a)+Σ_{l=1}^{L} A_l⊙E(x_{t-l}) (available lags only), formal p_t=softmax(W tanh(s_t)+b), q uses only lag1, no separate model. Equivalent shift-register recurrence with nilpotent shift J^L=0. For two same-length prefixes u,v, Δs_t=Σ_l A_l⊙(E(v_{t-l})−E(u_{t-l})); if last L tokens coincide, states and probabilities coincide in real arithmetic. No general Transformer guarantee; shared anchor must be same, and all other dependencies incl positions/processor state must match. An isolated change at j invalidates at most L next states, but subsequent changed tokens may extend closure arbitrarily. Do not conflate state equality with equality of full gradient across different snapshots. Fixed same version, same suffix and anchor give identical local forward and VJP for same output adjoint. For a teacher-forced loss at t, ∂L/∂A_l=δ_t⊙E(x_{t-l}) and ∂L/∂E(x)=sum of incidence contributions, δ_t=W^T(p−e_y)⊙(1−tanh²(s_t)). Shared embedding/readout gradient may be dense, finite-memory local structure not actual training acceleration. Ordinary finite-order AR/cache also benefits. ## T2 exact stale-proposal continuation
Generate draft X_1:B sequentially from q_i(.|X_<i), precompute p_i(.|X_<i) where possible, no selection of earlier accepted decisions using future candidates. Reveal sequentially; at position i, conditional on both revealed prefixes X_<i,Y_<i, X_i has its actual draft-prefix proposal q_i, even when prefixes differ (independent random source per proposal and repair, no look-ahead conditioning). Use p_i(.|Y_<i) from cache iff full dependencies match, else recalculate by exact state delta or direct. Accept X_i with min(1,p_i(X_i|Y_<i)/q_i(X_i|X_<i)), otherwise draw normalized positive residual of these two actual distributions. Conditional output Y_i marginal p_i, hence induction yields entire target sequence. Can continue after a rejection without throwing away candidates, *but repair is potentially serial* and acceptance may decrease. Never replace denominator with q(.|Y_<i) unless same distribution. Precomputed target probabilities may be used only according to past-revealed histories, not to select previous output. Fixed horizon, no bonus, no EOS; greedy use actual p argmax independently, production top-p/FP not tested. Not original dense target. R65 uses equal-state rejoining/re-draft and R91 fixed random maps; here stale proposal retained even if states differ. Related general coupling/causal sampling not fundamental novelty.
