## T: refinement neutrality and version-safe interface
For fixed anchor and complete parent history S, nested region leaf map g_e and common parent g0=r_e∘g_e. Define p_e(y|H)=P(g0(y)|S) R_e(g_e(y)|g0(y),H) E_e(y|g_e(y),H), each conditional normalized on its class. If parent dynamics depend only on parents, sum over leaves/tokens recovers exactly P, irrespective of R/E. For disjoint parameters, gradient of parent negative log-likelihood independent of R/E, and parent q/P acceptance independent of refinement. Thus merely improving private leaf decoding cannot affect deep SD acceptance; joint shared parameters or actual parent/state change required. If leaf affects deep transition, parent-level verification no longer sufficient; exact counterexample: same parent with two leaves leading to next p(A)=.9 and .1. Need full state equality and model snapshot version. Refinement of class partitions increases information of source history but also changes predicted output class; no general monotonicity of I(C;H|M,S) or overlap when both change. Refinement of output partition alone weakly decreases overlap by triangle inequality; merging increases overlap, not necessarily quality. With fixed predicted target C and refinement of history S, irreducible KL decreases by I(C;S_refined|M,S), not necessarily actual fitted quality. Parent distributions can be reused across local refinements only if all dependencies including P/q, state map, version, position and stopping rules unchanged. New model not exact old dense teacher. 
For a fixed block with R tokens remaining and no EOS before boundary, draft cap R-1: for any fixed q/p chain, using standard rejection/bonus, drafting final token versus directly sampling p as bonus has identical probability of reaching each formal position/number of committed tokens under same earlier randomness; last token is formal regardless of rejection, so extra q call unnecessary. Need same formal rows and same earlier RNG; output distribution same, sample may differ. This is standard horizon-aware SD, not a new claim. Any optimized token SD with factorized p=P E and q=Q E can do same (R66). Direct class AR strong baseline; same-info delegated flat can replicate all nested decisions. 
H: for online split/merge use stable global parent IDs, versioned regional leaf maps, commit only at block/version boundaries; preserve probability on split using normalized conditional mass, merging sums child mass; does not preserve future dynamics unless lumpable or recomputed. Fit constrained objective quality + measured exposed validation cost, optimize same-leaf budget. Do not assert HFL necessity from nested labels. To test physical HFL advantage need realistic restricted edge uplink/permissions, equal delegated baseline and actual communication; not done.
