## T/H
Given quantized row z in {0,...,15}^d, scale s, shared deterministic predictor t(u) and modulo residual e=(z-t(u)) mod16, decode z=(e+t(u)) mod16. Exact integer and identical dequantized state if s and arithmetic identical. No claim lossless relative FP32 h; new target p uses quantized active h and original q off. To use standard exact stochastic SD the actual active drafter law must match the verifier's q (e.g. both use same reconstructed state); if client draws from original q but verifier uses q_quant, correctness fails generally. Causal gate must be known before candidate sampling and version/caches consistent. This round only actual teacher-forced sparse forward and codec, no actual greedy or stochastic rollout. Prior R112 stochastic results apply only to its own original target. 
For side information U available both sides and vector Z, expected optimal lossless code bound H(Z|U); difference from unconditional H(Z) is I(Z;U). If U not available and must be sent, H(U)+H(Z|U)=H(Z,U)>=H(Z). With existing side information C, same conditional identity. This is classical information theory, not a novel theorem; finite codebook/model costs and suboptimal baselines matter. Consecutive active parents within the same valid proposal packet: parent token at row j+1 is preceding proposed token, available in packet metadata. Need explicit first parent after gap/packet boundary (or other proven side information), prefill handling, rejection invalidation. No real SD packet alignment measured. Teacher-forced x/y adjacency used as a proxy for proposal metadata, no future data used to predict z of current parent.
