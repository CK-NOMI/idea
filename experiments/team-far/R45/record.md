## Problem and candidate
Frozen shared shallow x(h), deep y(h), fixed vocabulary V. Personalized formal logits W_e y, p_e=softmax(W_e y), W_e=W_g+R_e (or cloud+edge+client decomposition, R_e total). Shared shallow base U and shared transport B, q_e=softmax((U+R_e B)x). At future version use U_new=U_old+(W_g,new-W_g,old) (identity transport for global drift in tested variant) and current R_e with frozen B. No per-client auxiliary head retraining after version change. B can be identity, dense feature ridge, or shared diagonal b trained on old formal models by conditional KL or exact two-token EAL. Distinguish from R39/FCRH: frozen old base plus future residual-only transport and cross-version heldout EAL, not novelty of a linear bridge. In tested experiment client formal heads learned independently, cloud mean computed afterward, no physical HFL or actual edge aggregation; hierarchy is architectural hypothesis, not implemented. SD feedback into formal parameters not exercised. Proposed future formal update quality constrained, not a new optimizer.

## T: exact log-odds drift compatibility and limitations
Let C=I-11^T/V. For fixed shallow/deep features and a formal parameter increment D, a proposal increment D B reproduces the formal log-odds increment iff C D(y-Bx)=0 for the prefix. This follows because log-softmax differences remove common additive scalars and C projects them out. For a family of regional increments D_e, common B works on all prefixes iff y-Bx lies in intersection of ker(C D_e); if stacked centered increments have full column rank, this forces y=Bx. If two legal prefixes have identical x and a difference y1-y2 not in that intersection, no such shared deterministic map reproduces all drift, even a nonlinear common feature translator. This concerns log-odds changes, not equality of p and q if their baseline probabilities differ. With changing backbone features, proof no longer directly applies. A fixed linear B commutes with convex aggregation of increments, (sum alpha D)B=sum alpha DB, but this is elementary linear algebra and same-information flat can reproduce. If D=A L is rank-r LoRA, DB=A(LB), rank<=r; right multiplication respects factor gauge, whereas separately averaging LoRA factors need not. No extra private draft adapter required given formal adapter, but shared U, B and compute/storage for materialized heads remain; a shared diagonal is d extra scalars, dense B d^2, independent full draft heads E V d, independent rank-r increments E r(V+d), subject to actual placement/optimizer state. Plain tied output W_e B uses only B and is stronger, no extra U. No claim new base math.

Probability bound: for logits z,z+delta, integrate softmax derivative p_i'(t)=p_i(t)(delta_i-E_p delta); sum abs <= range(delta)/2 by mean absolute deviation bound (Cauchy-Schwarz and variance <= range^2/4), so TV <= min(1,range(delta)/4). The acceptance-mass transition K_q(h,x)=min(p(x|h),q(x|h)) is substochastic. For fixed target p and two q policies, telescope products using K_{q'} up to t-1, difference at t, K_q after t; tail masses <=1. Thus |EAL_K(q)-EAL_K(q')| <= 2 sum_{t=1}^K (K-t+1) sum_{|h|=t-1} mu_{q'}(h) TV(q(.|h),q'(.|h)), where mu is prefix survival mass under q'. This bound is directional in choice of reference but bounds absolute difference, can swap references. Combine with logit range to get sufficient finite-window error bound for transport-vs-reference proposal, not guaranteed improvement and not exact if baseline discrepancies ignored. Counterexample identical x and y1-y2 visible to centered D means no universal drift map. W=0 uniform target can trivially maximize acceptance but destroy quality, hence frozen p in this experiment. Standard exact stochastic SD conditional kernel with actual q and p uses min(1,p/q) and positive residual (p-q)_+; real arithmetic sequence law by induction, greedy fixed argmax tie. No sampled generation, EOS/top-p/FP or batched implementation here.
