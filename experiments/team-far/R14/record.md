## T: learning event distribution and dominance
One fixed model snapshot, four clients with weights 1/4, two regional weighted gradient vectors g_e, global g=sum_e g_e, M_j=sum_e |g_ej|, S=sum_j M_j, L=||g||_1. Zero S implies all zero, return zero. Sample e with probability ||g_e||_1/S, then j with |g_ej|/||g_e||_1. Marginal proposal q_j=M_j/S, query signed g_j across regions. Accept with |g_j|/M_j, else null. No independent draft model. Successful coordinate has distribution |g_j|/L if L>0; for one attempt G=S sign(g_j)e_j on success, else 0. Exactly unbiased stochastic gradient, NOT equal to dense SGD path. Fixed number K independent attempts and averaging preserves unbiasedness. Repeating until acceptance changes expected step scale unless L available; if L=0 cannot repeat. Expected tries S/L if L>0. Triangle inequality ensures M>=|g|. Grouping before taking absolute values decreases S monotonically, may improve acceptance; no guarantee across alternative nonnested partitions. All terms at same snapshot and client weights, no equivalence to multi-local-step FedAvg.
Key strong baseline: same proposal and same signed query, return H=S g_j/M_j e_j. H=E[G|j]; variance trace H <= G. Moment order L² <= S sum_j g_j²/M_j <= S L <= S²; subtract ||g||² for trace variances, divide by K for iid averaged samples. First bound Cauchy–Schwarz, last triangle; g=0 makes all but local zero, if S>0. Local one-coordinate mixture estimator S sign(g_ej)e_j has moment S² and same expectation, often cheaper because no global query. Uniform HT moment D||g||², exact global-magnitude sampling moment L² (oracle requiring full g or exact specialized sampler). Conditional on j, HT deterministically uses already acquired exact values; rejection only useful if exact signed-event law itself required, which has not been justified by optimization objective. Ordinary importance sampling, classical Rao–Blackwell, rejection sampling; not novel foundational math.
Connection to self-SD: region internal shallow CE head grad sh_e could propose learning directions, but a valid envelope requires residual bound. Oracle M'_j=sum_e(|sh_ej|+|g_ej-sh_ej|)≥M_j by triangle. It can only reduce acceptance relative to M using same snapshot. Cheap tighter certificate not supplied. Token acceptance A=1-TV(p,q) unrelated to signed-cancellation acceptance: 2 clients with p=q=(.5,.5), same scalar feature 1, opposite labels, equal weights, global CE g=0 yet token A=1, S>0. Reverse: same label and identical gradients, A_learning=1 even if shallow/deep p differ. Learning and inference proposed event distributions are different; cannot claim gradient verifier is an implementation of token SD. Ordinary AR same internal head and same estimator, ordinary SD can be independently applied after training. Standard fixed-target token SD exact only with genuine processed p/q, residual correction, causal prefix and independent randomness, bonus/EOS/precision; not implemented here. No G2 necessity.

## P: cost and strong baselines
At regional boundary R=2, d=432, FP32 values: dense regional upload 3456B/round; local atomic 16 coordinate/value pairs (uint32+FP32)=128B plus masses8B, and broadcast/metadata; HT/thin require proposal ID from sampled region, broadcast to both, both signed values plus abs masses recover M at root; optimistic 16*(4+2*4+2*4)=320B incl two distinct downlink index copies, two masses8B, no control/version overhead or model broadcast; exact batching possible, repeated indices may be dedup, local client→edge traffic still dense unless separately compressed. Uniform shared indices known via common seed (no ID communication required), 16*2*4=128B plus metadata; same-query HT has no additional rejection cost. Local and uniform can be much cheaper. All methods full deep gradients already computed in actual audit; shallow oracle needs residual already known, no speed claim. Equal K is not equal byte or time budget. Compare ATOMO, error-feedback sparsification, correlated quantization, distributed coordinate sampling, full-gradient/dense, uniform HT, envelope HT, global magnitude oracle, ordinary HFL+production self-SD, flat same-region delegation. No DP; signed coordinates and mass disclose information. Good result same quality/budget strongest baseline true total time −15% or useful work +20%; no evidence.
