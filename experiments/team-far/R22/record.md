## 2. T: nested exact acceptance certificates and complementary computation
For stage r, B_i^r=w_i^T U_{1:r} U_{1:r}^T delta. Radius R_i^r=||U_{r+1:d}^T w_i|| ||U_{r+1:d}^T delta||. c_i^r=min(1,exp(B_i^r-R_i^r)/sum_j q_j exp(B_j^r+R_j^r)). With exact real arithmetic c_i^r<=min(1,p_i/q_i). For tau>0, nested thresholds t_i^j=max_{a<=j}(1-tau)c_i^{r_a}; t_i^0=0. Sample X~q and one independent uniform u. At first j with u<=t_X^j, accept X and mark stage J=j; otherwise compute missing coordinates and p exactly, then SAME-u standard SD acceptance or positive-residual sampling. This realizes identical real-arithmetic standard token-level SD; if schedule is determined before current X/u from legal past/context and future draft candidates not used, sequential prefix induction, first-reject truncation and legal bonus/EOS preserve sequence distribution. Greedy exact fallback or interval certificate possible but NOT executed here; temperature/top-p/penalties/EOS/FP tolerance not validated. Incremental partial logits B_i^{r_j}=B_i^{r_{j-1}}+sum_{a=r_{j-1}+1}^{r_j}(U_a^Tw_i)(U_a^T delta); full recovery by complement, no repeated computed coordinates. For fixed final rank and nested schedule, expected coordinate count weakly decreases relative to evaluating final rank upfront (for same final threshold use max of included prior certificates; even if final bound not monotone, nested max remains valid), not necessarily actual cost.
## 3. T: stage-coalesced conditional score
For formal emitted Y=i, stage j joint probability m_ji=q_i(t_i^j-t_i^{j-1}), full joint mass f_i=p_i-sum_j m_ji>=tau*p_i. Proxy distribution p_j=softmax(W s_theta+B^{r_j}), proxy moment mu_j=sum_l p_j(l) A_l. Mark j score A_i-mu_j. Full branch score A_i-mu_F(i), with mu_F(i)=(p_i mu_p - sum_j m_ji mu_j)/f_i. Conditional E[score|Y=i]=A_i-mu_p, exact by substitution. Unique deterministic fallback given fixed proxies/marks; conditional variance trace times p_i = sum_j m_ji||mu_j-mu_p||² + ||sum_j m_ji(mu_j-mu_p)||²/f_i. No general variance superiority; tau prevents singular correction. R21 binary mark is one-stage special case. Most importantly mu_F(i)=sum_l A_l b_i(l), b_i(l)=[p_i p(l)-sum_j m_ji p_j(l)]/f_i, a signed vector of sum1, not a probability distribution. Thus for the fallback only one V*k moment multiply, regardless of number of stages. Early branch also computes only one moment. Need retain/recompute prior logits/proxy distributions and thresholds until emitted Y determined; O(VL) worst storage, scalar blend O(VL), reductions/exp kernels nonfree. No per-trajectory gradient equality, no full parameter score, no PPO ratio, nonlinear Adam moments or reward depending on internal marks. R21 causal on-policy argument applies if schedule/marks don't influence target future sequence kernel; fixed snapshot and reward of emitted path, not hidden execution.
## 4. T: direct autoregressive replacement (CRITICAL)
Using exactly the same q proposal and nested certificate stages, an exact DIRECT single-token target sampler can emit X on marked event, else draw from (p-l)/F where l_i=sum_j m_ji=q_i t_i^L, F=1-sum_i l_i. Since p=l+F*(p-l)/F, the joint law of (Y,J) including full event matches candidate SD. The same conditional score and stage work are available without speculative multi-token blocks; stage reach is determined solely by X,u and identical for the two algorithms when coupled. This is not ordinary dense AR and is a necessary strong comparator. It doesn't match SD multi-token block scheduling or batched target hidden-state computation, so not a universal latency domination, but proves no distinct *single-token* HFL/SD learning primitive. Same-information flat can aggregate coordinate statistics and select same schedule, no demonstrated hierarchy advantage. No claiming G2.
