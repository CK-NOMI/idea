## Problem and assumptions
Fixed same public/authorized prompt, frozen identical formal causal policy p, fixed L, comparable deterministic binary reward R. Each of E regions knows a finite set A_e contained in {R=1}, potentially overlapping. Raw reference sets remain local, but authorized prefix-cell moments can be exchanged. Common prompt/model, legitimate distributed sharing and useful overlapping certs are hypotheses, not actual HFL workload evidence. Distinct local policy versions or reward definitions invalidate exact pooling. No privacy guarantee: moments, routing and prefix queries can leak; secure aggregation/access policies require separate implementation. R36 single-client certificate cannot handle unknown overlap by simple summation.

## T: partition of unity certificate
Choose a public prefix-free exhaustive partition U of complete trajectories (e.g. first token); for each cell u choose nonnegative weights lambda_ue summing <=1. Define r(y)=sum_e lambda_{u(y),e} 1_{y in A_e}, hence 0<=r<=1 and r=0 for incorrect paths even with arbitrary overlaps. Define a=E_p r, p_C(y)=p(y)r(y)/a, p_B(y)=p(y)(1-r(y))/(1-a). For 0<a<1, p=a p_C+(1-a)p_B pointwise. Draw independent Bernoulli(a) per group member; conditional independent sampling yields exactly p^N; draw C count binomial and uniformly label equivalently. If only first-step fixed-length binary on-policy group gradient expected value is required, replace each C score by its conditional mean. No full stochastic optimizer path preservation; do not call clipped PPO/variable length/other regularizers equivalent.
Moments per cell and region: a_ue=sum_{y in A_e intersect cell} p(y); g_ue=sum p(y) S(y); b_ue=sum p(y)||S(y)||^2. Then (a,g,b)=sum lambda_ue(a_ue,g_ue,b_ue), mu=g/a, D=b-||g||^2/a. Choose lambda before fresh sample and freeze when differentiating: mu=grad log a for fixed lambda (not differentiating selection). No need raw union or overlap counts for these moments. For original total success probability pi, N group members and L fixed tokens, R36 total covariance theorem extends to soft event (r<=R): trace reduction = [(1-pi)-(1-pi)^N]/(pi N L^2) * D, unconditionally with zero degenerate reward gradient; divide by Z=1-pi^N-(1-pi)^N for admitted-only fixed prompt. This follows from conditioning on C tags and all residual paths; conditional M|K~Bin(K,a/pi). D is concave in lambda (quadratic-over-linear convex), so max D over product simplexes or linear cost constraints is convex optimization in standard terminology; hard one-owner-per-cell discrete restriction not guaranteed optimal. Weight selection at same snapshot costs extra; score moments may be dimension P and expensive. Region ID of C event must not be used as additional conditioning for pooled mean if claiming pooled scatter gain. For any fixed cell, mass-max hard owner attains max_e a_ue; sum across cells >= any global single-region mass and any constant-simplex mixture. Does not imply mass-max scatter dominance or superiority to true union. Actual coordinate ascent maximizes D locally, no global optimum guarantee.
Counterexample: two regions each hold identical singleton probability .4, naive sum .8 while union .4; disjoint .4 sets same marginal masses but union .8. If only local masses known no exact union mass from these alone. Our fractional mechanism preserves p without reconstructing true union; it can lose coverage (e.g. two disjoint same-cell sets each mass .4, hard routing .4 vs union .8). With full union known oracle, r_oracle>=r pointwise and D_oracle>=D by weighted scatter update; not new basic theorem.

## T: conditional SD and route
Define H_r(h)=E_p[r(Y)|h], for valid prefix h. p_B(x|h)=p(x|h)(1-H_r(hx))/(1-H_r(h)); q_W(x|h) proportional to q(x|h)(1-H_r(hx)), for actual shared shallow q and positive normalizer (target-only fallback otherwise). H_r is linear in local futures with lambda held fixed. For first-token hard routing, root needs per-token selected certificate masses, after first token only chosen region has nonzero certificate contribution, so further certificate queries can be local to that region if it is authorized and capable of executing target/q; migration, model and data privacy, KV and communication overhead not implemented. All-region root moment/score collection and ownership selection still cost; does not imply fewer total bytes. Standard maximal-coupling exact local kernel with actual q_W and positive residual; causal continuation/rejection/bonus rules imply conditional sequence law then mixture recovers p. Conditional greedy not original greedy; original greedy must use p argmax. No production top-p, finite precision, actual multi-token SD or real transfer. Strong AR+same certificate can reproduce learning, and same-info flat with delegation can reproduce routing; not claim HFL uniquely necessary or G2 achieved.
