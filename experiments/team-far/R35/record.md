## 1. Contract and relation to previous results
One fixed prompt, policy snapshot, processed formal autoregressive p, known reference sequence a of fixed length L; reward R(y)=1 iff all L output tokens match a exactly. Fixed output length, no variable EOS or alternate valid paths; tokenizer, support and probabilities consistent. N independent full trajectories. DAPO-style admit if mixed binary reward, E={1<=K<N}. We want full admitted prompt/trajectory law, not only an unbiased gradient or stop training on arbitrary failed suffix. Rejected groups need not return trajectories; when admitted must complete every trajectory. No claim that typical mathematical reasoning reward reduces to a fixed sequence, or that real HFL needs shared cross-region groups. Region may keep private references under authorized computation; no DP guarantee. A/R13 early reward-score truncation and FOAS shared-prefix AR are antecedents; R34 proved full black-box sample bound, which does not constrain partial path probability queries. R30 count transport retained as math reserve, not actually required here. Same-head ordinary AR can implement all reference logic. Shallow q is used only in batch planning below, not as ordinary max-coupled SD proposal; no independent full draft model, no claim that self-SD alone produces the savings.

## 2. T: exact lazy group admission via first-deviation law
Define s_0=1, s_t=prod_{j<=t}p(a_j|prompt,a_{<j}), pi=s_L. For one independent U_i~Uniform(0,1), define deviation tau_i=min{t:U_i>=s_t} or L+1 if none. Then P(tau=t)=s_{t-1}-s_t, P(tau=L+1)=pi. On deviation at t, formal token distribution is p(.|reference prefix) conditioned not a_t; draw it independently of U_i given t, then sample formal continuation autoregressively conditional on actual prefix. If no deviation the trajectory is exactly a. Product of these probabilities reproduces original P for every trajectory. Independent U and independent conditional draws per trajectory preserve product law. Because all U_i>=s_t implies all trajectories fail, group can be rejected before computing remaining reference path; if at final all U_i<s_L, group all correct also discarded. If mixed, generate all actual mismatch tokens and suffixes; cannot leave out failed member suffix in admitted group. A selected suffix may run exact internal SD using actual conditional q,p, valid residual, causal state, EOS/bonus rules as appropriate; not implemented in experiment. Group acceptance probability Z=1-pi^N-(1-pi)^N, same original prompt admission D(x)Z(x). Uniform boundaries probability zero in real arithmetic; finite precision certification and rare-tail stable products not tested. Greedy fixed output is deterministic/all same for a fixed prompt absent external stochasticity; no general greedy or top-p system guarantee. Causal probabilities may be postprocessed if exact and same as formal engine. For multi-answer finite trie one can sum allowed path masses, exponential in depth/branching in worst case; do not claim cheap exact conditional normalizers for general rewards.

## 3. T/P: cost separation and strong AR equivalence
Counting formal probability positions, no batch FLOP/time claim. No cache sharing for divergent suffixes (same assumption for all schemes). Baseline full generation NL per candidate group. Early rejection per trajectory with defer-until-admission has N sum_{t=0}^{L-1}s_t reference-position cost plus expected suffix work S=N[1-(1-pi)^(N-1)] sum_{t=1}^L(s_{t-1}-s_t)(L-t). Shared-prefix AR with lazy exact admission has reference-position cost sum_{t=0}^{L-1}[1-(1-s_t)^N], plus same S. Full reference teacher forcing cost L+S. These formulas hold per candidate prompt; fixed admitted quota cost may depend on prompt distribution/normalizer, not reported wall time. Shared-prefix AR can perform the same lazy algorithm and achieve identical cost, or better with suffix trie; no SD or HFL necessity. No cost of mismatch sampling/reward checking/cache/communication counted. The apparent huge savings over naive full generation mainly result from exact early rejection and deterministic reference prefix sharing; no claim physical speedup. Greedy path/production numerical fidelity not demonstrated.

## 4. T/P: state-dependent batch planning
Consider known reference chain, at t verified positions and m trajectories still on it, one target batch k future reference positions has model cost a+k in units of position work (a>0 fixed invocation overhead); remaining live count M~Bin(m,prod_{j=t+1}^{t+k}p_j), given prior surviving U conditional uniforms and no selection depending on hidden exact surviving uniforms beyond count. Fixed path q-derived policy depends only on t,m and known model predictions; does not change formal admission/output. Under this restricted state-only policy class, DP C_p(t,m)=min_k[a+k+E C_p(t+k,M)], C_p(t,0)=C_p(L,m)=0. Oracle p probabilities all known are not free. Plan using q reference probabilities, then evaluate cost under p; this is planning not replacement of p, exact regardless of prediction error. Actual uniform values are available in RPA, can enable stronger scheduling; DP is not global optimum over all information or GPU batching. Fixed-k baselines k=1,2,3,4. Target AR can also batch known references, use q for same schedule or a learned cheap cost predictor; no necessity claim. Real q overhead, cache, batch scaling, suffix SD, physical transfer and optimizer excluded. A hypothetical q overhead of 2 target-position units (4 shallow positions at half cost, no launch cost) is tested, not measured.
