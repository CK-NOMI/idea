## T: independent population outputs, rather than correlated formal trajectories
At a fixed complete shared state and snapshot, N exchangeable slots must emit iid formal class tokens with law p, shallow endogenous draft q iid. Same complete p/q for cohort; heterogeneous target versions, raw state affecting deep class distribution, constrained/processor differences, private nonexchangeable trajectories cannot be silently pooled. Let X~Mult(N,q), Y~Mult(N,p) be draft/formal count vectors. Given Y, uniformly assign its multiset to labeled slots (or use permutation-equivariant maximum token-preserving assignment from iid labeled X and count-only coupling, without using downstream drafts, rewards, or private labels to choose). For any labeled output y with histogram c, Pr(y)=Mult(N,p)(c)/(N!/prod c_i!)=prod p_{y_i}. Thus exact iid labeled formal outputs, not merely marginal correctness, conditional on legal presampling state. No change in law of formal-only GRPO/other downstream learner if all steps preserve complete conditional joint law; only one step implemented here. Different client reward functions can be applied after correct assignment, cannot use them to bias assignment. If whole future draft tree reused, selection must depend only on current counts/independent RNG and not downstream proposals; reused subdrafts conditional iid q at same full state, regenerate others, never assume wrong-prefix fine tokens valid. Multi-step proof and implementation not completed. Unlike R27–30 version-conditioned bit-count repairs, no selection gate or posterior condition; unlike A/R04 correlated formal outputs, target is exact product; classical multinomial sampling/Strassen and transport are not new foundational math. 
Define deficit D={i:p_i>q_i}, surplus others. Standard independent per-lane maximum coupling accepts min(1,p_i/q_i), rejected residual p-q positive; any offdiag token moves surplus -> deficit. Hence for every class Y_i>=X_i on D, Y_i<=X_i otherwise. This yields simultaneously minimum expected count movement E[sum_i (Y_i-X_i)_+]=N TV(p,q), and minimum expected new occupied classes E[sum_i 1{Y_i>0,X_i=0}]=sum_i [(1-q_i)^N-(1-p_i)^N]_+. General lower bound follows from expected count differences and marginal empty probabilities; coordinatewise monotonicity attains both, for arbitrary nonnegative fixed per-class weights on these individual costs as well. Consequently a new count kernel cannot improve those metrics over ideal ordinary per-lane SD (same-state dedup). 
Binary randomized quantile transform U uniform in [F_q(X-1),F_q(X)], Y=F_p^{-1}(U), attains the two minima by monotonicity. General multinomial sequential binomial transform with arbitrary fixed category order, remaining q/p totals and conditional binomial CDFs yields exact multinomial target by conditional induction, but NOT necessarily componentwise monotone for K>2; no guarantee of better count movement/occupancy. Counts are finite with floating CDF underflow/rounding risks; audit not production proof.
 
## T/O: maximize complete histogram equality without sacrificing the two minima
Independent token maximal coupling has Pr(X=Y)=(1-TV(p,q))^N, since no cross-sign cancellation. Global count maximum is sum_x min(Q(x),P(x))=1-TV(Mult(N,q),Mult(N,p)). Claim: a single count coupling can attain this upper bound and both previous minima simultaneously. Define partial order x≼y iff all deficit coordinates nondecreasing and all surplus coordinates nonincreasing (equal p=q coordinates fixed by coupling). Independent per-lane coupling produces a feasible transport supported on this order. Remove common mass m(x)=min(Q(x),P(x)) from each marginal. For any increasing set A, Q(A)<=P(A) still holds after subtracting same m. Strassen finite stochastic order theorem implies residual monotone coupling exists; add diagonal m. Constructive alternative: remove original diagonal, treat offdiag mass as directed acyclic flow with divergence Q-P; topological order by total deficit count; decompose flow from positive-divergence origins to negative-divergence sinks, reroute along transitive closure, and restore max diagonal. This preserves support and marginals, yields three optimal metrics. Classical maximal monotone coupling/flow decomposition; novelty is scoped population verification application, not claiming new general theorem. 
Binary N fixed, binomial likelihood ratio monotone in count, residual supports strictly ordered for p!=q; standard maximal coupling of two count laws with independent positive residual remains monotone. Can compute exact finite binomial pmfs O(N) using stable recurrence and one residual categorical sample; no per-lane rejection loop needed at count stage. K>2 full histogram support size S=binom(N+K-1,K-1), naive graph up to S^2 edges and flow decomposition may be worse than independent O(N) token correction. For K4,N32 S=6545; K8,N32 S=15380937. No scalable general exact implementation; the exact bound for K4,N32 is enumeration only. Approximate kernels must preserve formal product law or use exact fallback, not accept numerical near equality. 
Potential HFL interface: at homogeneous cohort edge, exact count-equality event can skip all reallocation of lanes; if differing, preserve maximum matched slots (uniform within equal labels), reallocate necessary slots. When count equal and downstream class history fully matches, original candidate subdraft allocation stays. This may reduce fixed transaction/coordination events, not expected moved count or missing branches. A model where each nonzero correction incurs fixed B plus per-slot cost c has cost B*Pr(X!=Y)+c*N*TV; improvement in first term only. For K4,N32 avg .760028→.295413 event fraction (61.13% fewer events), but this assumes an exposed group-level fixed cost and actual region protocol, not measured. Strong local independent SD can aggregate correction instructions into one message; if no exposed fixed cost, benefit zero, increased exact transport work loses. Direct class AR can generate exact counts and all necessary target states without rejected branches, same grouped backward from R68; same-info delegated flat reproduces kernel. G2 unresolved. Potential future work restrict to binary state refinements where count transport O(N) and use actual edge synchronization trace before building multi-step protocol. No claim that binary compression preserves model quality.
