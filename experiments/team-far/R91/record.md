## Problem and model
R90 showed same-target cached AR's work-set inclusion for ordinary SD. Explore changing the formal model itself to have additive causal dependencies that support random-map invariance under corrections. Anchor a fixed outside-block observed character h, block length B, vocabulary V, regional parameters W_e. For i=1..B, logits L_i(y;x_<i)=A(h,y)+sum_{j<i} W_{e,i-j}(x_j,y). Formal p_i is softmax of these logits; inner prediction q_i is softmax A(h,.), no independent draft LM, but a simplified log-linear conditional model. Not equivalent to an old pretrained Transformer. No explicit learned sparse graph masks in this experiment. Fixed block and vocabulary, no EOS; target fixed before random draws. Shared anchor A uses global mean client gradients; each regional lag table update uses .7 times mean local edge gradients plus .3 global mean (plus regularizer). Two logical edges four clients, one common snapshot per edge, no physical deployment. Verification failures feed next-round heuristic lag-specific regularizer; no claim exact gradients of runtime.
## T1 random-map certificate
Independently sample standard Gumbels G_i(y) across positions and vocabulary before generation, preserve them for all refinements. Define F_i(x_<i)=argmax_y[L_i(y;x_<i)+G_i(y)], deterministic tie priority. Unique causal fixed point x_i=F_i(x_<i) by induction. Since x_<i depends only on earlier Gumbels in final fixed point, each x_i has the desired conditional softmax distribution. Correctness is pathwise equality to ancestral Gumbel sampling under the same noise, not a maximal-coupling guarantee or conventional SD min(p,q) acceptance; matching initial q under common noise is not 1-TV in general. Greedy uses zero noise and same tie priority; theoretical but not executed here. Fixed temperature>0 can scale logits in the certificate and sample independent Gumbels; top-p and EOS not implemented, do not assert production correctness or bitwise equivalence.
At any stage known predecessor set K_i, unknown U_i, let a_i(y)=A(h,y)+G_i(y)+sum_{j in K_i}W_{e,i-j}(x_j,y). For candidate c, define M_l(c,y)=min_{u in allowed symbols} [W_{e,l}(u,c)-W_{e,l}(u,y)]. If for every y!=c: a_i(c)-a_i(y)+sum_{j in U_i}M_{i-j}(c,y)>0, c is the unique winner for every completion of unknown predecessors. For full Cartesian allowed sets this is necessary and sufficient for strict robust winner (minimum separates across unknowns); correlated feasible predecessors could permit tighter bounds; with non-strict ties use tie priority or fallback. Independent box lower bound min W(c)-max W(y) <= M_l(c,y), so pair certificate is at least as tight for a fixed candidate. A candidate chosen from a partial score alone may miss a robust winner; any fully feasible representative completion's exact winner finds the only possible robust winner if one exists. Pair matrix precompute O(L V^3) arithmetic, O(L V^2) memory for lag count L; per candidate O(V|U|) table terms, plus known partial scores, argmax and traffic; must include refresh after weights change. Not scalable to V~100k as written. Classical robust margin and Gumbel search, no generic certification originality.
## T2 causal preservation and finite refinement
Initialize all block positions with q Gumbel winners. A certificate freezes a position only if invariant over all unknown predecessors; all known positions are exact by induction. Any unresolved position with all predecessors known can be solved exactly; each parallel wave fixes at least the first unresolved position, hence at most B waves. Hybrid evaluates unresolved positions at current guesses synchronously, freezes certified winners and exact prefix-ready positions, and terminates if all values form a fixed point (including unchanged certified positions), which is unique. Plain Jacobi with same prefix freezing and fixed-point check is strong baseline. Output internal out-of-order tokens only after preceding formal tokens are determined, not as unconditional tokens after observing future random draws; no resampling of the same noise until terminal output. Ordinary direct Gumbel ancestral solver can use same certificate; equivalent flat with same permitted edge computation replicates. Thus no unique HFL-SD primitive proved. Certificate that fixes sampled token does not fix its probability vector or CE/score gradient. e.g. binary logits (1,0) vs (2,0) can both pick first token under same noise but CE gradient p-e_label differs. Learning-side formal dense gradient still requires logits; sparsifying graph or changing objective changes model and needs quality control.
