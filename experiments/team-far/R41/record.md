## 2. T: fixed-scale hierarchical quantization cell certificates (HQRC)
Freeze model trunk; full-precision output head W trained by HFL. Define fixed block scales s_b>0, saturated nearest integer Q_b(w)=clip(round(w/s_b),-K,K), K=7 (toy symmetric INT4; ties consistent, two outer cells unbounded). Decoder q uses shallow features with dequantized head. Formal p uses actual full-precision updated head and deep features. No separate full draft LLM; quantized output head alone not production cheap quantized model. Real HFL uses convex region combination w'=sum_e alpha_e w_e (alpha>=0 sum1); region model may arise from arbitrary local steps, but final convex aggregate contract required. Fixed scale and common codebook, compatible row ordering, finite precision boundaries must be addressed.
T1: Each scalar quantizer preimage C_k is an interval, half-open except saturating tails, hence convex. For old block code vector c, preimage product of intervals is convex. If every region's block code equals old code c under the SAME scales, then Q(sum alpha_e w_e)=c. Equivalently OR of region changed-block flags is a safe invalidation mask for cloud draft code blocks; only flagged blocks must be recomputed from true aggregate. Induct up the hierarchy via convexity at each node; local SGD may invalidate flags, actual final contributors must be used; arbitrary negative/extrapolating aggregation, momentum applied after aggregation, scale changes, postprocessing or mismatched rounding may invalidate. If all regional codes agree with each other but not old, same argument permits common new code; protocol may report common new code (extra communication, not executed).
T2: old code c, margin m_b=min coordinate distance to nearest active quantization boundary, ignoring unbounded saturation side. If sum_e alpha_e ||w_e-w||_inf,b < m_b, by triangle bound no coordinate crosses a boundary. Strict inequality avoids ties (in finite precision use outward conservative margin/error bounds); actual global delta norm gives tighter test. OR flag method may certify more than a uniform bound, but not mathematically dominates all inputs. Both sufficient not necessary. Example scale1, old scalar0, region updates +.6 and -.6 equally: both local change, cloud stays0; no exact union necessity. If both codes equal but dynamic scales differ, dequantized values differ, so same code is not cache validity. With dynamic max scale, even unchanged codes may have changed scale. Quantizing individual values and averaging codes is NOT same as quantizing average in general (e.g. .49 and1.49, avg .99→1, codes0/1 average .5; rounding/tie can fail in general).
T3: q freshness is NOT required by exact SD: at same formal snapshot and causal prefix, use ACTUAL retained q distribution for sampling and acceptance min(1,p/q), reject sample normalized (p-q)_+, valid truncation/bonus/EOS; conditional sequence law p by induction, independent random draws. Old q parameters are okay; stale p or mismatched q probabilities/KV are NOT. Any q refresh schedule based only on past information preserves target p given contract. Greedy compares actual p argmax with fixed tie-break. Production FP/top-p/KV/EOS not tested. Thus exact refresh certificate is needed only to emulate a specified freshly quantized q or operational quality target; strongest comparator may simply retain old q. No learning objective changed, HFL affects q update while SD feedback does not affect formal learning in this round. Same-info flat can OR/recompute too; G2 fails. Fixed-scale convexity is elementary, no novel general theorem claim.
