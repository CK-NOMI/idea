## T: Cartesian block verification without product vocabulary enumeration
For a synchronized group, treat vector next token as a symbol P_h=prod p_i(.|h_i), Q_h=prod q_i(.|h_i). Sun et al. ICLR2025 Block Verification Algorithm 2 / Eq4-5 defines w_0=1, w_j=min(1,w_{j-1}P(x_j)/Q(x_j)); choose full prefix with w_k, otherwise inspect j=k-1,...,0 in reverse. At j let R_j(y)=(w_j P_h(y)-Q_h(y))_+, S_j=sum R_j; selection probability S_j/(S_j+1-w_j), conditional correction R_j/S_j. Reverse order is equivalent to independent prefix trials choosing longest successful one. Exact race: at reached j draw skip with prob 1-w_j; otherwise draw Y~P_h using independent categorical draws and accept with (1-Q_h(Y)/(w_j P_h(Y)))_+; repeat if rejected. Per iteration skip mass 1-w_j, correction mass R_j(y), giving exact categorical outcome and geometric waiting. No evaluation of S or product table V^N. At fixed draft prefix h_j, probability of reaching j averaged over later q draws and independent decisions is 1-w_j+S_j (paper Lemma3, sum Q w_{j+1}=w_j-S_j). Multiplying by conditional expected trials 1/(1-w_j+S_j) gives one when positive; zero-denominator states never reached. Unconditional total expected race trials <=k; final bonus separate. O(N) likelihood work per trial after categorical preprocessing, not a deterministic time bound. Worst-case race unbounded; exactness in ideal arithmetic on positive allowed support. Standard BlockVerify + classic rejection/Bernoulli race, not new foundational theory or polynomial exact TV computation. Group block correction can change multiple lanes and discard valid suffixes of unaffected lanes; no claim of R72 child coupling preservation.

## T: causal survivor frontier and hybrid
Prefetch draft blocks along separate lane paths; verification must not inspect unrevealed future proposals or use suffix length as selection signal. At each within-block position active lanes with previous matched prefix have independent q draws conditional on revealed history. Apply R72 to vector, commit independent target conditional outputs, retire changed lanes to next round, keep unaffected suffix; bonus independently p. Adaptive schedule depends only on past; bounded-horizon joint law follows by induction / completion harmonic martingale, not merely marginal law. Conditional per-lane maximal pair law same as tokenSD, so no gain in per-lane expected accepted length, only joint completion/repair schedule. Hybrid: group-couple first draft token only; survivors run independent standard block verification on remaining draft with weight reset to 1; rejected lanes commit corrected token and defer; p bonus for k=0. Completion identity of BV yields target tail from survivor entry history after averaging latent accepted prefix/stop; independently across lanes. Induction over rounds yields joint target trajectories. HybridInd controls first-step split with independent maximum coupling. Cannot use future draft to decide coupling, or freely apply R72 to arbitrary whole-block kernel. Fixed snapshot; production EOS, top-p, greedy, finite precision, asynchronous packet-level guarantee not established.
