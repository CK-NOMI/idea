## T: formal state rather than token acceptance
Fixed causal model snapshot, complete predictive state s incl all position/processing/EOS dependencies, p(y|s), endogenous q(x|s) derived from coarsened model state, deterministic next state T(s,y). For given s group tokens by equality of T(s,y); if q's future state has other dependencies those must also be included. Rejection x!=y need not invalidate later verified rows if T(s,x)=T(s,y) exactly. Future state transition and both distributions depend solely on complete state, no hidden token-history, dropout, future leakage or stale versions. Token outputs are still formally sampled from p, not copied approximate semantics. Standard greedy uses target argmax with fixed tie-break and identical state contract. New compressed p is not original Transformer p; exactness relative only to new target. EOS singleton, stop after formal EOS, finite sampling horizon. For unrestricted Transformer KV, differing tokens generally induce different state; equality of only last hidden state is insufficient. 
Maximal token coupling m_x=min(p_x,q_x). Residual source a_x=(q_x-p_x)_+, target b_y=(p_y-q_y)_+, total delta. Class masses A_c=sum_{x in c}a_x, B_c=sum_{y in c}b_y, C_c=min(A_c,B_c), residual A'=A-C,B'=B-C,D=sum A'. Same-class transport mass a_x/A_c*C_c*b_y/B_c for class(x)=class(y)=c; cross transport a_x/A_c*A'_c B'_d/D*b_y/B_d, omit zero denominator terms. This achieves token agreement sum m and successor-state agreement sum_c min(P_c,Q_c) simultaneously, both optimal; FQAC-SD already gives this coupling in context of equivalent environment actions, not new base theorem. Formal sequence exact by fresh independent random tapes (U_q,U_accept,U_route,U_resid etc) indexed by absolute generated position; at committed state s, sample x~q(s) from that position's tape and y from coupling. Even if future tapes used in speculative branch, actual committed state depends only on earlier tapes, so conditional target law p follows by induction. If true state differs from speculative state, regenerate x from q(actual s) with same position's U_q and compute y from same tape; never treat x from wrong state as a correct proposal. If actual and speculative states later coincide exactly, previously computed corresponding row may be used; other rows invalid. For bonus use independent U_bonus at the current position; whether bonus is reached must depend only on earlier tapes. Audit with no bonus compares exact deterministic output to serial coupled reference; bitwise equality with ordinary AR using different random streams not claimed. No production top-p/temperature/repetition penalties/FP parity; such transforms must be included in full state and actual distributions. 
Architecture distinction: FPQ merges candidate DAG nodes using state equality, FQAC preserves action-side work but explicitly discards wrong-token suffixes. R65 modifies formal state and makes continuation criterion successor equality, plus same-position tape repair and rejoin. Prior work and standard state-space caching prevent claiming foundational novelty. 
Quality lower bound: for teacher distribution on (H,Y) and deterministic state S=phi(H), min expected NLL of state-only model equals H(Y|S), gap to true full-history conditional H(Y|H) is I(Y;H|S); compression not free. New model quality requires independent validation. Direct state-first strong baseline: sample class C~P_c(s), advance state via T(s,c), then sample token conditioned on class p(y|s)/P_c(s); conditional on complete class path (and fixed block anchor), fine emissions independent if state depends only classes. Can precompute class sums and sampling tables for finite corpus model. This can eliminate the expensive fine-token sequential dependency without speculative verification if class marginal cheap, and AR same state cache needs at most one exact row/token. Therefore no inherent HFL/SD necessity. For large neural model class marginal may be expensive; not measured. 
## H: next bold architecture, delayed fine-grained memory commit
Use two clocks: at fixed block start retain full raw-token causal context M_b; within block of length B, formal target uses M_b and sequence of learned class states C_<j; raw tokens already emitted are accumulated separately but do not modify within-block deep state until boundary, when actual raw token block updates M_{b+1}=F(M_b,Y_block). This differs from permanent state quotient: restores full fine-token information at boundary, forbids speculation crossing boundary without exact full-anchor state. For teacher P and fixed block positions, ideal model approximation irreducible NLL gap per token is I_P(Y_j; Y_<j^fine | M_b,C_<j) if M_b contains full earlier history; first token gap zero, B=1 recovers full-history model family. General M_b compression adds further information loss. New formal target, not dense-model lossless conversion. Exact stochastic/greedy relative to new model under same complete-state assumptions; causal masking or block recurrent architecture needed. HFL could share anchor network globally, learn region-specific state classes from local counts/gradient+SD survival statistics; learn objective L=CE+beta expected (1-A_state), ideally window survival rather than one-step. In this round only count aggregation and calibration proxy implemented, no true neural update or SD feedback on learned weights. Need compare direct class-first, standard SD on same p, original dense teacher, same-delegation flat, class-first with exact state marginal cost, dynamic reset/attention baselines. This is untested, not claimed to solve G2/G5; no new toy sweep needed before real teacher quality and cost test.
