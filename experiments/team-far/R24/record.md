## 2. T: anchor group estimator of original expected reward update
Fixed prompt/context, snapshot, independent rollouts from original formal causal p, endogenous shallow q, standard SD min(1,p_X/q_X) and positive residual, first-reject truncation and legal bonus; training-only generation of needed trajectories. No external complete draft LLM. Fixed binary terminal reward R, score S_i (gradient of sequence logprob or fixed response-average logprob), group size G, normalized reward-only on-policy update g_G=1/(G*s) sum_i(R_i-Rbar)S_i, s=sqrt(M(G-M))/G+eps with M=sum R_i and eps>0. Rewards/advantages detached, no entropy/KL or other regularization. Fixed theta; one stochastic gradient expectation, not equality of update distributions or FedAdam/PPO multi-epoch trajectories. Formal output p unchanged for each generated rollout, but group size/realized gradient distribution is changed and complete joint cohort is not returned when stopped.
Identity g_G=1/(G^2*s) sum_{i<j}(R_i-R_j)(S_i-S_j). Pick a uniform b-subset B, b>=2, BEFORE seeing outcomes (by exchangeability first b independent trajectories works). Each pair inclusion prob b(b-1)/(G(G-1)). Thus g_b=(G-1)/(G*b*(b-1)*s) sum_{i<j in B}(R_i-R_j)(S_i-S_j) satisfies E_B[g_b|conceptual full group]=g_G. If initial anchors are all same reward, numerator exactly zero, skip remaining G-b without computing s. This is NOT asserting actual full group is homogeneous; the unbiasedness averages random subset. If mixed, generate G-b reward-only auxiliary rollouts; use full M in s and only anchor scores. Optionally select one success and one failure uniformly in anchors, use a(b-a)(Splus-Sminus) instead of full pair sum (unbiased conditioned on anchor set, additional variance). Full group postcommit one positive/negative comparator likewise b=G,two. If success p conditional prompt, a~Bin(b,p), c~Bin(G-b,p) independent. Expected generated=b+(G-b)(1-p^b-(1-p)^b), scores computed=b*P(mixed) or 2*P(mixed). On a mixed anchor set, let delta=E[S|R=1]-E[S|R=0], v+/- conditional covariance traces. Weight w=(G-1)*a*(b-a)/(G*b*(b-1)*s_{a+c}); conditional mean=w delta and covariance trace=w²(v+/a+v-/(b-a)) or w²(v++v-) for one-per-class. Exact variance trace=sum_{a,c}Pr(a,c) w²(||delta||²+conditional score variance term) - (E w)²||delta||². Full group g_G is b=G. E[g_b|full group]=g_G implies Cov(g_b)=Cov(g_G)+E Cov(g_b|full group) PSD, no free variance reduction. Equal-precision (independent same snapshot mean estimation) work proxy is variance*expected cost, not training convergence theorem. Homogeneous full groups can skip reward backprop in strong baseline. Plain AR can generate identical independent formal samples and implement all estimators, without SD. Same-information flat can select identical b and regional settings. No G2.
## 3. T: improved randomized completion
Instead of deterministic anchor-pair abort, let Z contain first b reward/score data, H(Z) any cheap proxy for full group gradient, pi(Z)>0 predictable, I~Bern(pi) independent of unrevealed auxiliary trajectories conditional Z. Estimator H+I(g_G-H)/pi; compute full G only if I=1; conditional expectation given conceptual full group equals g_G. Conditional extra covariance=(1/pi-1)(g_G-H)(g_G-H)^T, trace extra E[(1/pi-1)D(Z)] with D(Z)=E[||g_G-H||²|Z]. If fixed budget E[pi c] and known D,c>0, optimum pi=clip(sqrt(D/(lambda c)),pi_min,1) by separable convex Lagrange minimization. For proxy exact conditional mean H=E[g_G|Z] minimizes residual; true unknown moments are oracle, not free. Pi selected using past/calibration only; no post hoc use of unknown rewards. Does not preserve full group gradient distribution, nonlinear optimizer, current-round reward-weighted global normalization if it depends on missing groups, or independent regularizers automatically. Prior R21 conditional HT, R03 DR, randomized telescoping and active sampling overlap.
Implemented analytic one-step proxy based on anchor class score sums, coefficient estimates from fitted regional p_hat. For m successes define P_m=(G-m)/(G² s_m), N_m=-m/(G² s_m), set both zero if homogeneous. For a anchor successes and c auxiliary successes, g_G=P_m sum_all+ + N_m sum_all-. Proxy H=h+ sum_anchor+ + h- sum_anchor-, where h+,h- are means of P_m,N_m under Bin(G-b,p_hat); gated version H=0 if homogeneous anchors; oracle adds expected auxiliary sums under true p,delta. With on-policy one-step score E[S]=0, class means (1-p)delta and -p delta. Conditional squared residual can be integrated exactly over class counts and conditional score means/variances (formula in completion_probe). Candidate computes anchor scores whenever proxy nonzero; charges complete scores if no proxy and audited mixed; remaining score computations only for audited mixed groups. Expected cost counts each generated rollout 1 and each score r, ignores calibration, reward, storage, batches, communication etc. HFL uses per-region training-only estimates of p and D vs a to select b and pi; calibration exact p/v on one-step small model requires full dense probabilities, not free or deployable large-model learning. Same-info flat reproduces; no special role for SD beyond rollout speed.
