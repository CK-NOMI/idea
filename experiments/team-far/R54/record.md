## T/H: architecture and exact scope
Frozen lower/upper backbone x(h), y(h), per-client fixed initial tied head Wc (pre-fit; not a common initial global head). Choose common orthonormal columns B0 and edge-specific Be perpendicular to B0; P_e=B0 B0^T+Be Be^T, C_e=I-P_e. A_c=U0 B0^T+U_e Be^T+L_c C_e, shared/edge coordinates owned by cloud/edge and private complement by client. Formal p_c=softmax[(Wc+A_c)y]; internal draft q_c=softmax[Wc x+A_c P_e x]. Same frozen LM and base output head, no independent draft LM or separately learned draft matrix. q differs from ordinary tied early exit by private correction cut only. Since C_e P_e=0, any private delta L_c C_e leaves q_c identical for every h, not merely calibration activations, assuming fixed backbone, basis, Wc and processors. Formal p can change, e.g. binary logits with x projected to e1 and y=e2, private change (a,0) on e2 alters formal log-odds. If private formal gradient G C_e nonzero, taking delta=-eta G C_e gives first-order formal CE decrease eta||G C_e||_F²; no guarantee on held-out NLL or EAL. At fixed formal version, ordinary exact p/q ratio and residual, causal rejection truncation, bonus/EOS, independent randomness give exact formal sequence law; greedy official argmax/tie policy. No production sampling or top-p/FP test. If p changes mid-request, must specify snapshot or authorized causal target law; this is not an exact substitute for a fixed old target. Old q is already usable for standard SD when accurately tracked, so invariance alone is not a unique latency saving. A purely private update changes target p and may require new formal logits; cannot claim full KV/activation invariance under general backbone updates.
Hierarchy gradient: for equal clients, objective mean_c CE_c-beta overlap_c. Exact gradient in constrained orthogonal coordinates: cloud mean gradient projected onto B0, edge mean within edge projected onto Be, private local gradient projected onto C_e; coordinate-wise learning rates given. In initial A=0, let F_c=full formal part gradient (CE plus any p-side overlap derivative), Q_c=q-side overlap derivative. The spectral experiment actually uses F_c=CE-only gradient, J_c=CE-beta single-step-overlap full tied gradient. This is a heuristic proxy (the p-side overlap gradient persists in the private cut, so the exact formula would use F_c=CE+p-side overlap gradient). For the *exact* split at common anchor with F as formal-side total, J=F+Q, projected first-order squared descent for a group choosing shared rank-r basis B vs private is Tr[B^T (Jbar^T Jbar - mean F_c^T F_c) B] plus mean ||F||²; max for top-r eigenvectors (Ky Fan). Nested global then regional spectral choice is greedy, not joint optimum; score may have negative eigenvalues, selecting fixed rank may harm objectives; nonconvex generalization not implied. Implemented PCA and approximate shifted power iteration of the CE-only heuristic matrix, not exact joint spectral solver. Basis learned from local raw features centrally in the probe; real HFL could aggregate uncentered second moments d² or gradient Gram matrices with permissions, but cost/privacy not implemented. Same-information flat delegation exactly reproduces coordinate protocol, and ordinary personalized LoRA+fixed draft or tied head are strong alternatives.
Communication P: fixed basis globally available, rank-r0 cloud upload V*r0 scalars per client-equivalent; edge rank-re coefficients V*re remain region, private V*(d-r) remain client. Basis refresh d*r and d² statistics, base W and model distribution, optimizer/metadata, separate physical edges, actual training cost not measured. For V=32000 d=4096 r0=re=32, cloud FP32 4.096MB vs full output head 524.288MB, but standard matched rank LoRA achieves comparable savings; no comparative claim. Base head Wc*x still dense, no intrinsic draft FLOP reduction. Invariance does not force HFL; separate draft matrix baseline can freeze q too, at extra storage if not using same cut.
