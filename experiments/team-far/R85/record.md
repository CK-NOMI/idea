## T — parameter ownership and verification-aligned split
At common parameter snapshot theta, fixed client weights w_i>0 sum1 and fixed batches, g_i=gradient formal CE, t_i=gradient TV(p_i,q_i), both logits differentiated (same W, shallow early exit, no independent full drafter). For a disjoint parameter block B, allowed ownership partition P_B is a cut of the client-edge-cloud tree. Let W_A=sum w_i, g_A=weighted mean, t_A likewise, gbar/tbar at root. Compare common-snapshot global step -eta*gbar_B with cut-local -eta*g_A,B for all clients in A. Additional first-order CE descent is eta C(P)=eta sum_A W_A ||g_A-gbar||², TV descent eta S(P)=eta sum_A W_A <t_A-tbar,g_A-gbar>. Both follow by grouping linear term and zero weighted centered means. Refinement at node A replaces group by children and adds C_A=sum_child W_child||g_child-g_A||²>=0, S_A=sum_child W_child<t_child-t_A,g_child-g_A> (can be negative). Across multiple blocks sum C/S; expansion error O(eta²) only with local smoothness, TV kinks require directional derivative/branch care. Constraint S>=0 gives no FIRST-ORDER extra TV increase relative to global, not absolute TV decrease, not generalization guarantee or exact multi-local optimizer. Equal-size blocks, extra parameter copies cost |P|-1. Select sum C max with sum S>=0 and integer budget. Multiobjective DP over blocks and used copies, retain nondominated (C,S) pairs; dominance valid for additive future scores and fixed exact budget, complexity can be exponential in frontier size, no general polynomial claim. If all options infeasible select max S and report violation; none in these cases. Equivalent classical hierarchical variance decomposition/Pareto knapsack and gradient-based parameter disentanglement; not claim first FL layer sharing. Strong C-only policy is exact first-order formal gain optimizer within candidate budget. 
Model: early-exit q=softmax(W h1), p=softmax(W h2) using same internal W. A cut including only later blocks leaves q identical across regions at cloud synchronization if all upstream and W common; regional shallow updates generally invalidate common shallow features; no guarantee during edge cycles. Standard causal SD with exact p/q current snapshots gives fixed personalized p, not original global model distribution. Greedy/top-p/EOS/production FP not validated. Actual sampled standard token SD (K<=2 with bonus, rejection positive residual, 26-character output, fixed length); q and p both evaluated via full toy model, no cheaper real shallow kernel/batched verifier.
