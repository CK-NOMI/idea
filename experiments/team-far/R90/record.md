## Problem and architecture
To stop repeating R89 synthetic optimizers, test necessary headroom of a concrete architecture: a shared embedding/position/first transformer layer and tied output head (cloud owns these), regional second transformer layer (edges own), four logical clients in two regions with local private data. Within a frozen snapshot all same-version prefixes can share legal shallow computations, regional deep computations can share same-region prefixes. Sharing requires authorization and identical entire dependency closure, input/position/numerical state; simulated public names do not prove legal real cross-client sharing. q uses first layer and same head, p uses both layers and same head, no separate draft LLM. Generation followed by reward-weighted log-likelihood gradient at same snapshot, not full GRPO/PPO. Both model ownership and global/regional learning choices are conventional and closely related to R40/R76/R77. Main contribution is a counterfactual necessary-condition audit, not a new architecture claimed to win.
## T1 work-set dominance
Fix the formal sequence realized by any valid SD sampler and model snapshots. For client c let C_c be the ancestor closure of formal forward nodes needed for exact output probabilities and the selected-path loss, D_c be all verifier nodes including rejected draft candidates, T_c the training ancestor closure. In this setup C_c subset D_c, T_c=C_c (no additional loss ancestors). A strong AR with exact same formal path and same version-aware caching can evaluate exactly C_c (not necessarily same random seed); a strong cached SD evaluates D_c. For each layer or other dependency-equivalence class map pi, union preserves inclusion, so |union pi(C_c union T_c)| <= |union pi(D_c union T_c)|. Positive weighted node costs preserve inequality. This rules out reduction of unique forward nodes via SD alone in this model; not an impossibility for batched wall time, approximate/new objectives, alternate verification kernels or rejected-branch loss objectives. Exact formal backward uses only T_c and adjoint accumulation by reverse topological traversal; if both AR and SD retain same valid tape, neither needs extra forward replays. Gradient identity is conditional on graph equality, not just equal numeric activations; version changes invalidate. HFL can reduce duplicate rows of both AR and SD, but any hierarchy advantage must survive same authorized delegated flat baseline. 
T2: define A and S layer-row counts after legal sharing, N and R serial per-request step/verification block counts, q extra shared projection count. Ideal additive proxy AR=A_s c_s+A_d c_d+T_back+c_launch N, SD=S_s c_s+S_d c_d+T_back+c_q Q+c_launch R. Break-even iff c_launch(N-R)>(S_s-A_s)c_s+(S_d-A_d)c_d+c_q Q. For 15% total time reduction, necessary under this proxy c_launch(.85 N-R)>extra+.15(A_s c_s+A_d c_d+T_back). If .85N<=R and extra nonnegative no positive launch coefficient reaches threshold. Actual batch parallelism can alter step count, row cost, HBM traffic, activation storage, recomputation and latency; these counts are not real kernel launches. Four-way interaction in saved node counts I=(SD separate-SD shared)-(AR separate-AR shared) can be positive even while shared SD > shared AR, hence factorial interaction alone not sufficient. 
T3: conditional standard stochastic SD uses actual q and p (full softmax over 26 lowercase letters, excluding BOS from output), accepts min(1,p/q), rejects with normalized (p-q)+, truncates at rejection, bonus when length permits. Per step marginal p, induction gives specified fixed-length conditional joint law in ideal arithmetic with independent draws; deterministic greedy would require exact current formal argmax and same tie convention, not tested here. No EOS/top-p/FP exactness claim. Rewards held fixed during each gradient; score loss is negative reward times mean token log-prob. No external label gradient through reward, no claim exact optimizer equivalence to full HFL multi-step or original model including BOS.
