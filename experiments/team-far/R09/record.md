## Fatal R08 assumption and exact first-order replacement (T)
R04–08 freeze trunk and untie trainable output head W. For fixed prompt and parameter-independent reward R(Y), full-softmax p=softmax(Wh/T), the standard likelihood-ratio identity yields g=E[R S], where S=sum_t [(e_{Y_t}-p_t) h_t^T/T]. Since h_t is independent of W at fixed token history (frozen trunk, untied head), no deep backward is needed: the exact score is known from committed verifier logits and hidden states. Do not substitute draft logits, rejected suffix positions, or stop-gradient on policy probability when computing the score. At fixed finite horizon, differentiability and boundedness permit this identity. It estimates the *true first-order gradient* of J, not the exact finite-epsilon fixed-bank finite difference from R08; changing objective/estimator must be explicit.

For fixed disjoint row-coordinate blocks B_j of dimension n_j, independently seeded Rademacher u_j on each block, conditional on Y, S, E_u[sum_j u_j u_j^T S]=S. The central finite difference full-bank LR estimator tends to R sum_j u_j u_j^T S as eps→0. Conditional squared Euclidean norm E_u||R sum_j u_j u_j^T S||²=R² sum_j n_j ||S_j||², while ||RS||²=R² sum_j||S_j||². Therefore its additional trace variance relative to analytic score is E[R² sum_j (n_j−1)||S_j||²]≥0, with equality only when all nonzero components have n_j=1 or zero reward. Fixed partition, independent direction signs and anchor, same reward/trajectory budget; this does not compare fixed realized direction FD targets, full-backbone black-box ZO, unknown differentiable head or direction-conditioned anchor selection. Also applies to an action-independent fixed baseline replacing R. This is classical Rao-Blackwellization, but it disproves the necessity of zero-order directions in our actual R04–08 setup. Exact first-order score also avoids 2K perturbation heads and branch generation; dense outer products and communication are not free.

## Verification-tree sparse control variate (T/H)
Use an inner shallow q to construct a deterministic (or separately randomized independent of current formal sampling coin) candidate tree. At actual prefix H_t, state baseline b_t is predictable. Choose sparse residual c_t(v) supported on authorized candidate children, with estimates trained on prior data or independent folds, detached. Let s_t(v)=(e_v-p_t)h_t^T/T. Then
G=sum_t [(R-b_t-c_t(Y_t)) s_t(Y_t) + sum_v p_t(v)c_t(v)s_t(v)].
Conditioning on pre-draw state, tree and predictor gives E[c_t(Y_t)s_t(Y_t)]=sum_v p_t(v)c_t(v)s_t(v); b_t score expectation zero. Thus E G=grad J. No assumption of accurate c, no guaranteed variance reduction. Correction is rank-one per position [p_t ⊙ c_t − p_t (p_t^T c_t)] h_t^T/T, sparse c allows computing inner product only on tree, although p_t vector/outer product remain dense. If draft uses same sampling randomness as formal action, or tree is chosen after observing action, this conditional proof is invalid unless conditional p is recomputed. For exact decoding use target-first deterministic/independent tree, formal independent target RNG per token, submit actual target draw; fall back on missing branch and discard invalid descendants; autoregressive induction matches full-softmax sequence distribution. Greedy uses target argmax. Production top-p, EOS, numerical/KV and complete decoder not implemented. For stochastic rewards use conditional expectation as usual, reward predictor must not read current outcome; no private data transfer implied. Same candidate control variate on ordinary AR (compute q/child feature if not cached) is mathematically identical. Main hypothesis is existing verifier tree may contain useful predictive features at lower incremental cost, which must be measured. Standard action-dependent control variates and expected policy gradients already cover underlying estimator; do not claim novel foundational theorem.

HFL: train regional reward predictor on prior private prompts; aggregate formal gradients with predetermined weights and common snapshot. Per-token score/CV rank-one factorization allows delayed weighted merge at edge/cloud, rank ≤ number of committed positions, not necessarily compressive when many positions, no DP; sharing features may leak, use local dense aggregation unless authorized. Ordinary flat with same data/permissions and AR can emulate this, so G2 is still unproven. No new training optimizer or actual physical hierarchy in R09.
