## T: exact block renewal law
Assume finite predictive state space, fixed snapshot, exact deterministic state update given token, full support p,q on finite vocabulary, no EOS, fixed K proposals then bonus, standard causal rejection and positive residual. For finite first-order state s=last token used in experiments P_ij=p(j|i), Q_ij=q(j|i); general finite-state can sum accepted/rejected token masses into destination states instead of entrywise min of aggregated state matrices. Define M_ij=min(P_ij,Q_ij), R=P-M, H_K=sum_{j=0}^K M^j. For a block from state i, after j accepted drafts probability mass at state is M^j. Reject and resample produces unconditional R mass, all K accepted emits bonus P. Block end kernel B_K=sum_{j=0}^{K-1} M^j R+M^K P=I+H_K(P-I). Mean number of emitted tokens L=H_K 1. At K=0 B=P,L=1. With positive P,Q, B positive, stationary distributions mu(P) and nu(B) unique. nu B=nu implies nu H(P-I)=0, hence nu H=(nu L)mu by uniqueness and total mass. Thus mu is actual per-token stationary measure, nu distinct block-start measure. H invertible here: any left null xH=0 gives xB=x, so x=t nu, but nu H !=0; hence x=0. Let lambda=nu/(nu L)=mu H^{-1}. For known mean block cost column c (constant or state dependent), long-run cost per emitted token J=nu c/(nu L)=mu H^{-1}c. In particular c=1 measures blocks/token, not GPU time. For a deterministic causal state-dependent K(i), use row i of H_{K(i)}, B_{K(i)}, L_{K(i)}, c(i,K(i)); same identity holds rowwise and same invertibility argument. Finite state, stationary, positive kernels are essential; full arbitrary Transformer state space not tractable, finite sequence startup/EOS not handled. If p=q and K constant, H1=(K+1)1 and J=1/(K+1), despite periodicity possible in other nonpositive examples.
Exact differential at fixed cost c and no min ties: z=H^{-1}c, lambda=mu H^{-1}, v=(I-P+1 mu)^{-1}z. Stationary differential dmu(I-P)=mu dP, dmu1=0, hence dJ=mu dP v-lambda(dH)z. dH=sum_{k=1}^K sum_{j=0}^{k-1} M^j(dM)M^{k-1-j}. If c varies add lambda dc. Use actual p and q shared bias softmax chain rule; finite ties choose directional derivatives, no production guarantee. Detached current nu-weighted local window objective 1/(nu H1) matches VALUE J at anchor for unit costs, but not general gradient since nu changes. Uniform token-start mu objective 1/(mu H1) may even reverse rankings: actual sampled 2-state example P=[[.274604,.725396],[.762142,.237858]], Q1=[[.764900,.235100],[.881867,.118133]], Q2=[[.258135,.741865],[.141294,.858706]], K2. Naive costs .474315/.482732 prefer Q1, true costs .441691/.426573 prefer Q2. Exact full precision in results. Ordinary SMDP sensitivity / Markov renewal theory and WTV window weighting are strong prior art; no claim novel fundamental mathematics.
Fixed p,q and candidate depths 0..4, exact average adjusted-cost policy iteration: for current policy rho=nu c/(nu L), solve (I-B+1nu)h=c-rho L. At each state minimize c_k-rho L_k+B_k h; retain incumbent on ties. Bellman residual zero certifies global finite stationary policy optimum: for any other policy multiply h<=c'-rho L'+B'h by stationary nu', cancel h, implies rho<=rho'. Unlike local myopic c_k/L_k includes future block-state effect. SMDP classical. Full kernel enumeration and solve O(n^3) dense for n states, no deployability claim for vocabulary^context. Same-info flat can reproduce exact policy, ordinary AR + statistics and standard adaptive SD can access same info. No special HFL necessity.
