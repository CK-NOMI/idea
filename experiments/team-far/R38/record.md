## 1. Scope and four alternatives
Same authorized prompt, frozen formal p, fixed L, deterministic comparable reward, private regional certified set, soft certificate r(y) in [0,R(y)] as R37; for implemented experiments hard r in {0,1}. Let a=E_p r, Z=1-a. Preserve original p distribution via C/B tagging, only replace C score by its expectation under restricted R36/R37 first-step fixed-length binary on-policy objective. Not preserve random optimizer trajectory, general PPO, or full outputs if C not sampled. Region ownership fixed before independent draws. Not evidence real HFL shares such tasks, privacy/security not guaranteed. Two checkpoint microGPT same scale; q actual shallow distribution, no separate full drafter.
Strong alternatives: (1) ordinary exact SD p rollout then tag with Bernoulli(r(y)), same RB gradient; (2) draw tag first and sample B with conditioned q and p; (3) draw tag first and use ordinary SD p rollout rejection until B; (4) draw B first-token from p_B and use rejection within cell. Cache and certificate compute costs must be equally accounted, use optimized ordinary AR with same cached prefix and score integration as baseline.

## 2. T: cancellation of naive restart and cell restart
Let C(Y,execution) nonnegative additive cost per complete original SD draw, finite mean, iid attempts with independent cert Bernoulli tag conditional on Y. For one B request, E total rejection cost = E C/Z via renewal even if cost correlated with rejection (first attempt always incurred, then repeat with probability a). Per original slot with probability Z of B and analytic C treatment, expected total = E C, before C certificate/RB costs. This is an exact cancellation, not universal GPU wall time lower bound; cache across attempts, batch, stateful policy violate iid constant attempt cost. For cells u with original mass P(u), conditional survival Z_u=E[1-r|u], exact route p_B(u)=P(u)Z_u/Z. Generate p(.|u) and reject using 1-r; per original slot tail expected sum over Z_u>0 P(u) E[C|u]; only fully certified cells avoid tail work. Can retain root computation, and flexible per-cell selection; same-info AR and ordinary SD can apply both. No new rejection-sampling theorem.

## 3. T: first-exit frontier and ideal cache equivalence
Trie T contains all prefixes of nonzero finite certificates. Interior node h has p(h) and children C_h. First-exit atom m(h)=p(h)*sum_{x not in C_h} p(x|h). For fractional certificate terminal leaf y also include atom p(y)(1-r(y)); hard r=1 has no terminal remainder. These disjoint atoms (entire suffix cylinders plus fractional terminal leaves) sum to Z. Sample atom conditional on B with weight m/Z; for exit atom sample next token from p(.|h) conditioned outside C_h, and continue ordinary exact SD or AR from new prefix. Proof multiply atom probability by normalized exit token and unconditioned suffix; outside trie r=0, yields p(y)/Z; terminal fractional gives p(y)(1-r(y))/Z. Exact real arithmetic, shared snapshot, consistent processed p and causal histories, exact SD acceptance/residual/bonus/truncation. Greedy original use p argmax not conditional argmax. Finite precision, EOS, top-p implementation not tested. Prefix tree finite explicit, no arbitrary reward black-box guarantees.
Compact interface: store one node ID and exit mass, sample frontier atom; selected exit row may require target reevaluation to sample off-trie token unless dense p row cached or exact off-trie sampler exists. Need topology and leaf weights if fractional, model state/KV not included. For hard finite trie, storage proxy 8 bytes per internal node (32-bit ID + 32-bit mass; not bitwise exact probability implementation), vs dense FP32 p row 4V per internal node; actual compressed row alternatives, topology/index overhead, precision and memory traffic unmeasured. This is a compact representation, not 92.6% total system memory saving.
CRITICAL: ideal same-version cached AR can already reuse every p row on T, and any visited prefix outside T has r=0. For every outside prefix v, per original slot probability Z P_B(v)=P(v). Thus expected formal position work outside cached T identical with pretag conditional frontier and ordinary posttag AR with same cache; with shared multi-trajectory occupancy, probability of outside visit also equal under independent original slots (tag coupling can map same outside visits). For posttag SD, one may traverse cached trie first via identical first-exit distribution with certificate terminal mass included, then invoke ordinary SD only outside T. Hence no unique improvement from first-exit representation beyond equally allowed cache/skip baseline. Not claim ordinary production SD actually implements it or universal wall-time equivalence under different batching. If cache absent, candidate needs compute trie and may lose; if cached rows omitted, at most one target p row reevaluation per exit under assumed exact frontier and available prefix state; KV rebuild may add many calls. Real HFL communication/permissions remain unverified.
