## T: reuse-constrained sampling, not a new inference law
Fixed h and theta, strictly positive actual self-draft q, formal p, K=2. R52 notation m_i=min(p_i,q_i), a_i=child overlap, d_i=grad m_i, g_i=grad a_i, D=sum d_i, A=sum m_i(1+a_i). Fix b before drawing and detach. Define v_i=(a_i-b)d_i+m_i g_i. For any positive r chosen independently of the current sampled X conditional on h and snapshot, H_r=(1+b)D+v_Y/r_Y, Y~r, has mean grad A. Trace variance V(r)=sum ||v_i||²/r_i-||sum v_i||². The root p and q can be obtained from actual verification after X; r may depend on root probabilities independent of X given h/theta, but not on realized child features unless correcting the conditional sampling law. Actual formal decoding still uses X~q and its standard p/q acceptance and residual; the auxiliary Y is separate and cannot replace the committed token. Apply updates only after fixed-version generation/verification block; no current snapshot changes. If verified child hX is retained and legal, maximize reuse by coupling X and Y: conditional keep X with min(1,r_X/q_X); otherwise draw Y from (r-q)_+/TV(r,q). Marginal r exact, mismatch TV(r,q) is minimal among all couplings since diagonal mass <=sum min(q,r). Additional child evaluations expected delta=TV, only if one old child available and cost of missing child equal; not a GPU FLOP/latency theorem. Formal randomness independent of auxiliary coupling given X and p/q. Standard SD law unchanged by auxiliary sampling under this contract; no production top-p/EOS/finite precision implementation.
Unconstrained minimum variance r* proportional to ||v_i|| (Cauchy Schwarz; zeros use support or positive floor). Under extra-child budget eps solve convex minimize sum ||v_i||²/r_i subject sum r=1, r>0, TV(r,q)<=eps. KKT with positive norms, multipliers lambda, nu>=0 for TV expressed as half L1: r_i=clamp(q_i, ||v_i||/sqrt(lambda+nu/2), ||v_i||/sqrt(lambda-nu/2)) if lambda>nu/2; if lambda<=nu/2 upper endpoint infinity (handle degenerate/ties separately). This follows stationarity separately above and below q; no claim novel convex optimization. Numerical implementation below uses mixtures, NOT exact TV-constrained solver. Oracle uses unavailable child norms, not deployable.
HFL predictive implementation: on independent calibration contexts estimate per-token s_e(i)=sum ||v_i|| /sum q_i (small smoothing), aggregate additive 2V scalars at client/edge/cloud, use r=.5q+.5 normalize(q*s_e). Same global b in all arms; global and local predictor baselines. Mass baseline r=.5q+.5 m/sum m; oracle .1q+.9r*. If true live calibration computes only sampled child norm, need HT/ratio correction, estimate support, costs; actual calibration enumerates all children, so deployment unverified. Same-info flat can reproduce sufficient stats, standard AR+IS can reproduce learning target. No DP guarantee. FP32 two V arrays (V=32000) 256000 B per sender per refresh, excluding counts/version/parameters/downlink/overhead; not actual network measurement.

## T: total gradient variance and budget
Let C sampled uniformly within fixed client, G_C=grad CE_C-beta grad A_C. Conditional unbiased joint estimator grad CE_C-beta H_r has trace covariance B+beta² E_C V(r), B=E||G_C-E G_C||². Hence even zero auxiliary conditional variance can improve current estimator at most W/(B+W), W=beta² E V(q). This is an exact conditional finite-population bound for this fixed snapshot and sampling scheme, not all architectures or training dynamics. If average n iid child samples per context and M iid contexts (fixed client, equal weights), variance=(B+W/n)/M, cost=M(c0+n c1); continuous optimum n*=sqrt(W c0/(B c1)), constrained n>=1, integer/budget rounding required. Reuse-aware marginal cost normalized proxy (B+beta²V(r))*(1+lambda*delta), lambda incremental cost divided by base cost. Improvement requires lambda<(Vjoint(q)/Vjoint(r)-1)/delta when delta>0. For a second iid q sample taken with probability min(1,delta/(1-sum q²)), expected extra distinct child <=delta; estimator average if drawn, variance factor 1-prob/2. This is strong simple budget comparator; proxy assigns full delta cost even if capped, conservative for comparator. Neither cost proxy nor conditional moments prove convergence or real time.
Counterexample: if G_C varies widely but auxiliary variance tiny, arbitrarily large percentage reduction of auxiliary variance can be immaterial to total; if B=0, the bound is vacuous and child variance may dominate. If r adapts to realized X or child without correct law, importance estimator may be biased. Nonlinear local SGD/Adam and actual sequential training not implied.
