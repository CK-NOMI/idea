## T1 exact second-stage allocation, certified first-stage relaxation (K=2)

Fix E region distributions p_e and weights w_e, common proposal, nonnegative incremental costs independent of policy except through candidate prefix; all fixed length draft positions are verified, no EOS or cross-request costs. For root token x assign s=q(x), set a_e(s)=w_e min(p_e(x),s). Let child proposal z in simplex, child regional distributions p_e(.|x), mean costs c_x(y)=sum_e w_e c_e(x,y). Child optimization is max_z sum_y [sum_e a_e(s)min(p_e(y|x),z_y)-lambda s c_x(y)z_y]. Concave piecewise linear separable objective, slopes of each y decrease at p_e(y|x), greedy sort segments by marginal slope, allocate one unit (within tied slopes preserve segment order), exact even negative slopes because normalization equality. Root contribution f_x(s)=sum_e a_e(s)-lambda s c_root(x)+optimal child value. F_2=max_{s_x>=0,sum s=1} sum f_x(s_x). On intervals between {0,1,p_e(x)}, for fixed child policy f is affine in s; max over child policies convex on interval. Thus chords over adjacent breakpoints majorize f; taking upper concave hull H_x of all breakpoint values yields global concave majorant touching at retained knots. Solve max sum H_x(s_x) with same segment allocation. An optimal allocation exists with at most one partial segment; all other s_x are retained knot values and H_x=f_x there. Reevaluate child at partial s (all allocated s in implementation), producing feasible L; relaxed value U is upper bound. Hence L<=F_2<=U and U-L=H_j(s_j)-f_j(s_j) for at most one fractional token j, zero if all endpoints. This is a specific separable Shapley-Folkman-type certificate, not a new general convexification theorem. Nonzero gap possible; exact global search remains optional, no claim polynomial exact for arbitrary instance. For general K deeper child value remains expensive; no polynomial K theorem.
With sorted probabilities and incremental slope updates, one child costs O(V E log(VE)); evaluating O(V E) root knots yields O(V^2 E^2 log(VE)), plus root hull/sort, input O(E V^2), naive implementation loops E in each slope hence additional factor E in that component. This is polynomial in V,E for K2, not practical 100k vocab, no production speedup. Floating tolerance in implemented hull and comparisons not rigorous interval arithmetic; numerical tests not a proof of exact machine behavior.
